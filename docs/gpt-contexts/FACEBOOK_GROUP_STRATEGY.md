# Facebook Group Strategy

Last Updated: June 2026

---

# Purpose

Generate organic awareness for NoteLib through educational reviewer content.

The goal is:

Build trust first.

Introduce NoteLib second.

---

# Key Discovery

Groups engage with:

* reviewer questions
* board exam questions
* educational discussions

Groups do not engage strongly with:

* feature announcements
* product promotions

---

# Reviewer Question Framework

Post Structure:

Hook

↓

Question Screenshot

↓

Answers

↓

Answer Reveal

↓

Public Library Follow-Up

---

# Screenshot Rules

Screenshot contains:

* question
* choices

Caption contains:

* hook only

Never repeat the question in the caption.

---

# Good Example

Caption:

"Let's see if you still remember this one. 📚😅"

Question remains in screenshot.

---

# Bad Example

Repeating the entire question inside the caption.

This creates redundancy.

---

# Answer Comment

Purpose:

* reveal answer
* teach
* provide note link

Structure:

✅ Answer: C

Short explanation.

Specific note URL.

---

# Public Library Comment

Separate comment.

Purpose:

* provide additional reviewer materials

Structure:

"If you enjoyed this reviewer question, there are more reviewer notes available here:

<library url>"

---

# Reply Strategy

Correct Answer:

"You got it! 🎉 Looks like you're familiar with this topic. 😄"

Wrong Answer:

"You're close! 😄 Try another guess before checking the answer comment."
