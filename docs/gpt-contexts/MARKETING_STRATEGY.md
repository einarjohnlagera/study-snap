# Core Marketing Principle

People do not come looking for NoteLib.

People come looking for:

* reviewer questions
* educational content
* trivia
* board exam preparation

Therefore:

Content first.

Product second.

---

# Positioning

NoteLib is not positioned as:

* an AI tool
* a note summarizer
* a NotebookLM competitor

Instead:

NoteLib is a study workflow.

Tagline:

"Your notes become your study system."

Core Loop:

Capture → Generate → Review → Improve → Copy → Repeat

Engagement first.

# Post Structure Framework

Every post should follow:

## 1. Hook

Start with:

* curiosity
* relatable scenario
* challenge
* observation

Examples:

"Ever notice how..."

"A pregnant patient comes in..."

"Every CPALE taker has answered this question before..."

"Why do some buildings stay cooler..."

Avoid:

* Today let's study...
* Here's a lesson...
* Did you know...

---

## 2. Context

Provide 2–4 short sentences.

Make the audience think:

"I know something about this."

or

"I should know this."

---

## 3. Quiz Transition

End with:

Can you answer today's [EXAM] review question?

📚 Answer in the image.

---

## 4. Hashtags

Use 4–6 relevant hashtags.

Avoid hashtag stuffing.

---

# Image Rules

Image should contain:

* actual quiz question
* answer choices
* clean layout

Avoid:

* long explanations
* infographics
* large text blocks

The image should invite participation.

The explanation comes later.

---

# Step 1 — Quiz Post

Goal:

Generate engagement.

NOT signups.

NOT app installs.

NOT clicks.

Success metric:

Comments.

---

# Step 2 — Follow-Up Comment

Post after engagement starts.

Example:

💬 What's your answer and why?

Let's see how many future [RN / Teacher / CPA / Architect] get this one right.

Goal:

Increase discussion.

---

# Step 3 — Answer Reveal

Structure:

🎉 Thank you for joining today's challenge!

✅ Correct Answer

Short explanation

Relevant NoteLib note

Quiz challenge

Question for future topics

Goal:

Teach first.

Sell nothing.

---

# Step 4 — High Engagement Thank You Comment

Use when:

* engagement exceeds normal levels
* signups increase
* note copies increase

Purpose:

Build trust.

Reward participation.

Soft sell NoteLib naturally.

Never hard sell.

---
