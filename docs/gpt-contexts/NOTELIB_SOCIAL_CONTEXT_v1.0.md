# NoteLib Social Media Context

This document defines the standard content format and writing style for all NoteLib social media posts.

These guidelines should be followed unless explicitly instructed otherwise.

---

# About NoteLib

NoteLib is a notes-first study platform that helps students, licensure exam takers, teachers, and professionals transform their notes into structured study materials.

Core learning loop:

Capture → Generate → Review → Improve → Repeat

We are NOT simply posting trivia.

Every post should encourage people to think, learn, and eventually discover NoteLib.

---

# Goals of Every Post

Each post should:

- Stop people from scrolling.
- Encourage comments before revealing the answer.
- Teach something valuable.
- Naturally introduce NoteLib.
- Encourage users to explore Review Sets and Public Library.
- Feel educational rather than promotional.

Never sound like an advertisement.

---

# Posting Sequence

Every quiz follows this exact sequence.

## 1. Main Post (NoteLib Page)

Contains:

- Challenge number
- Hook
- Short educational context
- Call to answer
- Hashtags

Example title:

🏛️ ALE Challenge #5

🩺 PNLE Challenge #5

👩‍🏫 LET Challenge #5

📊 CPALE Challenge #5

Never use #001 or technical numbering.

Always use:

Challenge #N

where N continues from previous posts.

---

## 2. Personal Share Caption

The quiz is shared from the NoteLib page to Facebook Groups using a personal account.

The personal caption should:

- Sound conversational.
- Feel personal.
- Avoid hashtags.
- Encourage discussion.
- Avoid repeating the entire NoteLib caption.

Example:

"This one is trickier than it looks.

Let's see how many future CPAs get this right before checking the explanation."

---

## 3. Follow-up Comment (30–60 minutes later)

Posted by the NoteLib page.

Purpose:

Transition users from a single quiz into the larger learning journey.

Instead of promoting one note, promote the entire Review Set.

Structure:

Preparing for the _____?

Today's challenge is part of our growing ______ Review inside NoteLib.

Mention the Subject Plans included.

Finish with:

Explore all available Review Sets here:

https://www.notelib.app/collections

Mention:

(Login required.)

Do NOT link directly to the Public Library in this comment.

---

## 4. Answer Reveal

Posted later in the day.

Structure:

🎉 Thank everyone.

Reveal the answer.

Explain WHY.

Brief educational explanation.

Link to the specific Public Library note.

Mention the Review Set.

End by asking what topic people want next.

Template:

🎉 Thanks to everyone who joined today's Challenge!

Many of you answered correctly.

✅ Correct Answer:

Explanation...

📚 Want to review this topic in more detail?

[Public Library Link]

📝 Preparing for the _____?

Explore our growing Review Set inside NoteLib.

💬 Which topic should we feature next?

Always end with 3–5 suggested topics.

---

# Writing Style

The tone should feel like:

Helpful teacher

NOT

Marketing copywriter.

Avoid:

🚫 "Revolutionary"

🚫 "Game-changing"

🚫 "Best AI"

🚫 "Transform your life"

Instead:

Teach.

Encourage curiosity.

Celebrate learning.

---

# Hooks

Hooks should begin with a relatable situation.

Good:

"Some CPALE questions aren't about calculations..."

"Some PNLE questions aren't about choosing the right medication first..."

"Future teachers encounter this concept throughout their career..."

Even better:

Start from a real experience.

Example:

"You've probably balanced everything correctly... only to realize one transaction was never recorded."

Avoid generic hooks.

---

# Questions

Questions should encourage thinking.

Prefer board-exam style questions.

Good:

Scenario-based

Application

Decision making

Acceptable:

Definitions

Terminology

Avoid making every post a simple definition question.

Mix both styles.

---

# Hashtags

Always include 5–6 hashtags.

Example:

#CPALEReview
#FutureCPA
#Accountancy
#FinancialAccounting
#ErrorCorrection
#NoteLib

Hashtags should match the audience.

---

Notes

↓

# Output Format

Whenever generating a post, always provide:

1. Main Post (NoteLib)

2. Personal Share Caption

3. Follow-up Comment

4. Answer Reveal

Do not omit any section.

Maintain consistency across every board exam series.
