### Two-stage paired operating characteristics (computed before output)

**OWNER DECISION O1, 2026-11-12:** an exactly equivalent candidate's sampling-noise false-fail target is at most **20% per route**. **PROPOSED stage 1** uses the section-6 frozen paired sample: class A **30** cases per workflow, class B **12**. **PROPOSED stage 2 for tier 2, declared before output:** a blindly adjudicated candidate-only critical error in any workflow's stage-1 sample triggers a fresh, already frozen **30 paired cases in that same workflow stratum**, shared across the baseline, Luna and (only if justified) Sol comparisons; the original triggering case is excluded. The owner's Codex-plan blind reviewers independently score baseline and candidate against the same rubric, adjudicate disagreements blind, and never ask the API to judge itself. **PROPOSED confirmation FAIL:** at least **3 candidate-only confirmed critical cases** in that workflow's fresh reserve; fewer than **3** means the trigger is recorded and investigated but is not a confirmed route-blocking tier-2 pattern. A pooled tier-3 PASS never clears it. A baseline-and-candidate error on the same case is logged as pre-existing Quiz Quality debt and cannot trigger candidate-only confirmation. Missing reserve, scorer disagreement left unresolved or cap stop means INCONCLUSIVE. This predeclared pattern rule addresses sampling noise, not individual-learner safety; the monitoring hard trigger in section 9 still responds to one real incident.

**Exact method, reproducible without a helper file:** for baseline adverse rate `p_b`, candidate rate `p_c`, and arm association `ρ`, use a mixture of independent Bernoulli pairs and common-uniform pairs: `q11=(1−ρ)p_b p_c+ρ min(p_b,p_c)`, `qC=p_c−q11`, `qB=p_b−q11`, `q0=1−qC−qB`. Convolve the distribution of D from `{0:1}` across each primary case with `−1:qB, 0:q0, +1:qC`; sum masses above the route's tier-3 margin. For tier 2 let `q=qC`. A workflow with primary size `n` fails with `F_n=[1−(1−q)^n] × [Σ_(j=3)^30 C(30,j)q^j(1−q)^(30−j)]`; the route fails with `1−Π_workflows(1−F_n)`. This assumes independent fresh cases and workflows. **PROPOSED sensitivity grid:** baseline tier-2 rates **1%, 2%**; candidate increases **0, 5, 10, 15, 20 percentage points**; `ρ=0, .5, .8`.
