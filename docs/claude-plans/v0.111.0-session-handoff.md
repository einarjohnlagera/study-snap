## Lessons this cycle paid for, in order of cost

1. **⚠️ ASK WHAT IN THE FIXTURE WOULD HAVE TO CHANGE FOR THE TEST TO FAIL.** Three fixtures in one session
   were unfaithful **in the same direction**, each caught by MUTATION rather than review: a mocked
   repository whose derived query never executes (a dropped owner predicate passed the whole suite); a mock
   returning a **different** quiz id where production reuses the row (an id-keyed effect re-fetched on its
   own, so the assertion passed without the fix); and a round-trip fixture whose choice text did not
   actually look labelled (it survived the defect and the fix alike). **The common shape: the fixture
   differs from production on exactly the property under test.** Now recorded in `AGENTS.md`.
2. **A fix that names one path usually has more.** The choice-text defect was scoped as "deserialization"
   and was **four** rebuild paths; fixing only the named one would have changed nothing for session loads.
3. **An existing test that fails may be EXPIRED, not wrong.** Dating it settles which: the session-read
   label strip and the write-side sanitizer were added in the **same commit**, so the read half was a
   one-time repair made permanent — the origin of the bug. **Keep the half that has not expired.**
4. **Verify "X already does Y" against code BEFORE it reaches a prompt or a plan.** Three claims in
   `CLAUDE.md`'s header were stale this cycle.
5. **A cold agent found two regressions the fix itself introduced.** Both were worse than the limitation
   first written. Run one whenever production-data semantics change.
6. **Write the guard at the layer the defect lives at** — a `QuizItem`-level test passed while the utils
   class still rebuilt the wrong way.
7. Call `advisor()` **before** writing any Codex prompt, and again on the diff.
