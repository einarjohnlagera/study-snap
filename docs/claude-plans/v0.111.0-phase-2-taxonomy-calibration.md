## Naming — how these clear the rule

**The rule is *borrow real curriculum vocabulary; never invent*, and no value may equal a catalog
program name unless it is a board subject-area name.**

- All three names are the ALE Review Set's own Subject Plan titles, derived in
  `docs/gpt-contexts/archi-comprehensive-set-1.md:23` from **RA 9266**, which that document states
  defines the licensure-exam subject areas. **⚠️ That is a sourced provenance claim, NOT a claim of
  official blueprint fidelity** — per `v0.106.0`, the repo holds no board blueprint metadata and this
  release must not imply otherwise.
- **None equals a live catalog program name.** `Architecture`, `Landscape Architecture` and
  `Urban and Regional Planning` are programs; *Architectural Design*, *History and Theory of
  Architecture* and *Planning and Site Development* are not.
- **⚠️ `ARCHITECTURE` is NOT proposed, and this is why.** It equals the catalog program name exactly, it
  is not a subject area, and it would merge three demonstrably different treatments into one instruction.

## Draft `ADR-001` amendment (Phase 3 ships it, named / reasoned / dated)

> **Amended 2026-09-04 (`v0.111.0`).** The failure condition was a bare ratio of Domain Context values to
> course programs, recorded as `8:21`. **That denominator was stale: the live catalog holds 41 programs**,
> 20 added at runtime, so the real ratio was `8:41` = 0.195 and the condition was never close to tripping.
>
> **The ratio is demoted to a watch figure and is no longer the operative guard**, because a denominator
> that grows by curator action makes it **easier to satisfy by adding programs** — the exact failure this
> ADR's own note warns of (*"the catalog growing is not evidence for the taxonomy growing"*). The
> operative guard becomes, conjunctively:
>
> 1. **The naming rule.** No Domain Context may equal a live catalog program name unless it is a
>    documented subject area of a licensure curriculum. Names are borrowed from real curriculum
>    vocabulary and never invented.
> 2. **The composition matrix**, computed **against programs that exist**. A value serving exactly one
>    live program is presumed a program mirror and must be justified explicitly or deferred.
> 3. **Clause (a)'s note floor and clause (b)'s recorded owner decision**, unchanged.
>
> The ratio is still reported at every kickoff. **A value crossing 0.40 re-opens this amendment.**
