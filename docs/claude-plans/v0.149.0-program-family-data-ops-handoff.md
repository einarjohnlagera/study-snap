## Step 1 — create the two families

Neither `Health Sciences` nor `Accounting` exists in `program_families` today (verified: only `Engineering`
and `Education` exist). Create both via the existing endpoint (unchanged by this release):

```bash
curl -X POST https://notelib-backend-prod.onrender.com/api/course-program-catalog/families \
  -H "Authorization: Bearer <ADMIN_JWT>" \
  -H "Content-Type: application/json" \
  -d '{"name": "Health Sciences"}'

curl -X POST https://notelib-backend-prod.onrender.com/api/course-program-catalog/families \
  -H "Authorization: Bearer <ADMIN_JWT>" \
  -H "Content-Type: application/json" \
  -d '{"name": "Accounting"}'
```

Each response is a `ProgramFamilyResponse` — **record the returned `id` for each family**; you need both in
Step 2. (Equivalently, this can be done through the Admin Course/Program Catalog UI's "New Program Family"
field, which calls the same endpoint.)
