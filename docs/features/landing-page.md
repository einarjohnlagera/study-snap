# landing-page.md - NoteLib Feature Context

## Goal

The marketing landing page should explain NoteLib in one glance:

`Turn Notes Into Quizzes`

It should help students, board exam reviewees, and teachers understand what the product does, why quiz practice matters, and how to start.

## Structure

The landing page should include:

- Hero
- How It Works
- Who It's For
- Features Overview
- Pricing summary
- Final CTA

## Hero

Required copy:

- Title: `Turn Notes Into Quizzes`
- Subtitle: `Study Smarter. Not Harder.`
- Supporting text: `Generate summaries, key concepts, and practice quizzes from your notes in seconds.`
- Buttons:
  - `Get Started Free` -> signup
  - `Try Demo` -> demo study pack

## How It Works

Use a four-step explanation:

1. `Add Notes`
2. `Generate Study Pack`
3. `Practice`
4. `Improve`

The section should also visually communicate:

`Notes -> Summary -> Quiz -> Weak Concepts -> Practice`

## Who It's For

The landing page should call out the main audiences explicitly:

- Students
- Board Exam Reviewees
- Teachers

## Features

Position NoteLib as a notes-to-review-and-quiz workflow, not as an AI text tool.

Required feature cards:

- `Summaries`
- `Key Concepts`
- `Practice Quiz`
- `Weak Concept Insights`
- `Adaptive Practice`

## Pricing and Plans

- Landing page pricing should stay minimal and link to `/pricing`.
- Pricing must still use shared/backend-owned pricing surfaces.
- Messaging should highlight study outcomes and exam preparation, not raw technical features.

## SEO

Landing page metadata should use:

- title: `NoteLib — Turn Notes Into Quizzes`
- description should reflect summaries, key concepts, quizzes, and exam preparation value

Landing page structured data should use JSON-LD WebSite schema:

- `@type: WebSite`
- `name: NoteLib`
- `url: https://www.notelib.app`
- the same page description as the landing metadata

## UX Notes

- Keep the page mobile-friendly.
- Keep CTA paths explicit: signup and demo.
- Landing page should remain readable in both light and dark mode.
- Landing page should include footer links for:
  - `Privacy Policy`
  - `Terms of Service`
  - `Contact`
