# modals.md - NoteLib UI Context

## Goal

Shared app modals should stay readable, compact, and safe on mobile.

## Shared Rules

- modal content may scroll internally instead of forcing the whole page to scroll
- long modals should keep actions visible at the bottom
- mobile full-screen modals are acceptable when the content would otherwise feel cramped
- action hierarchy should stay clear:
  - secondary/dismissive action first
  - primary action second

## Suggestions Modal

- use a compact review layout
- show comparisons for `Your` value vs `AI` value
- use radios for field decisions
- use tag chips instead of long text buttons
- keep the footer visible on mobile while content scrolls above it
