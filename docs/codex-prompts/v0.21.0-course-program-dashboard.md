## TASK

Add a "Notes for [CourseProgram]" section to the Dashboard (all profile types) that shows up to 4 public notes matching the user's `courseProgram`, with a "See all in Public Library →" link and a modal prompt when `courseProgram` is not set.

## GOAL

Exam reviewers studying for PNLE, NMAT, or other board exams have no fast path to community notes for their specific track. Surfacing the top 4 relevant public notes on the Dashboard — with a link to the full filtered Public Library — makes the app feel immediately useful and personal, even for users with few personal notes.

## CONTEXT

### Decisions made

- Visible to **all four profile types**: STUDENT, BOARD_EXAM, TEACHER, PROFESSIONAL. Not profile-gated.
- Section placed **below Recent Notes** on the Dashboard.
- Data comes from **the existing `GET /notes/public` endpoint** with `courseProgram=<value>&size=4`. No new dashboard backend endpoint. Only backend change is adding an optional `size` param to the existing endpoint if it does not already exist.
- Section **hides entirely** when `courseProgram` is set but zero matching notes are found. No empty-state card in that case.
- When `courseProgram` is **not set**: section renders with a placeholder card and a modal CTA to prompt the user.
  - Modal title: "Set your Course/Program"
  - Modal body: "Set your Course/Program to see public notes tailored for your review track."
  - Primary CTA: "Go to Learner Profile" → navigates to `/profile#learning-profile`
  - Secondary CTA: "Cancel" → dismisses the modal
- Note cards use the **shared public library card layout** (same `SharedNoteCard` or equivalent used in Public Library).
- "See all in Public Library →" footer link navigates to `/public/library?courseProgram=<value>`.

### Existing code to understand before implementing

Read these files before making changes:

## ERROR STATES

- Network/API error fetching community notes → hide the section silently; do not show an error banner (this is a discovery addition, not critical content)
- `courseProgram` is set but returns 0 matching public notes → hide the section entirely (no empty-state card)
- `courseProgram` is null → show the placeholder card + modal prompt; the user can dismiss and continue using the dashboard normally
- User clicks "Go to Learner Profile" in modal → navigate to `/profile#learning-profile`; modal closes
- User clicks "Cancel" → modal closes; placeholder card remains (re-appears on next dashboard visit until courseProgram is set)
