## TASK

Add three server-rendered exam hub pages at `/exam/ale`, `/exam/pnle`, and `/exam/let` that surface curated public notes for each board exam, with SEO metadata, a conversion CTA, and a link to carry the exam context through to signup.

## GOAL

Give the ALE / PNLE / LET communities we market to a rich, browsable destination — instead of a single note — so that visitors from Facebook study group posts land on a page that says "here's everything for your board exam," and have a clear path to sign up and start practicing. This is the primary capture mechanism for v0.25.0: turning 2,613 anonymous public views into signed-up, activated users.

## CONTEXT

**Agreed decisions (from the v0.25.0 ROADMAP section):**
- Wave-1 launch set is exactly `ale`, `pnle`, `let`. No other exam slugs in this prompt.
- Route is `/exam/[slug]` — a new route family, separate from `/public/library/[subject]`.
- Pages are **public and anonymous-accessible** — no auth gate, no profile-type gate. Any visitor (logged out, any profile type) can view.
- Conversion gates live only on *actions* (quiz, copy) — not on reading or browsing the page. This rule is carried from v0.23.0 and must not be broken.
- The page is a **curated view over existing public notes** — not a new entity, not a new table, not a new content type. Reuse the existing public notes infrastructure.

**Curation / alias map:**
`courseProgram` is a free-text String in the backend. Exam slugs map to `courseProgram` value(s) as follows — match is case-insensitive, exact on the canonical value:

| Slug | courseProgram value(s) to include |
|---|---|
| `ale` | `"Architecture"` |
| `pnle` | `"Nursing"`, `"Medical – Surgical Nursing"` |
| `let` | `"Education"` |

This mapping must live in a single config location in the frontend (a constant/map, not scattered inline). It is the config alias layer; it is not a database table.

**Exam display names and descriptions (for SEO metadata and page header):**

| Slug | Full exam name | Short description |
|---|---|---|
| `ale` | Architect Licensure Examination (ALE) | Notes and practice quizzes for Philippine architecture board exam reviewers |
| `pnle` | Philippine Nurse Licensure Examination (PNLE) | Notes and practice quizzes for nursing board exam reviewers |
| `let` | Licensure Examination for Teachers (LET) | Notes and practice quizzes for Philippine teacher licensure exam reviewers |

**SSR pattern to reuse:** the existing `/public/library/[subject]/page.tsx` is the reference implementation — SSR, `revalidate = 300`, `buildPageMetadata`, structured data (`buildCollectionPageStructuredData`), featured/popular/recent discovery sections from `public-library-discovery`, note cards from the existing public library. Do not reinvent this pattern.

**Backend filtering:** `GET /notes/public` already accepts a `courseProgram` query param (see `NoteController` / `lib/api.ts`). For PNLE, pass multiple `courseProgram` values (or issue two requests and merge/deduplicate client-side — whichever is simpler without adding a new endpoint). Do not add a new backend endpoint unless the multi-value filter genuinely requires it.

**Conversion CTA:**
- Primary CTA on the exam page: `"Start preparing for the [Exam Name]"` → routes to `/auth?intent=exam&exam=[slug]` (or the existing signup path, preserving the exam context as a query param).
- On authenticated users: CTA becomes `"Browse [Exam] Notes"` → links to the filtered public library (`/public/library?courseProgram=[value]`).
- Reuse the existing `PublicSeoCopyCta` component pattern for the auth-gated action. The CTA must not gate anonymous *reading* — only the signup action.

**Exam context through signup:**
- The `exam` query param on the auth URL is the bridge to Track 2 (Goal + Milestones). For this prompt, the only requirement is that the param **survives through the signup redirect** — it does not need to pre-populate a goal yet (that's Track 2 scope). Store it the same way copy-intent is stored (short-lived cookie or `sessionStorage`), but do not implement goal-setting logic here.

**Navigation surface:**
- Add an `/exam` index page or entry point in the public footer (alongside "Public Library") so these pages are discoverable — a simple list of the wave-1 exams with their full names and a link each.
- Do NOT add exam hub links to the authenticated sidebar or dashboard — these are discovery/capture surfaces for anonymous visitors.

**Anti-drift rules from AGENTS.md that apply:**
- Public note pages must not persist anonymous session state.
- Analytics events use the `AnalyticsEventType` Java enum and the matching frontend constant. Add `EXAM_HUB_VIEWED` and `EXAM_HUB_CTA_CLICKED` to the enum before firing them. (Frontend-only analytics fire; no backend endpoint required.)
- Upgrade CTAs always go through `getUpgradeCtas(currentPlan)`. The exam page CTAs are not upgrade CTAs — they are conversion/signup CTAs — so this rule does not apply here.
- Use `globalThis` instead of `window`/`self`/`global` for any browser globals. ESLint enforces this.

**Explicitly OUT OF SCOPE for this prompt:**
- Goal-setting or pre-populating a learner goal from the exam context (Track 2 — separate prompt).
- Admin tagging or normalizing `courseProgram` values on existing notes.
- Wave-2 exam slugs (CPALE, Civil Engineering, Pharmacy, etc.).
- Any backend migration or new entity.
- Changes to the authenticated dashboard or library sidebar.
- The `/progress` report or ConceptHealth — do not touch.
- Any quiz generation or Study Pack logic.

## ERROR STATES

- **Exam slug not in the config map** (e.g. `/exam/unknown`) → 404 page — use Next.js `notFound()`. Do not render an empty or broken page.
- **Zero notes returned for an exam** → show an empty state: `"No [Exam Name] notes have been shared yet. Check back soon."` with a CTA to the main public library. Do not render a broken layout.
- **Fewer than 3 notes total** → featured/popular/recent sections gracefully collapse (show what exists, suppress empty sections). Do not show section headers with nothing beneath them.
- **Network error fetching notes** → server-side fetch failure should propagate as a Next.js error boundary (existing pattern); do not swallow silently.
- **Authenticated user on the exam page** → CTA changes to "Browse [Exam] Notes" linking to the filtered public library. The page is still fully functional; do not hide content from logged-in users.
