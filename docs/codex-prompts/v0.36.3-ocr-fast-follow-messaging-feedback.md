## TASK

Complete the OCR-disable story started in v0.36.2 (which added a backend-only kill-switch) by fixing a swallowed error message and giving all three OCR-gated flows a consistent, honest "temporarily unavailable" state with a lightweight feedback ask.

## GOAL

v0.36.2 added `studysnap.ocr.enabled` (env `OCR_ENABLED`) which gates all three Google Vision OCR call sites and throws `OcrDisabledException` (`OCR_DISABLED`, HTTP 503) with a user-readable message. The backend is fully correct and already shipped. This release is frontend-only work (plus one additive backend enum change) to make sure users actually see that message clearly, consistently, everywhere OCR is gated, and to capture whether they want the feature back — since disabling OCR is currently a cost/stability tradeoff we may reverse once revenue exists.
