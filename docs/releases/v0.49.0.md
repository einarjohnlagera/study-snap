# Release Notes: v0.49.0 — Progress Page: Private Library Links

## Release Theme

Fix Progress page navigation so personal "study this next" actions point at the learner's own Library instead of the public one.

## Polish & Fixes

- Progress page's per-subject Concept Mastery rows are now links, taking the learner to their private Library filtered to that subject.
- The "study this next" card's CTA (both the weakest-subject and course-program variants) now links to the private Library instead of Public Library, with copy corrected to match ("Study X in your Library" instead of "Browse X notes in the community") — the earlier copy and destination described a discovery action for what's meant to be a personal one.
- No backend change; Public Library is unchanged and remains the correct destination everywhere else it's used.
