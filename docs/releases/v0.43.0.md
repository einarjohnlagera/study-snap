# Release Notes: v0.43.0 — Companion Coach Experience

## Release Theme

Give the Review Set detail page a coach-voice presentation layer over the Companion and its already-loaded live signals — frontend-only, no new engine, no new backend.

## Key Features

**🧭 Today's Focus — one Coach card answers "what should I do next?"**
- Replaces the former countdown/primary-action/coach-intro surfaces with a single `TodaysFocusCard` at the top of the page: the resolved primary action, a `Continue Studying` CTA, a short pacing/encouragement sentence, and Quick Actions for due-concept review plus the existing terminal exam/builder action.
- Quick Actions render even in the "all caught up" state, so exam/builder access is never lost when no primary action remains.
- Coach encouragement is no longer gated on an authored Companion — collections without one still get a Today's Focus card; only the Companion card itself hides when empty.

**🗺️ Coach-voice Companion headings**
- The five Companion sections now show friendlier, still-descriptive headings (Overview → "🗺️ What this covers", Study Strategy → "🧭 How to study this", Common Mistakes → "⚠️ Avoid these traps", FAQ → "💬 Common questions", Resources → "📎 Extra resources").
- Same curator-authored text, same order — this is relabeling, not generation.

**📖 "View Full Guide" — the Companion becomes reference material, not the first thing you see**
- `CompanionDisplayCard` now collapses by default on every viewport; its header and toggle always show, and the five sections render only once expanded.
- Expanded sections render as icon-led sub-panels with restrained tinting, in the same authored order as before.

**📊 Progress card absorbs pacing data**
- `GoalWeeklyCountdownCard` is gone. Weeks/concepts remaining now render as a `countdown` line inside the compact Progress card when a target date is set; today's concept budget moved into Today's Focus's pacing sentence.
- The post-adopt target-date tip keeps its existing condition, dismissal, and analytics, now surfacing directly after Progress.

## Polish & Fixes

- Quick Actions now use the design system's `outline` button style instead of a stripped-down bare link and a ghost button, so they read as clickable actions, not plain text.
- Quick Actions and Continue Studying are full-width and stacked on mobile, matching-width side-by-side from `sm:` up — fixes mismatched-width wrapping on narrow screens.
- Fixed the Review Set/Study Plan detail title crumpling into a word-per-line column on narrow screens; the hero title and its actions now stack vertically by default and switch to a side-by-side row from `sm:` up.
- Anti-drift confirmed: this reorganization is frontend-only — no backend endpoint, persisted state, migration, Companion content-model change, section reorder, or change to Companion authoring/generation.
