# Release Notes: v0.139.0 — Reopened

## Release Theme
A prompt asking when you'd come back was only ever shown once, to almost nobody, and answering it made you worse off — this reopens the question and makes answering actually worth something.

## Key Features

**📅 Choosing your review days now changes what you receive**
- Picking review days used to do nothing you'd notice: the reminder email arrived either way, and choosing days quietly *narrowed* when it could reach you
- Now it's an upgrade — the nudge lands on the days you picked, and on each of them when there's something due, instead of once a week on a day you didn't choose
- Nobody loses reminders by ignoring the prompt: leave it alone and your weekly nudge continues exactly as before

**🔁 The question can be asked more than once**
- The prompt could previously appear only at the end of your very first study session, ever — one moment, gone forever if you were busy
- It can now appear after any completed session, up to three times, with a two-week gap between asks, then it stops for good
- Answering it either way retires it permanently

**🔕 We no longer ask when the answer can't matter**
- If you've turned due-concept reminders off, picking review days would change nothing at all — so you're no longer asked
- The prompt's description of what you already receive is now accurate rather than aspirational

**🔍 We can now tell "ignored" from "declined"**
- Closing the prompt or navigating away previously recorded nothing, so a prompt nobody engaged with looked identical to one nobody was shown
- Abandonment is now recorded, which is what makes the next read of this feature meaningful rather than guesswork

## Polish & Fixes
- Reminder emails opened from a digest link now attach correctly to your account instead of being logged anonymously
- Corrected the Settings copy for due-concept reminders, which still described a weekly-only schedule after the cadence changed
- Fixed a case where a browser configured to block site data could record a dismissal for a prompt that was never displayed
- A deploy-verification script now reports a confirmed mismatch as a mismatch, rather than as "could not check"
- Documented the review-commitment prompt, which had never appeared in the feature docs despite being the only place review days are collected
