# Release Notes: v0.84.0 — Public Explore

## Release Theme
Someone who has never signed up can now browse what NoteLib has — at the same address a member uses, and reachable from the places that used to send them elsewhere.

## Key Features

**🌏 Explore is open to everyone**
- `/explore` previously bounced signed-out visitors to the login page before showing anything
- It now renders the same discovery page for visitors and members — the Official Study Plans catalog and the community notes library, side by side
- Members see no change at all: same tabs, same default, same behaviour

**🧭 The main navigation points at Explore**
- The public navigation now names **Explore** where it used to name Public Library
- The Exam Hubs pages send you to Explore too, keeping whatever course or program you were looking at
- The Public Library itself is unchanged and still has its own address — it is one of the places Explore draws from, not something that was removed

**🔖 An adoption you start before signing up is not lost**
- Click Adopt on a study plan as a visitor, and it is remembered through sign-up, email verification, and onboarding
- The plan is then added for you automatically, and you land straight on it
- The sign-up screen now tells you that is what will happen, instead of showing generic copy
- If your browser blocks the cookie that remembers it, you are told to pick the plan again rather than left waiting for something that will never arrive
- If the plan is withdrawn while you are signing up, you return to Explore with a plain notice instead of an error

**🔍 Explore can be found by search engines**
- Real page title, description, social preview, and structured data, plus a sitemap entry
- The Public Library keeps its own identity — the two pages describe different things rather than competing

## Polish & Fixes
- Signed-out visitors now see "Official Study Plans" instead of the generic "Official Collections", which had been showing by accident
- Wrote the first feature documentation for Explore, which had none despite the page being live since v0.67.0
- Hardened the sign-up handoff so an adoption can never run twice, cannot fire before your account is confirmed, and will not pull you away from a note you have started writing
- The "plan unavailable" notice no longer claims a reason it cannot know, and now uses your own vocabulary for plans
- Adoptions started from the browse-all list now record where they came from, so the two lists are measured the same way
