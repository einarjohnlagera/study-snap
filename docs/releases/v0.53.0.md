# Release Notes: v0.53.0 — SEO Discoverability: Exam Hub Depth & Organic Attribution

## Release Theme

Closes the highest-leverage fixable gaps from the organic-search strategy session — exam hubs were hiding most of their real content behind an 18-card cap, shipping no structured data proving that depth existed, and giving no visibility into whether organic search traffic was showing up at all. Pure new-user acquisition work: getting people who don't know NoteLib exists into the funnel.

## Key Features

**📚 Exam Hub Subject Breakdown & Full-Inventory Path**
- Each exam hub now shows a "Browse by Subject" section with real per-subject note counts, linking to the existing subject-landing pages.
- A new "More {Exam} Notes" section lists every note not already surfaced in Featured/Most Popular/Recently Added, so a 63-note bucket is no longer capped at 18 visible cards.
- Adapted from the original plan: instead of a single "Browse all {N} notes →" link (which would under-represent hubs mapped to multiple course/programs, like PNLE), the remaining notes render directly on the hub page — putting more crawlable content on the page being optimized.

**🔗 `ItemList` Structured Data on Exam Hubs**
- `buildCollectionPageStructuredData` now accepts an optional `items` list and emits a `mainEntity: ItemList` of every member note (name + canonical URL) when provided.
- Exam hubs pass their full, uncapped note list, so the `CollectionPage` schema now asserts real membership instead of an empty collection.

**📈 Organic-Landing Attribution**
- Every page view through the shared `AnalyticsPageViewTracker` now carries a coarse, privacy-preserving `referrerSource` bucket (`google`, `other-search`, `social`, or `direct`) — no raw referrer URLs stored, no new page-view call sites touched.
- Admin gets a new Organic Landing Attribution panel: an eight-week view of landings by week and surface, plus the Google Exam Hub landing → signup-CTA click ratio.
- No new analytics event types, migrations, or Search Console dependency.

## Polish & Fixes

- Audit fix: corrected two `globalThis` convention violations (`referrer-source.ts`, `page-view-tracker.tsx`) introduced during implementation.
- Audit fix: restored `RELEASES.md`'s Planned Scope bullet list and `ROADMAP.md`'s section heading, both of which had been overwritten instead of preserved.
- Pre-signoff check verified `getServerPublicNotes()` returns the full, unbounded note list (no implicit `size` cap) — confirming P4's "More Notes" section and P5's `ItemList` both reflect a hub's true note count rather than silently truncating at the public-list API's explicit-size clamp.
