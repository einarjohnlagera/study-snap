# Release Notes: v0.20.0 — Conversion & Re-engagement

## Release Theme
"Conversion & Re-engagement" — close the account security gaps that block returning users, give admins a targeted re-engagement tool, enrich AI-generated summaries with structured insight, and polish the public profile into a cleaner learning portfolio.

## Key Features

**🔑 Forgot Password**
- Users can request a password reset link from `/forgot-password` without needing to log in
- Reset tokens are valid for 60 minutes, stored as SHA-256 hashes — raw token is never persisted
- Successful reset re-hashes the password, revokes all active sessions via `tokenVersion` bump, clears account lockout fields, and backfills `emailVerifiedAt` if missing
- No user enumeration — all responses return the same generic message regardless of whether the email exists
- `/reset-password` page handles three states: form, invalid token, and expired token (with "Request a new link" CTA)
- "Forgot password?" link added to the login form; green success banner on return to `/auth`

**🔒 Change Password**
- Password-enabled users can change their password from Profile > Sign-in Methods
- Validates the current password before accepting the new one
- New password minimum: 8 characters, enforced on both client and server
- Revokes all sessions on other devices via `tokenVersion` bump on success

**📋 Study Pack Summary Enrichment**
- AI-generated summaries now include optional structured sections when the content supports them: a compact markdown comparison table (for notes covering comparable concepts) and a Common Misconceptions paragraph (1–3 common points of confusion)
- Summary word limit raised from 120 to 200 words
- Frontend renders summaries via `react-markdown` + `remark-gfm` across all study pack surfaces: note detail, shared study pack, public library note page, onboarding preview, demo, and admin study view
- Preview-only surfaces (public library listing card) use a plain-text extractor to avoid rendering raw pipe characters

**📧 Re-engagement Campaign (Admin)**
- One-time admin-initiated email campaign targeting users inactive for 30+ days who signed up before v0.19.0
- Three profile-segmented variants: student/generic, professional, and teacher
- Available at `/admin/campaigns` — shows eligible user count, last-sent date, and total recipients
- Sends up to 100 emails per invocation (Resend free tier); `email_log` deduplication ensures already-sent users are always skipped on re-runs

## Polish & Fixes
- Quiz header now shows note title below the mode label in Quick Review and Challenge Quiz running bars
- Removed redundant `N.` number prefix from question text in Quick Review (progress counter already shows position)
- Long Exam sources banner lists all note titles in the running phase for multi-note sessions, matching Board Exam's existing treatment
- Public profile note cards capped at 8 (sorted by copies → views → shares) so the page reads as a portfolio rather than a feed
- Note card tags capped at 3 with overflow count on the public profile
- Copying "Share Profile" link now fires a `PUBLIC_PROFILE_SHARED` analytics event and surfaces a "Profile Shares" header metric (hidden when zero)
- Study pack generation: concept duplicate check demoted from a hard failure to a warn — over-strict normalization was causing false positives and burning double LLM tokens on retry
- Study pack generation retry log upgraded from INFO to WARN and now includes the rejection reason for easier production diagnosis
