# Release Notes: v0.36.0 — Readiness/Progress Merge

## Release Theme

Make Progress the single canonical answer to "how ready am I?" across all subjects and individual study plans, with one readiness vocabulary and no new mastery signal.

## Key Features

**📊 Unified Progress Surface**
- `/progress` now handles both all-subject progress and plan-scoped readiness through `?collectionId={id}`.
- An in-page leaf-plan picker lets learners switch between `All subjects` and one saved plan without a full page reload.
- Plan detail "Check readiness" links now deep-link into `/progress` instead of a separate readiness route.

**🧭 Shared Readiness Vocabulary**
- Progress, plan readiness, and note readiness now use the same labels: `ready`, `mastered`, `due`, and `not started`.
- Subject rows reuse the shared readiness bars so `70%` becomes `70% ready`, never-practiced subjects show `Not started`, and due counts use `N due`.

**🏗️ Goal Builder Entry**
- Brand-new empty plans can now become Goal-shaped plans from the Builder by choosing `Add Subject Plan`.
- Empty plans still support the flat leaf path with `Add notes`; once notes exist, the Goal option is hidden to match backend hierarchy rules.
- Leaf and Goal detail pages now share a single top-level `Build` entry point.

## Polish & Fixes

- Removed the old `/collections/[id]/readiness` frontend route; the backend `GET /collections/{id}/readiness` endpoint remains the scoped data source.
- Preserved the `Progress` nav label and `My Progress` page title while merging the surfaces.
- Kept readiness signal available to Free users and per-concept timing details gated to PLUS/PRO.
- Removed duplicated Study Pack-ready status from plan Progress surfaces, keeping Study Pack coverage as a caveat only when plan notes are missing Study Packs.
- Prevented the empty-plan-to-Goal Builder transition from flashing the generic `Could not load builder` error while Goal data is still loading.
- Moved `Add Subject Plan` to the Builder page header for undecided empty plans and normalized Subject Plan casing across Builder controls.
- Removed the redundant Notes-card `Edit` builder link from leaf plan detail; the `...` menu Edit action remains metadata-only.
