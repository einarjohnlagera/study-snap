# Release Notes: v0.75.0 — Authoring by Inference

## Release Theme
Stop asking curators to compose three orthogonal metadata axes by hand — the authoring surface now infers what it can from the Review Set and the author's own profile, and asks them to confirm rather than compose.

## Key Features

**📐 Review Sets carry an authored depth**
- A Review Set can now record the educational depth its notes are written at, set and cleared from the collection editor
- Child subject plans inherit the nearest ancestor's depth, so a curator tags a Board Review set once and everything beneath it follows
- Adopting an Official Review Set carries its depth across, so adopters get the same head start
- No depth anywhere in the chain means no suggestion at all — never a silent default

**📚 Bulk-generate authors straight into a Review Set**
- An optional Review Set selector on Bulk Generate, offering only sets that can actually hold notes
- Choosing one pre-fills the Authored Depth for the batch from that set's own or inherited depth
- Generated notes are added to the chosen set when the batch finishes, in order — replacing the manual pass of adding twenty freshly generated notes by hand
- Partial failures add only the notes that succeeded, and a note deleted mid-batch no longer costs the rest their place in the set
- The selector is labelled in each profile's own vocabulary — a teacher sees "Lesson Plan", not a term the rest of their app never uses

**✏️ Authored Depth, pre-filled and renamed**
- Curators creating a note now start from their own profile depth instead of an empty field
- A Review Set outranks the profile, and an explicit choice outranks both — including a deliberate "leave it blank"
- "Note Learner Level" is now **Authored Depth** across the Note Editor, Note Detail, and Bulk Generate
- Learners are deliberately untouched: the depth field is a curator control, so nothing is written on their behalf

## Polish & Fixes
- Retrying a failed bulk batch now restores the Review Set it was queued into, so the retry reproduces the batch instead of quietly dropping it
- Retrying a batch that deliberately had no depth set no longer inherits one, so retried notes match the batch they replace
- Switching or clearing the Review Set re-resolves the depth instead of leaving the previous set's value behind
- The empty depth and domain options on Bulk Generate now read "Automatic — based on the reader" / "— based on the program", matching the other two authoring surfaces
- Collection depth is no longer exposed on the public collection endpoint, where a published child under a private parent could surface its parent's value
- Corrected `ADR-001`'s sequencing section, which had blocked this work on two prerequisites that were already satisfied — one of them four releases earlier
- Documented the `?noteAccepting=true` collection listing contract, including the two fields whose meaning differs in that mode
- Backlog Index rows are now cited by title rather than line number, which kickoff commits shift every release
