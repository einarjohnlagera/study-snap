# Release Notes: v0.88.0 — Section Authoring

## Release Theme
Sections in a Subject Plan can finally be created, and notes can arrive already in one.

## Key Features

**📚 Create a section without leaving the Builder**
- A per-note **Section** control replaces the old Move dropdown: pick an existing section, or type a new one to create it
- Typing a case or spacing variant snaps onto the section that already exists, so `algebra` joins `Algebra` instead of minting a second one that looks identical
- Renaming a section into another one asks first, then combines them in a single write

**🗂️ Notes arrive already sectioned**
- Bulk Generate takes an optional **Section**, pre-filled from the batch subject and fully editable — so generating the Algebra batch creates the Algebra section as a side effect
- The field appears only when a target plan is selected, and stops following the subject the moment you edit it
- An over-long or reserved value is refused on the field before the batch is queued — no generation runs, no quota is spent

**⚡ Section a whole plan in one action**
- **Group by subject** assigns every note's section from the subject it already carries, after a confirmation naming the number of notes it will overwrite
- Turns roughly 230 clicks on a 77-note plan into one
- Disabled when no note has a subject, so it can never silently clear a plan

**🧭 A 77-note plan you can actually navigate**
- Sections now collapse at every screen size, not only on mobile — the desktop page was previously an uncollapsible wall of cards
- Notes without a section sit in a clearly named **Not in a section** group, pinned last, which disappears entirely when everything is sectioned
- Teachers see **Part** instead of **Section**, so it no longer collides with a class cohort

## Polish & Fixes
- Subject and course/program are now capped to match what the database actually stores, so an over-long value is refused with a clear message instead of failing mid-save
- An over-long batch subject is caught before the AI runs, so a rejected batch no longer costs a generation
- When the AI itself returns an over-long subject, it is shortened rather than discarding a Study Pack you already paid for
- Section names are capped at 120 characters in the Builder, matching the server, instead of accepting 150 and failing on save
- The section field no longer saves while you are still typing in it, which previously created a section from a half-typed name and moved focus away mid-word
- Pasting a long section name now stops at the limit on screen rather than displaying more than it saves
- Fixed two notes-without-a-section groups appearing with the same name and the same readiness percentage
- Removed a "drag notes here" prompt on empty sections that could never be reached
- Section assignment is now recorded, so the case for bulk editing tools can be judged on evidence
