# Release Notes: v0.101.0 — Language and Observability

## Release Theme

The product now describes what it does for you rather than what technology produces it — and it can finally see the moment a note becomes part of a plan.

## Key Features

**📊 The quiz meter says what it actually counts**
- The monthly meter is now called **Quiz generations**, and its description is complete for the first time
- It previously said "Challenge Quiz sessions and quizzes you make for someone", which left out Board Exam — every Board Exam start has always spent a unit of this allowance without saying so
- It now reads: *"Quiz sessions we generate for you, plus quizzes you make for someone. Board Exam sessions also count against their own allowance."*
- The wording names no individual mode on purpose, so it stays true as more kinds of session start using the same allowance

**💰 Pricing copy stopped being collateral damage**
- The meter label and the pricing pages were sharing a single piece of text, so renaming one silently rewrote the other
- They are now separate: the meter names what is being counted, while pricing counts what you get — "20 generated quizzes / month"
- Neither surface reads like the other's, and a test now stops them being merged back together

**✍️ Copy describes the outcome, not the machinery**
- Sixteen learner-facing places that advertised "AI" now say what you actually get: a title written for you, a suggested subject, a domain that shapes how a note is written
- The suggestions screen after generation is now simply **Suggestions**, with **Suggested Title**, **Suggested Subject** and **Suggested Tags** — more accurate, since these are proposals you accept rather than output you receive
- Safety and disclosure wording is untouched by design: the privacy policy, the terms, "verify calculations" on computed working, and the warning shown before you share a quiz all stay exactly as they were

**🔍 Adding a note to a plan is finally measurable**
- The product now records the single moment a learner decides a note belongs in a Review Set — the transition the whole retention question rests on, and one nothing has ever measured
- Re-adding a note already in the set records nothing, so the signal counts decisions rather than repeat clicks
- Notes added automatically during bulk authoring are tagged separately, so curator work never gets mistaken for a learner's choice

## Polish & Fixes

- The explanation under Domain Context no longer says it "tells the AI how to write it"; it says it shapes how the note is written, while the programs decide who finds it
- Three warning messages about notes spanning several programs still mentioned the AI and were missed by the previous release's reword; they are corrected now
- The landing page comparison column is now "Generic chat tools", and the headline claim leads with what NoteLib does rather than what it is not
- The Study Packs help guide now explains the feature rather than the technology behind it
- Corrected an internal note claiming the Settings usage meter cannot show a description — it can, and does
- The suggestion screen kept its existing capitalisation rather than adopting a new style that would have clashed with the unchanged options beside it
