# Release Notes: v0.42.1 — Companion & Progress Polish

## Release Theme

Small UX fixes surfaced from using v0.42.0 in practice — no new features, no backend changes.

## Key Features

**📋 One Readiness card, not two**
- The Review Set detail page's readiness card and its "View full progress"/"Review due concepts" row now render as a single card instead of two visually separate elements.
- `ReadinessSummary` gains an optional `footer` slot, rendered inside the existing card in its compact variant — no new component, no layout duplication.

**🔗 Progress backlink returns to where you came from**
- `/progress?collectionId={id}` now returns to the originating collection (with a profile-aware label) when reached via that collection's "View full progress" link, instead of always showing "Dashboard".
- Keyed off the URL's `collectionId` param rather than live selection state, so a plain nav-in that defaults to the user's Primary Review Set still shows "Dashboard".

## Polish & Fixes

- Considered and declined: turning collection cards' course/program metadata into a badge — stays plain text per the existing badge-classification rule (identity/state get badges, metadata does not).
