# Release Notes: v0.113.0 — Session Anchoring

## Release Theme
A quiz session is now keyed on what it is actually about — a note or a whole Study Plan — so practising across a plan no longer collides with practising a single note inside it.

## Key Features

**🎯 Practice across a plan without fighting your own sessions**
- Three kinds of session used to share one anchor slot, so starting whole-plan remediation could silently hand you a single-note session instead
- A plan-scoped session is now anchored on the plan itself, and you can hold one alongside an active note-scoped session on a pack inside that plan
- Starting plan-wide practice no longer refuses just because the notes you are weakest on already have their own sessions open

**📊 Plan-wide practice now counts toward your Study Plan progress**
- A completed plan-scoped session credits every note it drew questions from, so the progress bar advances
- Previously it credited a single note regardless of how many were practised
- Those sessions now also appear in each participating note's Recent Sessions

**🗂️ Deleting a Study Plan keeps the practice you did against it**
- Completed and forfeited sessions survive the plan being deleted, instead of being removed with it
- They stay reachable through the notes they covered
- Unfinished sessions on that plan are cleared, since they have nowhere left to resume

**🔗 A plan-scoped session can be opened and reloaded**
- Plan-wide practice is addressed by its own session, so it can be entered from the plan page, resumed from the dashboard, and survives a refresh
- Previously a plan-scoped session had no address of its own to return to

## Polish & Fixes
- The dashboard *Continue Studying* card keeps its entry attribution for note-scoped Adaptive Practice resumes, so dashboard-originated practice is no longer under-recorded.
- A finished Adaptive Practice session is no longer offered as resumable; reloading one no longer shows a start button that leads nowhere.
- The Adaptive Practice session read now requires a verified email, matching the equivalent note-addressed read.
- The weak-concept reminder email stops asking you to revisit concepts you already cleared through plan-wide practice, matched per source note rather than by concept name.
- Concept attribution fails loudly rather than recording practice against an empty key when a question's source cannot be resolved.
- Plan deletion no longer removes the concept history that explains a learner's weak areas while deleting the sessions that produced it.
