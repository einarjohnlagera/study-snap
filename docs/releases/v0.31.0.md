# Release Notes: v0.31.0 — Adoptable Study Plans

## Release Theme
Most learners don't want to assemble a study plan note-by-note — they want a ready-made, structured plan for their goal. This release lets a learner **adopt** a curated, ordered study plan in one tap: a snapshot copy of the plan's public notes (and their Study Packs) into the learner's own library, where the full learning loop already runs.

## Key Features

**📚 One-Tap Adoptable Study Plans**
- Admin-published `NoteCollection` records now act as public, course/program-targeted study plans. Learners see a matching plan on their Dashboard and tap **Start this plan**.
- Adopt = **snapshot copy**, not a live link: NoteLib copies the plan's public notes plus their linked Study Packs into a private personal collection, preserving curated order, with `sourcePlanId` lineage and idempotency (re-adopt returns the existing plan, never duplicates).
- Adoption bills **no quota** (it is a copy, not a generation), reuses the existing public-note copy path, and fires `STUDY_PLAN_ADOPTED`. The copy fan-out is per-item isolated and race-safe, so one bad note never sinks the adopt.

**🌐 Admin Publishing Flow**
- Admins publish a plan from a visibility control that doubles as the **Published/Private badge** below the plan title (Notion-style): clicking it opens the publish modal.
- The publish modal targets the plan to a learner audience via a **constrained Course/Program combobox** (locked to known buckets, never freetext — a value that matches no learner would silently surface to nobody).
- Because adopters copy the plan's notes, the modal flags any still-private notes with per-row `Private` badges and a one-tap **Make N public**; publishing is blocked until every note is public, matching the backend rule.

## Polish & Fixes
- Study Plan Detail header reworked: `Build Exam` (shortened from `Build exam from this {singular}`) sits at the bottom-left of the header card via a new `PageHeader` footer slot; the published/private badge moves below the title for Note Detail parity, leaving `⋯` alone top-right; context-menu labels shortened to `Edit` / `Delete`; the boilerplate header description is dropped when there's no author-written one.
- Publish modal redesign: status pill, an **in-flow combobox dropdown** (new `SuggestionCombobox` `inlineDropdown` option) that no longer clips against the modal footer, a single close affordance, and a retry when course/program suggestions fail to load.
- Combobox fixes: the public/private Library filter comboboxes no longer wipe the current selection on focus (you can edit it instead of retyping), and an inline clear (`×`) button was added across the shared `SuggestionCombobox` and both Library filters.
- Sheet modals now slide up from the bottom on mobile and scale-fade on desktop (`motion-sheet-panel`).
- Adopted-plan and copy flows reflected across the collections, public-notes, public-library, dashboard, and my-progress feature docs; added a frontend anti-drift rule that taxonomy fields (course/program, learner level, subject, audience) must use a shared combobox, never freetext.
