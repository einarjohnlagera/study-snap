# Release Notes: v0.47.0 — Conversion Audit Tier 4: Cleanup Batch

## Release Theme

A batch of small clarity and polish fixes across public discovery, onboarding, and Dashboard — clearer copy where it was ambiguous or missing, and a couple of previously-silent empty states now replaced with helpful guidance.

## Key Features

**🧑‍🎓 Author Identity on Public Notes**
- Public note pages now show a compact author card with the creator's bio and public note count, linking through to their full profile — falling back gracefully when a profile is private.
- Breadcrumb navigation (Home → Public Library → Subject → Note) makes it easier to see where you are and get back.

**🧭 Clearer Discovery Guidance**
- Dashboard's recommended-plan section now shows a helpful prompt to set your course or program instead of silently showing nothing when it's missing.
- "Adopted" plan status is now labeled consistently everywhere you see it, across Collections, Collection Detail, and Dashboard.

## Polish & Fixes

- Tightened mobile spacing on the landing hero and pricing preview.
- Harmonized "how it works" messaging between the landing page and the dedicated walkthrough page; clarified the AI Critique guide's title so it reads as part of Interview Practice rather than a standalone feature.
- Added a note showing which region's pricing you're seeing.
- Signup now restates the specific reason you're signing up — saving a note, or continuing from a study guide — instead of always showing generic copy.
- Non-owner public profiles now include a closing link to browse more of that creator's notes.
- Course/Program now displays as plain text instead of a badge on note cards, matching how other metadata is styled elsewhere.
- Onboarding's recommended-plan card is now clearly marked optional; the Dashboard learner-level prompt no longer implies your level is unset; onboarding's final step now confirms your Study Pack is saved to your library.
- Documentation and search-engine metadata corrections across Public Library and Learn.

## Known Limitations

None specific to this release.
