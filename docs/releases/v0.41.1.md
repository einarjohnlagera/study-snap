# Release Notes: v0.41.1 — Review Set Detail Page: This-Set Study Dashboard

## Release Theme

Re-compose the Review Set detail page so it orients the learner — "what should I do next, in this Review Set?" — instead of introducing the set as a collection screen, scoped narrowly to this one Review Set (the cross-set "which set" job stays with the Dashboard).

## Key Features

**🎯 This-Set Study Dashboard**
- Goal and Leaf detail now render as Identity → Current Journey → Primary Action → Readiness → Guidance → Subject Plans/Notes → Progress, replacing the old metadata-forward hero.
- The three previously-competing next-action surfaces (next-in-plan card, continue banner, mastery-step card) resolve into one free-tier-safe `Continue` action. The terminal exam CTA (e.g. `Take the Board Exam`) now renders as a visually secondary, stacked action rather than a same-weight peer button.
- Primary is now a card-level accent treatment (left border + tinted background, plain caption text with a Star icon) instead of a badge pill, on both the detail hero and the `/collections` list card.
- Authoring controls (Build, Edit, Publish, Manage Companion, Set/Remove primary, Delete) are grouped into a compact `⋯` menu + Build button in the hero's top-right corner — present, but visually minimal, so they never compete with the learner's study flow.
- The existing Learning Companion display now anchors the new Guidance tier, directly after Readiness — a durable home for future Companion growth (Resources, Ask Companion) without another redesign.

## Polish & Fixes

- Migrated the `/collections` list card's Primary badge to the same card-level accent treatment as the detail hero, closing the one remaining surface still on the old pill styling.
- Documented a badge-classification rule (identity vs. state vs. metadata; metadata is never a badge) in `docs/features/collections.md` so future Guided Learning additions get checked against it before reaching for a pill.
- Added test coverage for the Goal view's Primary Action fallback (resolves to the first child Subject Plan when there's no continue/next-note action) and for label resolution on the new hero text under the BOARD_EXAM profile.
- Refined the authoring-controls placement once post-implementation: an initial pass built a dedicated "Manage this Review Set" card at the bottom of the page, which a follow-up review found had over-corrected into interrupting the learner's scroll; controls now live as compact chrome in the hero corner instead.
