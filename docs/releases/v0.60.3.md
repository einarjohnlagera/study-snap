# Release Notes: v0.60.3 — Challenge Quiz Shaping

## Release Theme

Shape Challenge Quiz's pacing and correctness: a score-adaptive starting question count, a fix for Redo Missed Questions silently resuming the wrong session, and a guard against submitting with questions left unanswered.

## Key Features

**📈 Adaptive Initial Question Count**
- Challenge Quiz sessions now start with 10, 12, or 15 questions based on the learner's last Quick Review score, instead of a flat 5 — reducing mid-session "+5 Questions" click friction.
- Board Exam Mode and Redo Missed Questions keep their existing fixed counts; the session timer scales correctly with the new adaptive count.

**↩️ Redo Missed Questions Session-Matching Fix**
- Redo Missed Questions could silently resume an unrelated, stale in-progress Challenge Quiz session instead of starting a fresh session sourced only from missed questions.
- A dedicated session-state provenance marker now lets the app tell a genuine prior redo session apart from a stale ordinary one — the latter is forfeited and replaced with a correctly-scoped fresh redo session.

**⚠️ Incomplete-Submission Guard**
- Manual Submit on Challenge Quiz used to finalize immediately with no warning about unanswered questions.
- A lightweight confirmation now appears on manual submit only — go back to the first unanswered question, or submit anyway with today's existing incomplete-scoring behavior. Timeout-triggered auto-submit is unaffected.

## Polish & Fixes

- Routed to Codex as a single bundled prompt/PR covering all three items, audited before commit — the audit caught and fixed a race window where a concurrent Redo Missed Questions request could misidentify and forfeit another still-generating redo session.

## Known Limitations / Deferred

- **Onboarding coverage-gap capture, scoped alongside these three items, was deferred rather than shipped.** Its own kickoff gate required confirming effectively-zero STUDENT-profile presence in the Diagnostic Read's signup-surge measurement cohort, to avoid contaminating that read's funnel data mid-measurement. The gate query (run 2026-07-28) found real presence (2/29, 6.9%), failing the bar. The design is unchanged and still valid — it now tracks as its own Backlog Index item in `docs/product/ROADMAP.md`, gated on the Diagnostic Read closing (~2026-08-06) and a clean re-run of the gate query.
