# Release Notes: v0.44.0 — Conversion & Retention Polish

## Release Theme

Close the highest-confidence findings from a 7-session conversion/retention UX audit — starting with a universal defect that intercepted every copy-on-signup user before they ever saw the note that brought them in, then working through landing, pricing, public notes, onboarding, and Public Library, and finally a second slice (Tier 2) surfacing due-concept signals, pre-adoption trust, and pass-renewal reminders.

## Key Features

**🔓 Copy-on-Signup Onboarding-Intercept Fix**
- Fixed a confirmed universal defect where a newly verified public-note copier was redirected to `/onboarding` before their copied note or auto-launched Quick Review could render — the exact conversion mechanic the acquisition channel depends on.
- Successful copy-on-signup now carries a distinct local completion marker that preserves the copied-note landing, then collects Profile Type, Learner Level, Course/Program, and optional Board Exam date through a dismissible Dashboard card.
- A pre-signoff pressure test found the initial fix only covered the email-verification signup path; the independently implemented Google OAuth path had the same bug and was closed with the same marker call, plus a regression test.

**🏠 Landing & Acquisition Polish**
- Rewrote the hero headline and nearby Board Exam Mode callout to align with NoteLib's actual notes-to-quizzes promise, without misrepresenting the adjacent Study Pack screenshot.
- Target User panels now link to their matching Learn categories, with the Board Exam card also linking to Exam Hubs; zero-note Exam Hubs keep a signup-intent path instead of dead-ending.
- The landing page now shows a live public-note count fetched server-side, rendered only when the count is valid — no estimated or testimonial claims.

**💳 Pricing Trust & Instrumentation**
- The no-auto-charge reassurance now sits directly below every paid CTA (pricing cards, paywall modal, Settings plan cards), not just in the footer.
- Near-limit quota banners and the shared Study Pack-limit modal emit one-shot, source-tagged view and upgrade-click events across all entry surfaces (Study Pack, note generation, OCR), extending the existing `UPGRADE_CLICKED`-with-source pattern.

**📚 Public Library & Study Plan Discovery**
- Public Library now defaults to the existing decay-adjusted Recommended ranking when no sort is specified; a Course/Program filter silently bridges to a matching Official Study Plan when one exists.
- The Course/Program helper card surfaces the six highest-count canonical programs as one-tap chips.
- Every public plan card now offers an unauthenticated, read-only preview (`GET /collections/public/{id}`) showing real note titles, subjects, course/program, estimated study time, and a live practice-ready ratio before adoption.
- Public plan responses now return a live `readyCount`, shown as plain-text metadata ("N of M notes practice-ready") on the Published Plans page — zero and fully-ready inventory both render honestly, no hiding logic.

**🎯 Due-Concepts Dashboard Visibility**
- Dashboard's Today Focus card now surfaces real, deterministic due concepts when no session is resumable, each linked to its source note.
- Due/mastery status on the Key Concepts tab is now visible to every plan tier instead of falling back to "Not started" — visibility only, Adaptive Practice feature access and quotas are unchanged.

**💰 Pass-Expiry Renewal Notice**
- Active Plus and Pro users now see a Settings renewal notice in the same 7-day (6–8 day) and 1-day windows as the existing email cadence, dismissible per pass and stage, routed through the existing hosted checkout handler. Copy stays one-time-pass, no-auto-charge.

**🧠 ConceptHealth Tracking for Quick Review (backend)**
- Completed Quick Review sessions now write the same per-user, per-Study-Pack `concept_health` records already used by Challenge Quiz and Adaptive Practice, closing a gap where plain Quick Review completion left concept mastery data unrecorded. Transactional and duplicate-safe.

## Polish & Fixes

- Public note Quick Check completion now uses an outcome-framed prompt reusing the existing copy-intent flow; ready public notes explain that their study tools came from the source note.
- Onboarding Step 5 now names the learner's topic, sets a return expectation, and makes "Open your Study Pack" the clear primary action.

## Known Limitations

- Dashboard's `NearLimitBanner` renders with no `onUpgrade` handler for PLUS/PRO users who hit the near-limit warning. Confirmed pre-existing (predates this release branch), not a regression — tracked as a conversion-audit backlog item.
- `DashboardService.getTodayFocus()` and `getContinueStudyingRecommendation()` are two independent, never-reconciled resolvers that both compute "resume the latest in-progress session" as their top priority, and similarly overlap with the Focus Areas weak-concepts card. Mitigated this release by only rendering the new Today Focus card for its one genuinely new state (`DUE_CONCEPTS_REVIEW`); full reconciliation is a larger refactor than this release's scope.
- The backend's `isDue` definition treats a concept with no prior correct answer as immediately due, not just spaced-repetition-elapsed. This is long-standing Adaptive Practice generation logic, but this release is the first time it reaches Dashboard card copy — a first-run user can see "N concepts are due for review" for material they've never opened. Explicit product call was to ship as-is; revisit copy if it proves confusing in practice.
