# Release Notes: v0.158.0 — Reading the Evidence

## Release Theme

NoteLib stopped adding features for one release to read the evidence it already owed, and the first readings say the retention emails work as designed but mostly do not bring dormant learners back.

## Key Features

**🔎 Overdue checkpoints, actually read**
- The publication boundary is not stranding curriculum yet: one Review Set holds 325 unpublished topics but the oldest is 9 days old, so the check is re-dated to 2026-09-28.
- Learning Connections still has exactly one accepted relationship, so the kill criterion does not fire and it is re-read next release.
- The 5-second connection timeout is inconclusive: 500s rose from about 0.07% to about 0.27% with spikes on 09-17 and 09-18, some from genuine pool saturation and some after database drops. It is left as an owner decision.

**📬 The first retention run behaved as designed**
- The daily run dispatched the due-concepts digest first, then weak-concept, then inactivity, in about 17 seconds with no errors.
- Inactivity sent 46 emails under a 46 budget instead of being pinned at 60, and the digest sent all 14 due.
- Opens are being counted; clicks are still zero because click tracking is not switched on for the sending domain yet.

**📉 Evidence that inactivity emails rarely bring people back**
- Across 4,466 sends to 235 users, the first email brought about 4.7% back within a week and the eleventh or later about 0.7%.
- There is no control group and the consent basis of these sends is unchecked, so this is recorded as an owner decision rather than acted on.

## Polish & Fixes
- The monthly knowledge-impact digest is now pinned to Asia/Manila like the daily and weekly retention jobs, and the schedule-zone contract test records it.
- `retention-emails.md` no longer describes the monthly send as host-time.
- The learning-relevant notifications Stage 1 plan is indexed in the Backlog, blocked on a badge and retention category decision.
- The cross-note review re-check found 906 quiz sessions and none anchored to a collection, so the deferral stands.
