# Release Notes: v0.39.0 — Flexible Review Methods

## Release Theme

Let a Study Pack be reviewed through more than Multiple Choice — Flashcards and real spaced-repetition Memorization as free, non-scored review methods, Identification and Enumeration as new scored assessment formats in Challenge Quiz — while preserving the v0.37.0 review-vs-assessment mastery boundary throughout.

## Key Features

**🗂️ Flashcards**
- New private Note Detail entry point, on the Key Concepts tab, for every non-teacher profile. Renders a flip-card deck straight from existing `keyConcepts`, matching each concept to its `quiz[].explanation` for the card back — no new AI/backend call, no `ConceptHealth` write, entirely outside the quiz-session engine.
- Concept matching uses a normalized, bidirectional-substring fuzzy match rather than exact string matching, raising average definition coverage from ~18% to ~56% across generated Study Packs (the practical ceiling, since `keyConcepts` always outnumbers `quiz` questions — a documented, permanent limitation rather than a bug to keep chasing).

**🔁 Memorization**
- A real spaced-repetition review surface sitting beside Flashcards, reusing its fuzzy concept-matching but excluding fallback-only concepts (a card with no real answer can't be self-graded).
- Simplified SM-2 scheduling (Again/Hard/Good/Easy) backed by a new, separate `memorization_cards` table — never a `ConceptHealth` field, never read by `ProgressReportService` or any readiness calculation. Free for every plan.

**✍️ Identification in Challenge Quiz**
- Challenge Quiz's generated question mix can now include free-text `IDENTIFICATION` questions (fill-in-the-blank / name-the-term), ungated across every plan tier.
- Scored deterministically against a generation-time `acceptableAnswers[]` list (normalized, case-insensitive) — no per-submission LLM call. Contributes to `ConceptHealth`, concept breakdown, weak concepts, review, and exports exactly like every other format.

**📝 Enumeration in Challenge Quiz**
- Challenge Quiz can also generate multi-slot `ENUMERATION` questions asking learners to name every item in a well-defined set of 2–5 (e.g. "Name the three branches of government"), ungated across every plan tier.
- Scored **all-or-nothing** via exhaustive bipartite matching against generation-time `acceptableAnswerGroups[]` — not first-match greedy, which can wrongly reject a valid answer when synonym groups overlap.

## Polish & Fixes

- Relocated the Flashcards entry point from the quiz-mode action row (which it never belonged in, and which was overflowing on narrower widths) to the Key Concepts tab, and made "back to note" links return to the tab a learner actually came from.
- Fixed a gap where Memorization's per-user data wasn't wired into `AccountPurgeService`, and added missing controller-layer tests for its two new endpoints.
- Adapted both the static `schema.json` and the programmatic strict-mode schema builder for OpenAI Structured Outputs to support choice-less, free-text question formats (`choices.minItems: 0`, nullable `answer`, new required-but-nullable `acceptableAnswers`/`acceptableAnswerGroups` fields).
- Fixed a scoring denominator bug where a session mixing choice-based and free-text answers could silently over- or under-count `totalQuestions`.
- Added `IDENTIFICATION` and `ENUMERATION` mock items to `StubLlmStudyPackService` so local/offline development exercises both new formats without a real OpenAI call.
