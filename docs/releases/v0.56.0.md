# Release Notes: v0.56.0 — Weak-Concept Explanation Links

## Release Theme

Closes the loop from "you missed this" to "here's what it actually means, right now" — a learner who missed a concept on a quiz can jump straight to that concept's Study Pack explanation in one click, instead of hunting for it themselves.

## Key Features

**🔗 Weak-Concept Explanation Links**
- Quick Review, Adaptive Practice, Challenge Quiz, and Board Exam Mode result screens now link any missed/weak concept that matches a source-note Key Concepts entry straight to that entry — unmatched concepts stay plain text.
- The link opens `?tab=key-concepts#concept-*`; Note Detail scrolls to and briefly highlights the target so it's unmistakable which concept you landed on.
- A same-session, in-the-moment learning aid, not a retention or return mechanic — no new schema, endpoint, generation, or scoring changes.

**📝 Quiz-Tab Full Notes Nudge + Key Concepts Readiness Sort**
- A one-time nudge on the Quiz tab points toward Full Notes if you haven't visited it yet this page visit — a narrower addition, not a reopening of the existing (deliberate) tab order.
- The Key Concepts tab now sorts entries by readiness — struggling first, then due, then not-started, mastered last — once your progress data has loaded, so the concepts most worth reviewing surface at the top.

## Polish & Fixes

- Fixed a pre-signoff finding where a learner arriving via a weak-concept link could get scrolled and highlighted against a concept's pre-sort position, only for the readiness sort to relocate it moments later with no re-scroll to follow — the scroll/highlight now re-targets the concept's final sorted position.
- Independently re-verified that weak-concept matching behaves consistently across all four result screens (including both Challenge Quiz result branches) — no drift found.
