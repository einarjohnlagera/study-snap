# Release Notes: v0.107.0 — Curriculum-Scale Remediation

## Release Theme
Practice your weak areas across a whole Subject Plan or Review Set — on evidence that is finally honest, because every mode now records what you got wrong against the note it actually came from.

## Key Features

**🎯 Practice Across a Whole Plan**
- Adaptive Practice can now be scoped to an entire Subject Plan or Review Set, not just one note
- Start it from the plan itself, or from the dashboard's Weak Concepts card
- Sources are sampled across the plan and the session is anchored automatically — nothing to pick
- Existing note-scoped Adaptive Practice is unchanged

**🧭 Weak Concepts Keep Their Source**
- Two notes weak on the same concept now stay two separate entries, each labelled with the note it came from
- Concept strength is scoped per note, so merging them would claim a connection the product cannot make
- The focus list shows the source whenever a concept name repeats

**📊 Honest Evidence in Every Mode**
- Interview Practice now records concept results against the note each question came from, instead of copying one list onto every source
- This was the last mode still over-attributing, so subject-level strength is now supportable across the store
- Concept results written before this release keep their old attribution — nothing was rewritten

## Polish & Fixes
- Adaptive Practice and Interview Practice can no longer complete, resume, or forfeit each other's sessions — starting one while the other is active now explains the conflict instead of silently ending it
- Starting plan practice while another session is running on one of the plan's notes now anchors elsewhere or says why, rather than handing back an unrelated single-note session
- The dashboard's plan practice button now explains why a session did not start instead of doing nothing
- A plan whose weakness is all repeat-misses (nothing due) now shows the practice button
- Practice quota and rate limits are checked before the plan's notes are loaded, so an over-quota learner is told immediately
- Concept lists no longer collide when two notes share a concept name
- Coverage sampling now keys on plan identity rather than plan title, so two same-titled plans stay distinct
- Removed unused session-state helpers, an unused breakdown method, and an unused API wrapper
- Corrected feature docs that still described removed mechanisms, and added the Adaptive Practice capability line to the mode contract
