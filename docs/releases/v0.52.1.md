# Release Notes: v0.52.1 — Early-Lifecycle Feedback Signals

## Release Theme

Three small, targeted proactive feedback prompts aimed specifically at *new* users in their first few sessions — a leading indicator for friction that predicts a second or third session might not happen, not a way to reach users who already left (that's a separate, still-unsent outbound interview track).

## Key Features

**📚 Public Library Browsed-Without-Adopting Prompt**
- Fires once, entirely client-side, when a new/light user views 3+ distinct public notes in one session without adopting any.
- Gates on the already-shipped `GET /dashboard/overview` `totalNoteCount` signal as a "new/light user" proxy, avoiding a new backend field.
- Renders back on the Public Library list; adoption is tracked from both the list-card and detail-page copy paths so the prompt never fires for someone who already adopted a note that session.

**📝 First Non-Onboarding Study Pack Generation Prompt**
- Fires once, the first time a Study Pack finishes generating from the regular Note Detail page outside onboarding — deliberately not on a user's very first-ever generation, since asking before they've consumed anything is premature.
- Reuses the existing generation-complete poll and one-shot per-user marker convention.

**🎯 Second-Ever Completed Quiz Difficulty/Pacing Prompt**
- All four quiz completion paths (Quick Review, Challenge Quiz, Board Exam/Long Exam, Adaptive Practice) now compute `isSecondCompletedSessionEver` from a new owner-wide completed-session count, alongside the untouched `isFirstCompletedSessionEver` signal.
- Asks specifically about difficulty and pacing ("Too easy" / "Too hard" / "Too repetitive" / "Felt right") — questions a user couldn't answer meaningfully after only one quiz.
- Sits after the first-quiz-ever ask and before the generic helpfulness panel in priority.

## Polish & Fixes

- Added a shared, session-scoped cap so at most one of this release's three new prompts fires per browsing session.
- Pre-signoff check found that the Public Library and Study Pack generation prompts deferred only to each other's shared cap, not to the already-shipped first-quiz-ever prompt's own session marker — fixed so both check it directly, matching how the existing welcome-back prompt already does.
