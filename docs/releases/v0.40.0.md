# Release Notes: v0.40.0 — Weekly Study Plan (Exam Countdown) + Primary Review Set

## Release Theme

Turn readiness from a static number into an ongoing weekly cadence — learners can now name one Goal as their Primary Review Set, give it a target date, and see a live weekly countdown of what's left to study and today's concept budget.

## Key Features

**🎯 Primary Review Set**
- Learners with a single owned top-level Goal automatically get it set as their Primary Review Set — the one answer to "what should I be working on."
- The Dashboard, Review Sets list page, and Progress all key off this single reference instead of guessing from course/program matches.
- Deleting or losing the primary Goal falls back gracefully to today's existing recommendation behavior — no dead ends.

**📅 Target Completion Date + Study Intensity**
- Top-level Goals can now carry an optional target completion date, set independently of the profile-level exam date.
- A new study-intensity setting (days per week) captures a learner's real capacity, feeding directly into the weekly countdown math.
- Both fields are deliberately never copied when a Goal is adopted or self-copied — a deadline or pace only means something to the person who set it.

**📆 Weekly Countdown ("This Week")**
- The Goal detail page now shows weeks remaining, concepts remaining, and today's concept budget, computed live from readiness + target date + study intensity.
- Due concepts always act as a floor on the day's budget, so nothing overdue gets crowded out by new material.
- No stored schedule — the countdown recomputes fresh on every visit, so a missed day rebalances automatically instead of needing a "catch-up" feature.

**🏠 Primary-Driven Surfaces**
- Dashboard, the Review Sets list page, and `/progress` all default to the Primary Review Set's scoped view instead of a generic course/program match.
- A post-adopt guidance tip nudges newly adopted, dateless Goals toward setting a target date.

## Polish & Fixes

- Fixed a save-before-prefill race in the Goal edit modal that could silently wipe a learner's study intensity to null.
- Fixed Dashboard and public plan cards using hardcoded "Goal"/"Subject plan" text instead of resolving through the profile-aware label system.
- Fixed a target-date leak where reparenting a dated top-level Goal into a child position let it keep a stale, now-invalid date.
- `EditCollectionModal` now uses fully custom validation instead of a native form constraint that was silently blocking submission.
- Goal detail page now refetches immediately after a target-date edit so the weekly countdown never goes stale until reload.

## Known Limitations

- Progress shows a hard "Goal not found" card on a stale primary reference, while Dashboard falls back silently — narrow stale-cache window only, since deleting a collection already self-heals the primary reference.
- The target-date picker has no minimum, so a past date is currently selectable.
- The weighted largest-remainder subject allocation and day-of-week interleaving (Phase 2 of the weekly scheduler) did not ship this release — deferred to `v0.40.1` pending real usage of the Phase 1 countdown.
