# Release Notes: v0.30.1 — Copy Flow Polish

## Release Theme
Reduce the friction of copying notes from the Public Library: say what the action does, let the post-copy moment showcase the note instead of shortcutting it, and give adapters a clean editable-draft path — all frontend-only, no backend or new infrastructure.

## Key Features

**📥 Clearer Copy Action**
- The Public Library card action is now **Add to Library** (with a copy/library icon), replacing **Save** — which read as a bookmark, especially sitting next to the like/heart. The already-copied state reads **In Library**.
- The card keeps a single primary copy action on every breakpoint — no dropdown or caret (a poor touch target on mobile). The editable-draft fork lives on the note detail page instead.

**✅ A Success Modal That Showcases the Note**
- The post-copy success modal now leads with a single **View Note** action and **removes the Quick Review quick-action**, which short-circuited users into one narrow mode instead of the note detail — the hub where the full Study Pack and every quiz/exam mode live.
- The modal body now states the payoff: *"The note and its Study Pack are now in your library — open it to read, quiz yourself, and track your progress."*

**✏️ Editable-Draft Copy on Detail**
- On the public note detail page, the two copy options are relabeled **Add to Library** (note + Study Pack, ready to study as-is) and **Copy as editable draft** (`includeStudyPack=false`), which arrives as an editable Draft so a user can adapt the content before generating their own Study Pack.
- This places the rarer "adapt" intent where deliberate readers are, keeping the grid's common path one tap.

## Polish & Fixes
- Fixed a duplicate close-button bug in the copy success modal: `AppModal` already renders its own close button, but the modal also passed a second one via `headerActions`. The redundant button is removed; a test now asserts exactly one close button so the regression can't return.
- Frontend-only: reuses the existing `copyNote` `includeStudyPack` parameter and the existing `PUBLIC_NOTE_COPY_CLICKED` / `PUBLIC_NOTE_COPIED` analytics, so the relabel is measurable today — no backend, quota, analytics-enum, or endpoint changes.
- Updated the public-library and public-notes feature docs to match the shipped copy flow.
