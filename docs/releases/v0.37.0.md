# Release Notes: v0.37.0 — Readiness-First Plans & Mastery Integrity

## Release Theme

Make plan-level readiness the headline of the Study Plan page instead of a click-through, and make sure that readiness number can't be satisfied for free by unlimited Quick Review grinding.

## Key Features

**📊 Readiness on the Plan Page**
- Leaf Study Plan detail now shows an inline readiness summary (overall %, mastered/due/not-started) between the hero and the execution-progress card — previously only reachable via a "Check readiness" click-through to `/progress`.
- A dedicated "Review due concepts" CTA sits next to it, independent of the plan's existing "next action" recommendation — so a plan with due concepts always has a direct way to act on them, even when another note needs a Study Pack first.
- A profile-aware Pro CTA pairs the free readiness number with a paid, formal way to prove it: Long Exam for Students, Board Exam for Board Takers, Interview Practice for Professionals — reusing the existing premium-exam entry point rather than a new one.

**🔒 Mastery Integrity**
- Quick Review can no longer move mastery, due-state, or Overall Readiness. It stays a refresh-only mechanic — its own in-session feedback (right/wrong, retry-incorrect) is unchanged, but completing a Quick Review session no longer writes to `ConceptHealth`.
- Existing readiness data is left as-is rather than backfilled or reset: any concept whose mastered status was only being held up by past Quick Review activity decays naturally once nothing refreshes it. From then on, only real assessment activity (Challenge Quiz, Adaptive Practice, Long Exam, Board Exam, Interview Practice) can re-master it.
- Completed Quick Review sessions no longer clutter Note Detail's "Recent Sessions" history list — the underlying data still persists exactly as before, so "Continue where you left off" and practiced-status tracking are unaffected.

## Polish & Fixes

- Corrected the premium-exam CTA's profile mapping across docs (Student → Long Exam, Board Taker → Board Exam, Professional → Interview Practice).
- The Dashboard's "Strongest Notes"/"Top Performance" widgets intentionally still include Quick Review sessions for best-score highlighting — left untouched as a separate, pre-existing decision.
