# Release Notes: v0.125.0 — Bounded Reads

## Release Theme
The last two places in the product that read a whole collection when they needed a slice of one — closing a shape that had already caused three production events.

## Key Features

**🔎 The note picker searches your whole library, not just the page it loaded**
- Adding notes to a Study Plan used to download every note you own, then filter them in the browser.
- It now asks the server, so the picker loads a bounded list and search reaches everything behind it — including notes matched by their subject, course program or tags, not just their title.
- Search shipped *with* the bound, deliberately. A bound on its own would have made every note past it impossible to add, which is why this was held back until now.

**⚙️ The admin template backfill stops reading the entire catalog**
- Seeding Official Challenge Quiz templates loaded every public note in full — bodies included — and then asked the database two more questions about each one, roughly 2,884 queries for a single click.
- It now answers the same question in four, and picks exactly the same notes in exactly the same order.

## Polish & Fixes
- The Add-notes list tells you when it is showing a bounded slice, and that searching reaches the rest.
- A dead copy of the Add-notes dialog was removed from the collection page — it could not be opened, but it still carried the unbounded fetch.
- Public library search is untouched: the new search is a separate clause, so nothing about Explore changed.
- The curriculum reshape tooling gains a cross-program pool query, so material tagged for a sibling program is no longer invisible when shaping a Review Set — and it now reports authoring depth, since notes written for junior high cannot be used in a licensure reviewer.
- The LET Review Set target shape lands: 321 notes across 6 subject plans, 145 of which need no authoring.
- Six Building Laws titles now name the regulation that defines them rather than the program that applies them.
