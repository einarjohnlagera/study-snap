# Release Notes: v0.83.2 — Anonymous Discovery Access

## Release Theme
A signed-out visitor browsing the Public Library now gets the filters the page was built to give them.

## Key Features

**🔓 Subject and Course/Program filters work without signing in**
- Browsing the Public Library while signed out previously showed two of its four filters as empty — Tags and Authored Depth loaded, Subject and Course/Program silently did not
- Both now load for everyone, on the page that most new visitors arrive at first
- Your own private subjects and course/programs stay private: only the public lists were opened up, and only for reading

## Polish & Fixes
- Removed the back link from the Exam Hubs index, which pointed at the Public Library as though Exam Hubs sat underneath it — it is a top-level destination reached directly from the main navigation and footer
- Recorded the Exam Hubs index in the navigation rules as a main page, since its absence from that list is what let the stray back link go unnoticed
- Added test coverage for the course/program filter endpoint, which had none, and for the access rules on both filter endpoints
