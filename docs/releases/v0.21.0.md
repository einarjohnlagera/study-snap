# Release Notes: v0.21.0 — Personalized Discovery & Library Organization

## Release Theme
"Personalized Discovery & Library Organization" — make the app feel personal from day one by surfacing community notes relevant to each user's study track, letting users save and reuse their own filter shortcuts, and giving content creators a direct path from their public profile to their full note catalog.

## Key Features

**🏠 Community Notes on the Dashboard**
- Dashboard now surfaces up to 4 public notes matched to your Course/Program below Recent Notes
- Section title reflects your track — e.g. "Notes for PNLE"
- Footer link navigates to the full filtered Public Library
- Users without a Course/Program set see a placeholder card prompting them to complete their Learning Profile
- Visible on Student, Exam Reviewer, and Teacher profiles

**🔖 Saved Filters for Private Library**
- Save the current filter state (search, subject, course/program, tags, status, sort) as a named shortcut
- Apply a saved filter with one click from the filter bar
- Delete stale filters individually
- Filters are backend-persisted — available across devices and sessions

**🔍 Public Library Creator Filter**
- `GET /notes/public` now accepts a `creator` query param (username) to filter the public library to one author's notes
- Public profiles with more than 8 notes display a "View all X notes →" link that opens the filtered library
- An active "By @username" filter badge appears in the Public Library when a creator filter is applied; clearing it removes the param

## Admin Tools

**📊 Admin Funnel Metrics**
- New `/admin/funnel` page showing five conversion-health metrics derived from existing tables — no new migrations
- Metrics: activation rate (signup → first Study Pack), stuck users (notes with no Study Pack after 7 days), free quota hit rate, paywall-to-upgrade conversion, and Study Pack → quiz loop closure rate
- Non-admins are redirected to the dashboard

**⚙️ Admin Summary Regeneration**
- `POST /admin/study-packs/regenerate-summaries` queues enriched-summary backfill for admin-owned Study Packs not yet in the new format
- Returns queued/skipped counts immediately; work runs async on the LLM parallel executor
- Live progress polling: frontend shows "Processing X/Y..." and a final toast with regenerated/failed counts
- Idempotent — already-enriched summaries are always skipped

## Polish & Fixes
- Removed subject badge list from the Learning Focus section of public profiles; the summary sentence and "View all" creator link replace badge-based browsing
- Right-aligned "View All in Library →" link in library grid sections for consistency and better right-hand reach on mobile
- Official author detection is now role-based (`UserRole.ADMIN`) — removed hardcoded `OFFICIAL_AUTHOR_EMAIL` constant; admin display name shown on public notes
- Summary word limit raised from 200 to 350 to accommodate enriched summaries with comparison tables (markdown pipe characters inflate word count)
- Added plain-language helper text for Display Name and Username fields on the Profile page
- Fixed N+1 query in admin funnel quota-hit metrics — single projection query replaces per-subscription lazy load
- Fixed `RejectedExecutionException` crash in admin summary regeneration when the LLM executor queue is full — tasks that cannot be queued are recorded as failures and the operation remains idempotent on re-run
