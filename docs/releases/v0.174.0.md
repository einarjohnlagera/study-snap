# Release Notes: v0.174.0 — Enhanced Generation

## Release Theme

Study Pack generation can now follow each learner's plan, ready for a model upgrade that switches on
separately, while every quiz and practice screen keeps its current speed.

## Key Features

**🧭 Study Pack generation that follows your plan**
- Study Packs, summaries, notes generated from a topic, and official NoteLib content can each use a
  different AI model, depending on the learner's plan. Official NoteLib content has its own route,
  whatever the account's plan.
- The plan is read from the live subscription, so an expired paid plan is treated as Free.
- The new models switch on separately, after this release is live. Nothing changes for learners
  until then.

**⏱️ Quizzes keep their current speed**
- Challenge Quiz, Board Exam, Long Exam, Adaptive Practice, Interview Practice and study tips all stay
  on today's setup for every plan.
- Testing showed that the newer models would make a Challenge Quiz start noticeably slower, so faster
  quiz preparation is planned for the next release before those screens change.

**🔁 Try again when a Study Pack can't be created**
- If generating a Study Pack on the Study page fails, the error now offers a clear Try again button.
- It only appears when retrying can help. It never retries on its own, and it can't send the same
  request twice.

## Polish & Fixes
- Every AI request now logs which route it took, how long it took and how it ended, with no note text recorded, so problems can be traced after the switch.
- A monthly cost alert tells the NoteLib team when tracked spending on official content passes a set amount. It is an alert only and never stops anything from being generated.
- Two rounds of testing on real NoteLib notes compared the current and newer models on reliability, speed and question quality before any change was approved.
- An independent pre-release review caught an issue where Try again could re-send an image instead of confirming edited text. It was fixed before release.
- A Study Pack's record of which model created it now always names the model that was actually used.
- This release reaches production only after the previous release's database checks finish, so each change can be measured on its own.
