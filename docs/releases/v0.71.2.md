# Release Notes: v0.71.2 — Catalog Management

## Release Theme

Adding a Course / Program no longer requires a database migration — a curator can create one the moment a note needs it, without leaving the note they are writing.

## Key Features

**📚 Grow the catalog from inside the app**
- A curator can add a Course / Program from the Admin area, with an optional Program Family and an optional supported exam goal.
- This unblocks the case the whole applicability model was built for: one canonical Algebra note extended to every engineering program it genuinely serves, instead of waiting on a migration to add each program.
- Growth stays demand-driven — a program is added when a real note is applicable to it, not seeded ahead of need.

**✍️ Add a missing program without losing your place**
- Typing a program the catalog does not have now offers to add it, right inside the Applicable Programs picker, and selects it once created.
- Near matches appear first, so a second spelling of an existing program is caught before it is created rather than after.
- It is an explicit action with a confirmation step, never something a stray keystroke can trigger — the picker still only accepts catalog programs.

**🧹 An Admin dashboard you can actually scan**
- The Course / Program catalog and Note Applicable Programs curation now live on their own page at `/admin/course-programs`, linked from the Admin header.
- The dashboard goes back to being an operational view — usage, billing health, feedback — instead of mixing authoring tools into the page you check in production.

## Polish & Fixes
- Duplicate program names are caught regardless of capitalisation or spacing, so `civil engineering` cannot be created alongside `Civil Engineering`.
- Trying to create a program that already exists offers the existing one to select, rather than failing with an error.
- A failed creation keeps everything you typed, so nothing has to be re-entered.
- Assigning a family at creation time is what makes a new program participate in that family's authoring expansion — the form says so directly.
- No database migration and no schema change shipped in this release.
