# Release Notes: v0.45.1 — Study Plan Collection Fixes

## Release Theme

Close three pre-existing collection and discovery defects surfaced during v0.45.0's pre-signoff review: a Goal-collection note count that always read 0 when its notes actually lived on child Subject Plans, a Published Plans back link that ignored how the user got there, and a dead end where users with a primary study plan lost all access to the official-plan catalog.

## Key Features

**🔢 Goal-Collection Note-Count Rollup**
- Public and owned collection lists now report a Goal's true note and practice-ready counts, rolled up from its child Subject Plan collections instead of always showing 0.
- The Dashboard's Goal recommendation card now shows the real note count alongside the Subject Plan count instead of hiding a misleading zero.

**🧭 Published Plans Navigation**
- The Published Plans page's back link now returns to wherever the user actually came from (Dashboard, Public Library, or Collections) instead of always defaulting to Dashboard.
- Once a user has a primary study plan set, the Dashboard's recommendation card intentionally stops linking to the full official-plan catalog — but there was previously no other way back to it anywhere in the app. `/collections` now has a persistent "Browse official plans" link in its header, independent of primary-plan status.

## Polish & Fixes

- Fixed the `Official` plan badge's dark-mode contrast — it used a solid fill that broke against the dark card background; now uses the same border-plus-tint pattern as every other identity badge in the app.

## Known Limitations

None specific to this release.
