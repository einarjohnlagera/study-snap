# Release Notes: v0.50.1 — Mobile UI Polish

## Release Theme

A fast-follow patch fixing UI issues surfaced by direct use of v0.50.0's mobile tab bar, plus two small, unrelated pre-existing polish items.

## Key Features

**📱 Mobile Tab Bar Refinements**
- Library and Public Library tabs now restore your last filtered view instead of always resetting to the unfiltered list, reusing each surface's existing filter-memory mechanism.
- A new "Show mobile navigation bar" toggle in Settings > Preferences lets you hide the tab bar entirely; on by default.
- An icon-only variant was tried for Note Detail and Challenge Quiz Result, then reverted before shipping after review found it lost real accessibility and recognition value without meaningfully reducing on-screen chrome. The tab bar keeps its labels everywhere.

**📊 Concept Mastery Redesign**
- The Progress page's "Concept Mastery" list — which can hold 15+ subjects — now uses a denser, purpose-built row instead of the roomier card built for pages with only a handful of entries, cutting a full list's height by roughly a third.
- Each row is now clearly clickable (matching the styling used by Library's note cards) with a trailing chevron, and reliably truncates long subject names instead of letting them push the page wider than the screen.

## Polish & Fixes

- Review Set descriptions (Goal headers and child Subject Plan cards) now offer a "Read more" / "Show less" toggle when the curated text is long enough to be clipped, instead of cutting off silently with no way to read the rest.
- Goal Milestones now states the next checkpoint in plain text (e.g. "Next: First concept mastered") above the marker grid, so a zero-progress state reads as a real empty state instead of looking broken.

## Known limitations

None specific to this release.
