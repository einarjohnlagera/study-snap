# Release Notes: v0.63.0 — Ask Companion

## Release Theme

Give PLUS a genuinely distinct capability — grounded Q&A over a Review Set's curator-authored Companion content — using the cheapest, lowest-risk runtime-AI shape available, rather than just more quota than FREE.

## Key Features

**💬 Ask Companion Grounded Q&A**
- PLUS and PRO learners can ask up to six questions per conversation directly against a top-level owned Review Set's renderable curator-authored Companion content, right beside the static guide on collection detail.
- A dedicated session aggregate preserves turn history across refreshes, idempotently resumes the single active user/collection conversation, and ends cleanly at six turns.
- Bounded runtime cost: a 20-session rolling monthly limit, the existing per-minute AI rate limit, and the cheapest configured model tier. FREE sees a plan-aware upgrade prompt instead.
- The system prompt answers only from the authored Companion content and explicitly refuses unsupported or outside-knowledge questions rather than fabricating an answer.

**🔁 Twice-Missed Concept → Ask Companion**
- Concept Health now tracks a consecutive incorrect-answer streak per concept, resetting on a correct answer.
- When a concept is missed twice in a row, Adaptive Practice, Challenge Quiz, and Quick Review results offer an "Ask Companion about this" CTA using the same Primary Review Set already resolved on those screens.
- FREE sees the same upgrade nudge Ask Companion already shows; eligible PLUS/PRO learners get a deep link with a pre-filled question draft that still requires an explicit send — landing alone never starts a conversation or spends quota.

## Polish & Fixes

- **Owner-requested Opus pre-signoff pressure test (three parallel agents) found and fixed five issues before any learner hit them**, given this release's size and two PRs touching the same shared session-start method:
  - Ask Companion conversations would have broken on the second question — OpenAI's Responses API rejects the content type the backend sent for prior assistant-turn history. Fixed to match the API's actual contract for assistant-role content.
  - The session-start response displayed a quota count one behind actual, caused by a stale cached read immediately after the quota increment. Fixed to report the correct post-increment count.
  - The collection-detail page could show a twice-missed deep link built for a learner's previous plan right after an upgrade or downgrade, since it read a more stale plan source than the result pages it's paired with. Now reads the same fresh source.
  - A quiz question with no concept tag could surface as "Can you explain Unknown a different way?" in the twice-missed CTA. The card now skips placeholder concept labels.
  - A locked product-contract doc still said Quick Review never affects mastery tracking — untrue since a deliberate change weeks before this release. Corrected to match actual, already-shipped behavior.

## Known Limitations

- **The twice-missed CTA can point at the wrong Review Set.** It reuses the same Primary Review Set resolution `CompanionResultBridgeCard` already relies on elsewhere, which doesn't guarantee the missed concept's note belongs to that collection — but unlike that card's free static excerpt, pressing send here starts a real, quota-consuming session even when the Companion never covered the concept and the model has to refuse.
- **The twice-missed streak counter has no mode discriminator.** Board Exam, Long Exam, and Interview Practice sessions still update the same underlying counter that Adaptive Practice, Challenge Quiz, and Quick Review read for the CTA, even though those three modes show no CTA of their own.
- **No retroactive credit on deploy.** Learners already partway through a miss streak before this release get no immediate credit — their next miss is only their first counted one.
- **Two independent placeholder-concept labels exist in the codebase** ("Unknown" and "Uncategorized") and are only guarded against at the CTA's last mile, not unified at the source.
- The pre-filled draft query parameter isn't cleared from the URL after arrival, and a deep link doesn't scroll the Ask Companion panel into view.
- The session lock used while asking a question is held for the full duration of the LLM call, which can serialize — but not duplicate — a rapid double-submit against the same session.
