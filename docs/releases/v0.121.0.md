# Release Notes: v0.121.0 — Shared Quiz Recipient Experience

## Release Theme
When you send someone a quiz, the person who takes it gets a fair one.

## Key Features

**🎯 Nobody is scored on a question they cannot answer**
- Matching questions reached recipients stripped of the grouping that makes them matching — so a block of four items sharing one set of choices arrived as four unrelated questions, and was **graded** as if that were fine
- They are now excluded from shared quizzes entirely. Every in-app mode still uses them normally
- This was reachable, not theoretical: the quiz generator is instructed to include one matching block, and shared quizzes are built by that same generator

**✏️ A wrong answer can be corrected**
- Answers used to be final the instant you clicked. Notice a mistake one question later and there was nothing you could do
- A **Back** control now returns you to any earlier question with your answer still selected, and you can change it
- Two locks had to go, not one: answers were recorded in a way that could not be revisited, *and* picking a single-choice answer disabled every other option on the spot
- You still cannot skip ahead past an unanswered question — answers became correctable, not optional

**📱 The quiz is the only thing on screen**
- Signed-in recipients were shown the full app, bottom tab bar included, while taking a scored quiz — so the same link behaved differently depending on whether you happened to be logged in
- Everyone now gets the same focused page. The in-app quiz screens are unaffected
- The result button no longer runs off the edge of a narrow screen

**📚 Somewhere to go after the score**
- A result screen that ends in a number gives a learner nothing to do next
- Where the quiz came from material that is already public, the result now offers it: **View Note** if you are signed out, **Add to Library** if you are signed in
- **Private sources are never surfaced — not named, not counted, not hinted at.** Sharing a quiz has never meant sharing the note behind it, and it still does not
- Quizzes built from several notes at once offer nothing here yet, because those quizzes do not record which notes they came from. That is recorded as a follow-up rather than guessed at from titles

**📊 We can now tell whether any of this worked**
- Opening a shared quiz was already recorded; finishing one was not, so there was no way to see whether recipients got to the end
- Completion is now recorded, and only once answers are actually graded — a failed submission you retry is not counted as a finish

## Polish & Fixes
- The concept under each question is labelled *Topic* instead of sitting bare beneath the question, where it read as a second sentence of the question itself
- Corrected a fix from earlier in this same release: the wrapping change intended for the long result button had landed on a different, short button, so the real overflow was still live. The missing guard that would have caught it is now in place
- The quiz you keep is untouched — recipients see a filtered view, and nothing is rewritten in your own copy
- Documentation that described matching questions reaching recipients as "presentation only" with "grading unaffected" was corrected: it was neither
