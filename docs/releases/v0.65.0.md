# Release Notes: v0.65.0 — Study Effectiveness Polish

## Release Theme

Close out the remaining, still-valid candidates from the 2026-07-22 Study Effectiveness/UI Polish/Pricing Fit consultation — showing a learner what a Study Pack actually contains before they commit, cleaning up the card stack that has accreted on Review Set Detail and the quiz result screens over many releases, making the collapsed Companion discoverable, and explaining why Adaptive Practice picked a given question.

## Key Features

**📊 Study Pack Scope Surfacing**
- Note Detail's Summary tab and private Library cards now show a ready pack's concept count, quiz length, and a deterministic rough review-time estimate before a learner starts a session.
- Draft, generating, failed, and empty-pack states show no misleading zero-value scope row. Public/discovery cards are unchanged.

**🧹 Result & Review Set Detail Layout Pass**
- Goal Detail now groups Today's Focus, readiness, and post-adopt guidance into one tight study-decision cluster, followed by a tight Companion/Q&A cluster.
- Quick Review, Challenge Quiz, Adaptive Practice, and Board Exam Mode's own result branch now consolidate their next-step/pacing cards and Companion-adjacent cards into shared visual groups — presentation only, no action, conditional, or data fetch changed.

**👀 Collapsed-Companion Teaser**
- `CompanionDisplayCard` now shows a single-line plain-text excerpt under the toggle while collapsed, instead of rendering nothing until a learner clicks "View Full Guide."
- The collapse-by-default decision is unchanged; a Companion with only FAQ/Resources populated still shows no teaser.

**🎯 Adaptive Practice Rationale Tag**
- Active questions now show why their concept was targeted — due for review, missed last time, or both — via a short pill row above the question.
- The reason is captured before due and previously-missed concepts merge, persists in session state alongside the quiz, and survives resume/refresh. Unmatched concepts stay untagged rather than getting a guessed rationale.

## Polish & Fixes

- A real-browser visual audit (production CSS, mocked API data) of the layout pass found and fixed two presentation bugs the RTL/tsc/lint pass couldn't catch: `ResultGuidanceGroup` used `Card`'s `p-0` override to zero out padding, but this codebase's `cn()` is a plain string join (no `tailwind-merge`), so `Card`'s hardcoded `p-6` and the passed `p-0` both landed in the DOM and Tailwind's compiled stylesheet order — not DOM order — picked the winner, leaving every group inset by extra padding; fixed by dropping `Card` for a plain div replicating its other base styles. Separately, Goal Detail's Companion-guidance section rendered unconditionally even when nothing inside it was renderable, leaving an empty box in the page's spacing rhythm; fixed by gating the whole section on the same check its children already used individually.
- Per this release's own pre-signoff gating rule, checked whether the release's four PRs crossed the full multi-agent-pressure-test threshold: below the 6+ PR bar, no single concept spanning 3+ surfaces, and two same-file overlaps between PRs confirmed to land in disjoint rendering regions rather than a shared method — so a single `advisor()` summary was the right depth. That check verified the new rationale pill row renders only in the active-question branch (never the result branch, despite sitting in the same file as the layout pass's result-screen changes), and caught that the merged `releases/v0.65.0` branch itself had not yet been built/tested as a whole — each PR had only been verified pre-merge, on its own branch. Ran the full backend build, `tsc --noEmit`, and Jest suite on the merged branch before signoff; all green.

## Known Limitations

- **Challenge Quiz's outcome area (score, Score Summary, per-metric cards, Concept Breakdown) still reads as an accreted card stack.** The real-browser visual audit flagged this as the reason Challenge Quiz's result screen is the weakest of the three (Adaptive Practice's outcome hierarchy was rated strongest). Materially larger than this release's scope — needs its own scoping pass and Codex prompt.
- **The rationale pill row has not had a real-browser visual check.** The longest single-reason string is 62 characters in a rounded-full pill, and a matching-group question can render 2-3 distinct pills in one row — neither case is covered by this release's tests (all use a single short concept). Code review confirmed the row never renders on the result screen. The owner opted to verify it directly in-browser rather than route through a separate visual-review pass.
