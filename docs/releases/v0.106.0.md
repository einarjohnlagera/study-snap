# Release Notes: v0.106.0 — Board Exam Review Set Identity

## Release Theme
A Board Exam is now built from the whole Review Set it is named for, instead of three of its notes.

## Key Features

**🎓 Board Exam draws on your entire Review Set**
- The eligible syllabus is every note in the Review Set's Subject Plans that has a ready Study Pack — not a hand-picked handful
- Sources are sampled with coverage spread across Subject Plans, so a wide review set is represented rather than one corner of it
- The sample is deterministic per session: reopening the same exam gives the same exam
- Subject Plans provide spread, never weight — a large section earns no extra questions simply for holding more notes

**📚 Starting from a Subject Plan gives you the board exam, not a section quiz**
- Launching from any Subject Plan resolves up to its parent Review Set, because a Board Exam is about the whole licensure curriculum
- Ownership is re-checked on that parent, so a child of someone else's Review Set is never a route into their curriculum
- A note that belongs to two Subject Plans is counted once, not twice

**⚙️ Exam length is configuration, with an honest floor**
- The target item count is a configured value rather than a number baked into the code
- If some sources cannot contribute, a still-valid shorter exam is delivered and clearly marked as short
- If too little assembles to be a real exam, the session fails and both quota units are refunded rather than charging you for it

**🔒 Quota is safe when generation fails**
- Board Exam generation now runs after the start commits, with a refund path and a race guard that ship alongside it
- The refund fires on every route into failure, including the background recovery sweeper, and can never take usage below zero
- Plan entitlements are unchanged: Board Exam stays Pro, at one unit per session regardless of how many notes it draws on

## Polish & Fixes
- A Review Set Board Exam no longer shows a source picker, because the server chooses the sources — a picked list is rejected with a clear message instead of being silently dropped
- Fixed the reachability defect that made the capability unusable: the app only sent the Review Set when notes had also been picked, which is exactly the combination the server rejects
- A failed plan lookup falls back to a normal single-note Board Exam again, instead of leaving you unable to start one at all
- Board Exam had lost its AI rate limit and its answer-key filter when its code path moved; both restored
- Exam question pools no longer contain questions that already sit on the note's own Quiz tab, where their answers are visible — fixed for both Board Exam and Long Exam, at generation time and again at sampling time
- Legacy single-note Board Exams now follow the same ship-short-above-the-floor rule as sampled ones, rather than failing outright on any shortfall
- Internal quota bookkeeping is no longer sent to the browser
- Board Exam start events now record source count and verified source scope, so exam assembly can actually be measured
- Corrected feature docs that still said Board Exam and Long Exam quota is charged per source note — it has been one unit per session since v0.32.2
