# Release Notes: v0.89.0 — Support Another Learner

## Release Theme
You can now help someone else learn — make them a quiz, connect with them, and see how they are doing.

## Key Features

**🤝 Make a quiz for someone, whoever you are**
- Creating a shareable quiz no longer requires calling yourself a Teacher — any signed-in, verified account can do it
- A parent, tutor, sibling or mentor previously had to misrepresent their own learning profile to unlock it, which changed their own dashboard and practice options
- The person you send it to takes it in the browser with no account, and sees their score at the end

**🔗 Learning connections**
- Invite someone to support your learning, or offer support to someone you help
- **Both people must agree** — an invitation does nothing until the other person accepts, so nobody can claim a connection over your account
- Either side can end a connection at any time, and access stops immediately
- Connections involving a young learner ask for a guardian's confirmation before they become active

**📊 See how they are doing**
- With an accepted connection, a supporter sees readiness, study streaks, quiz performance and plan progress
- **Notes are never shared.** A supporter sees how learning is going, never what the learner wrote — your notes stay yours
- A supporter-only account now has a home surface listing the people they support, instead of an empty dashboard

## Polish & Fixes
- Quiz sharing copy now speaks about helping someone rather than distributing to a class
- Teachers keep their printable multi-version exports; only sharing opened up
- Invitation emails can no longer be used to smuggle formatting or links through someone's profile name
- An invitation no longer reveals the other person's name before they have accepted
- Sending an invitation now requires a verified email address
- Fixed a progress page that could show the previous person's numbers under a new person's name after a failed load
- Fixed an error message that still told people quiz sharing was for Teacher accounts only
- Recovery of stalled exam generation now records when it acted, so the next review can tell recent activity from old
