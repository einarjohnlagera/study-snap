# Release Notes: v0.83.1 — Note Creation Integrity

## Release Theme
A learner who pastes notes and generates a Study Pack should get a Study Pack — not an error and a spent quota.

## Key Features

**🩹 Pasting notes into Study works again**
- Generating a Study Pack from pasted text, an uploaded image, or a confirmed text draft no longer fails at the last step
- Remixing a shared Study Pack works again too
- These paths had been failing since March, and the failure came *after* the generation had already run and counted against your monthly allowance — so the time and the quota were both spent for nothing

**🔎 Depth filter links accept the same shapes as every other filter**
- `?level=senior-high` now filters the Public Library, matching how the subject and course/program filters have always worked
- Previously only the exact `?level=SENIOR_HIGH` form worked, so a hand-written or shared link in the ordinary style quietly returned everything

## Polish & Fixes
- Removed leftover markup in the note editor's generation-context panel that a previous release had left behind
- Cleared retired audience data from test fixtures across nine files, while deliberately preserving the two that use it to prove older saved drafts still load
- Documented that the depth filter's URL parsing must stay in step on both the server and the client, since normalising on only one side would filter results while showing the filter as inactive
- Scoped the groundwork for making Explore a public discovery destination, verified against current code rather than an earlier plan
