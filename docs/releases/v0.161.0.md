# Release Notes: v0.161.0 — Scannable Study Plans

## Release Theme

A Study Plan page reads at a glance instead of an unbroken scroll: Sections stay collapsed until you choose one, one tap opens or closes them all, and untouched content is finally called what it is.

## Key Features

**📚 Scannable Sections**
- Every Section on a Study Plan page now starts collapsed, at every screen width, so a large plan opens as a short list of headings instead of a wall of expanded notes.
- The one exception: a plan with a single Section opens it automatically, since there is nothing to scan.
- An `Expand all` / `Collapse all` toggle appears whenever there are two or more Sections, and its label always matches what is actually open.

**🌱 "Not started" instead of a false zero**
- A Section you have not yet practiced now says `Not started` instead of the misleading `0% · 0 due`.
- The same wording appears on a Study Plan's readiness header when nothing in it has been practiced.
- The wording only appears when it is true: if you have completed a session on any note in that Section, or in a leaf Study Plan, it keeps its real numbers instead — even if every answer so far was wrong.

**🔓 A real production fix, found before shipping**
- Pre-signoff pressure testing uncovered a live defect: a Subject Plan can carry its publication stamp while still being privately visible — either because it was added and published without also being made public, or because it was a private draft that predates this product's publication tracking. Either way, adopting a whole Study Plan used to fail partway through when it reached that Subject Plan, after your personal copy had already been created.
- Reading and adopting a Study Plan now treats the publication stamp, not visibility, as the boundary that matters, so adoption completes instead of failing midway.
- A Subject Plan that has never been published still cannot be read or adopted early, and that boundary is now enforced consistently everywhere it is checked, including a couple of direct-link paths that previously weren't checking it at all.

## Polish & Fixes
- Removed the old rule that decided whether Sections started open based on your screen's width; the collapsed-by-default behavior is now the same everywhere.
- The Year builder is unaffected: it already starts every Subject collapsed on first load and keeps its own `Expand all` / `Collapse all` controls.
- Learners who adopted the ALE or PNLE Review Sets before this release and are missing some Subject Plans are not automatically repaired by this update; using the existing `Review update` action on that plan will offer the missing Subject Plans as additions, the same way it already does for any other update.
- Two independent cold reviews and a separate automated pass checked this release before signoff; every finding was either fixed or is recorded as a known limitation in `RELEASES.md`.
