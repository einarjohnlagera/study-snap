# Release Notes: v0.143.0 — No Way Out

## Release Theme
Two live defects, found by re-verifying Backlog Index candidates against current code instead of
trusting their rows — a focus-mode trap that could leave a learner with no exit, and an exam
question pool that could keep serving questions from before a Note was regenerated.

## Key Features

**🚪 Long Exam always has a way out**
- If a Long Exam completion request ever hung, the header stayed hidden and the one exit button
  was disabled for as long as the request took — no way out at all
- The exit now stays available for exactly that moment, matching the same fix Challenge Quiz
  shipped for its own equivalent trap

**🔄 Regenerating a note keeps its exam questions in sync**
- Regenerating a Note's Study Pack used to leave its Long Exam and Board Exam question pools
  untouched, so a learner could still be served questions built from the content that was just
  replaced
- Both pools now reset and rebuild themselves whenever you regenerate a Note or its Study Pack —
  whether the Note's content changed alongside it or only the Study Pack did

## Polish & Fixes
- Closed a real concurrency race the exam-pool fix could otherwise have made easier to hit: a
  generation attempt that gets superseded by a newer one can no longer publish stale questions
  over the newer attempt's result
- Found and fixed a genuine deadlock risk before it shipped — the exam-pool fix was locking two
  tables in the reverse of their usual order under concurrent load; verified with a real database
  test, then corrected
- Corrected four stale Backlog Index rows that had been overstating already-shipped work as open
  candidates, closing one production checkpoint outright and re-dating another whose premise had
  gone stale
