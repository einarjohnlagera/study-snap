# Release Notes: v0.131.0 — Inbox Polish

## Release Theme
The notification bell now behaves like every other control in the header — it closes when you click away, it toggles instead of reloading, and it gets out of the way while you are taking a quiz.

## Key Features

**🔔 The inbox closes the way you expect**
- Clicking anywhere outside the panel closes it, and so does pressing Escape
- The Close button is gone — it only existed because there was no other way to close the panel
- Clicking the bell while the inbox is open now closes it, instead of reloading the list underneath you
- Opening it still fetches your latest notifications; only the click that closes it skips the request
- Screen readers are now told whether the inbox is open or closed

**🎯 The bell steps aside during a quiz**
- Taking any quiz now hides the header for its duration, so nothing is competing for your attention mid-question
- This already happened for Long Exam and Board Exam; it now covers Challenge Quiz, Quick Review, Adaptive Practice and Interview Practice too
- Every one of those screens keeps its own Leave button, so you can still stop at any point — and on Challenge Quiz, where that button is deliberately disabled while your answers are being submitted, the header comes back for exactly that moment rather than leaving you with no way out
- The unread count keeps updating quietly in the background, so the bell is accurate the moment you finish

## Polish & Fixes
- Fixed two in-page toolbars that would have floated with a gap above them once the header was hidden during a quiz
- Corrected a claim made when this release was opened: Quick Review was reported as having no way out mid-quiz, which was wrong — it has a Leave Quiz button, and no screen needed one added
- Dropped the shared quiz link from the hidden-header work after finding it already renders no header at all, so the change would have done nothing while looking like it had shipped
- Caught before release that hiding the header during a Challenge Quiz would have left no way out at all while answers were being submitted, since the Leave button is switched off during that moment — and on a timed Board Exam, which submits itself when time runs out, that would have happened without the learner doing anything
- Recorded that a mocked module in the test suite is an allow-list, after it silently hid a working feature twice in two releases
