# Release Notes: v0.169.0 — Study Journey, Continued

## Release Theme

Civil Engineering joins NoteLib's Exam Hubs, closing the last gap from the exam-aware terminology
work started in `v0.167.0`.

## Key Features

**🏗️ A Civil Engineering Exam Hub**
- `/exam/ce` is now a real discovery page, alongside the existing ALE, PNLE, LET, and CPALE hubs —
  curated Civil Engineering public notes, summaries, and practice quizzes in one place.
- The Exam Hub index page and the Help Center's Exam Hubs guide both now list all five hubs.
- Along the way, fixed a pre-existing gap where the Help Center guide had its own independently
  maintained hub list — already missing CPALE before this release even started — by making every
  surface read from one shared source instead of several separately-updated lists.

## Polish & Fixes
- Verified before shipping that Civil Engineering's public note count (113) sits comfortably within
  the range of the existing hubs (90–154), so the new page carries no new performance risk.
- Two other Study Journey items originally considered for this release — multi-goal exam support
  and Public Note → Study Journey discovery — were deliberately held back. Multi-goal needs further
  product-direction validation before implementation; Public Note discovery already has a design
  but is sequenced after two other in-flight production-stability checkpoints clear, to avoid
  contaminating their results.
- A documentation correction: a production-monitoring checkpoint from `v0.166.0` had been
  incorrectly recorded as "not yet started" after the release had, in fact, already deployed —
  corrected with the real deploy timestamp and recalculated due date.
