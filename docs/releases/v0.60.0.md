# Release Notes: v0.60.0 — Shared Official Pool Foundation

## Release Theme

Adopters of the same Official (admin-curated) content no longer each pay their own redundant AI cost to generate Challenge Quiz questions — a canonical set is now seeded once per Official study pack and shared, closing the gap v0.58.0 named but explicitly left open.

## Key Features

**🎯 Official Challenge Quiz Template Sharing**
- Any Official (admin-authored, published) study pack now eagerly seeds a one-time canonical set of up to 20 Challenge Quiz questions — triggered when a note becomes Official and already has a Study Pack, or when a Study Pack is generated for a note that's already Official, covering both orderings.
- Every adopter who copies that content and plays Challenge Quiz now claims first from their own bank, then copies unseen questions from the shared template into fresh, learner-owned rows, before falling back to a live LLM call for any remaining shortfall — invisible to the learner, with zero schema change.
- The template is read-only and learner-level-neutral at read time; copied rows are tagged to the adopter's own current level, so the same template serves adopters at any level, not just the one it was generated at.
- Private, non-Official study packs are completely unaffected. The existing "+5 Questions" progressive flow, per-user outcome tracking, and Redo Missed Questions all behave exactly as before.

**⚙️ Admin Backfill Trigger**
- Added a "Seed Official Challenge Quiz Templates" button to `/admin`, mirroring the existing Regenerate Summaries action, so already-published Official content (which predates this release and won't re-trigger the eager-seed hooks on its own) can be backfilled with one click instead of a raw API call.

## Polish & Fixes

- Added test coverage the audit found missing: the two eager-seed trigger call sites (`NoteService.updateVisibility`, and `StudyPackService`'s Study-Pack-generation hooks) now have dedicated tests verifying they actually invoke the seeding step with the correct note and study pack — the mocked collaborator in existing tests would otherwise silently swallow a broken trigger.

## Known Limitations

- **Backfill requires one manual trigger post-deploy.** The eager-seed hooks only fire on a state transition (note publish, Study Pack generation) — they never re-fire for content that was already Official and generated before this release shipped. An admin must click the new `/admin` button once for that existing content (including the LET/PNLE Review Sets the release was ratified on) to actually benefit. All new Official content going forward seeds itself automatically, with no manual step.
- **Template seeded at a fixed `medium` difficulty**, regardless of an adopter's own difficulty selection, until the template is exhausted for them and they fall through to live generation at their real difficulty. A deliberate concession, not a bug — the same tradeoff already made for learner level.
- **Long/Board Exam pool sharing remains undone.** This release retargeted from the originally-scoped exam-pool design (`ExamQuestionPoolService`) to Challenge Quiz after confirming Long/Board Exam is PRO-gated with ~zero production load. That idea is still valid and still on the table, just not part of this release.
- A proposal to also front-load Challenge Quiz sessions to their full question count for Official content (instead of the existing 5-then-`+5` progressive reveal) was considered — independently reviewed by Opus and Fable — and rejected for this release: the cost savings were already fully captured by the template mechanism regardless of pacing, and the provenance-dependent inconsistency it would introduce (adopted content behaving differently from private content in the same mode) wasn't worth it. Parked in `docs/product/ROADMAP.md`'s Backlog Index as a mode-wide, not Official-only, candidate if ever revisited.
