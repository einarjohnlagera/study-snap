# Release Notes: v0.105.0 — Curriculum-Scale Exams

## Release Theme
A Long Exam over your Study Plan is now built from the whole plan, not from an arbitrary handful of its notes.

## Key Features

**📚 Your whole Study Plan is eligible**
- Every note in the plan with a ready Study Pack can now appear in its own exam
- Previously a 77-note plan produced an exam drawn from at most 8 notes, and the other ~69 could never be picked — not because anything failed, but because the limit quietly discarded them before the questions were written
- The exam samples across your plan's sections rather than working through it in order, so a single sitting covers the breadth of the subject

**🎯 Coverage you can see before you start**
- The prestart screen states what the exam will actually cover, instead of asking you to pick notes and then ignoring the choice
- Repeat attempts on the same plan draw a fresh spread rather than re-serving the same note

**🛟 A failed exam no longer costs you an attempt**
- If question generation comes up short, the exam either runs as an honestly shorter exam or fails outright — and a failure gives your monthly allowance back
- Recovery covers the case where generation is interrupted rather than merely erroring

**✍️ Identification questions in Long Exam**
- Type the answer from memory instead of picking from four options
- Graded by exact match after trimming, lowercasing and collapsing spaces, against answers curated with the question — no AI marking, so the same answer always scores the same way
- Carries the same safeguards as Challenge Quiz, including the rule that stops the AI asking you to type a formula

## Polish & Fixes
- Fixed a case where a repeat exam on the same Study Plan quietly became a single-note exam while still reporting itself as covering the whole plan
- Fixed a failed exam being able to refund an attempt and then still appear as a usable exam
- Fixed quiz answer text losing part of itself when a question group was reorganised — an option beginning with an initial, such as "A. B. Smith", could be truncated
- Fixed typing in an Identification answer sending a request per keystroke; answers are now saved once you pause, and always saved before you submit
- Fixed characters disappearing while typing an Identification answer during a save
- Removed the additional-notes picker from plan-sourced exams, where it had no effect on the exam you received
- A plan exam now refuses a source list it cannot honour instead of silently ignoring it
- A note whose Study Pack is not ready now gives a clear message instead of a generic error
- Corrected the Help Center description of which exam modes pre-select notes from a plan
