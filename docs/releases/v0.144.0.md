# Release Notes: v0.144.0 — No Backdoor Left

## Release Theme

Closes the fourth and last known path that let an exam question pool keep serving questions from
a Study Pack's replaced content — the two admin-only repair endpoints `v0.143.0`'s own review pass
found but didn't fix.

## Polish & Fixes

- The admin summary-repair and quiz-repair maintenance endpoints now reset a Study Pack's Long Exam
  and Board Exam question pools whenever they replace that pack's content, matching the invalidation
  `v0.143.0` already shipped for the regular regeneration path.
- No learner-facing behavior changes — both endpoints are admin-only maintenance tools, and this
  closes a gap in them rather than changing what any learner sees.
