# Release Notes: v0.141.0 — Formulas That Render

## Release Theme
Maths now renders in two places that never rendered it at all — and the headline fix this release was named for was built, measured against real content, found to make things worse, and pulled before it shipped.

## Key Features

**📄 Summaries render maths they previously printed literally**
- A Study Pack summary containing an expression written without the usual markers showed it as plain text with the backslash visible
- Summaries are now repaired the same way every other surface already repaired them

**🔗 Shared Study Packs render maths at all**
- The page you reach when someone shares a Study Pack with you displayed its summary, key concepts and full notes as raw text — no maths rendering of any kind
- It now uses the same renderer as every other surface

## Not Shipped

**🧮 The fix for formulas in money questions was reverted before release**
- A question mentioning an amount of money and a formula in the same sentence still prints the formula as raw code — this release attempted a fix and withdrew it
- Checked against 1,158 real questions, the change repaired 3 and broke 385: expressions like scientific notation and simple arithmetic steps, which had always displayed correctly, began showing as raw code
- The cause was that the fix judged "is this money?" from the single character after the digits, and that character cannot tell the difference
- The original problem is unchanged and remains recorded, along with why this approach cannot work and what a future one has to do instead

## Polish & Fixes
- Backfilled the LET Review Set's plan file so it once again rebuilds into the workbook curators work from — following the documented "edit the source file and regenerate" rule had been quietly discarding a column
- The Review Set workbook builder now refuses a plan file that is missing its programs column, rather than silently producing a workbook with the column dropped
- Added the PNLE Review Set target shape, its strategist inputs, and the 25 previously-unwritten section titles
- Regenerated the PNLE workbook so it reproduces exactly from its own plan file, removing a hand-added block that no file could rebuild
- Recorded a production incident from 2026-09-10 in full, including what could not be determined: the mechanism is understood, the trigger is not, and the diagnosis says so rather than guessing
