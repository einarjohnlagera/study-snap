# Release Notes: v0.96.0 — Authoring Integrity

## Release Theme
What the product generates, names and shows should be correct — and building a Review Set should not fight the save your last drag started.

## Key Features

**🖱️ Reordering a Review Set is now deliberate**
- Drag notes and sections freely — nothing is saved while you rearrange
- **Save order** commits the whole plan in one go, and **Discard** puts it back
- You are warned before leaving with unsaved order, and a failed save keeps your arrangement so you can retry
- Renaming or adding notes while an order is pending saves that order first rather than losing it

**🧮 Summaries render formulas**
- Maths in a Study Pack summary now displays properly instead of showing the LaTeX source
- This covers every surface that shows a summary, including the public note pages
- Formulas with subscripts, which used to be mangled by the formatter before they could render, now survive

**✍️ Generated note titles name the topic, not the course**
- Titles describe the knowledge taught rather than the programme it sits in — *Highway Drainage Systems*, not *Drainage Systems in Civil Engineering*
- Disciplinary wording is kept when it is genuinely part of the topic, as in *Nursing Management of Acute Asthma*
- A title stays meaningful when the same material is reused in another programme
- Existing titles are left alone; they are tidied only when a curator is already reviewing that note

**🔣 Formulas stop being corrupted as they are written**
- Some generated notes were saving mathematics with the command silently destroyed, showing as `imes` instead of `×`
- This was invisible to every existing check, because the damaged text was shorter than the original
- New notes are protected, and near-misses are repaired as they are read

## Polish & Fixes
- Dragging no longer reloads your entire note list to reorder one plan
- A drag no longer starts on the first pixel of movement, so clicking a section name to rename it works reliably
- Domain Context guidance for curators is recorded in the architecture decision record, including that a new course or programme does not imply a new Domain Context

## Known limitations
- Notes that already contain corrupted formulas are not repaired. The fix protects new generation; there is no bulk migration, and no count of how many existing notes are affected.
- The formula repair covers commands beginning with `t`, `b` and `f`. Commands beginning with `n` or `r` are deliberately left alone, because repairing them could destroy real line breaks.
- The title rule applies to the Study Pack title. The note body's own heading is not yet governed by it, pending one production check.
- Summary maths renders wherever the shared summary component is used; other surfaces were not audited in this release.
