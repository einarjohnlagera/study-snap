# Release Notes: v0.99.0 — Connection Completeness

## Release Theme

Finish the two connection properties the last release shipped half-built, and stop a paused sweep from hiding the very expiries it later performs.

## Key Features

**⏳ An expired request stays visible, even if the sweep was paused**
- A request that lapses is kept on your list for a while afterwards, so you can tell an expiry apart from silence
- Previously that window was counted from the deadline rather than from when the request actually lapsed — so if the sweep had been paused or was working through a backlog, a request could go from "pending, overdue" one day to simply gone the next, never once shown as expired
- The deadline shown on a pending request is unchanged, and a connection paused to re-confirm a guardian's permission is still never on the expiry clock at all

**🔑 Inviting someone now requires a finished account setup**
- This was the last way to start a connection that did not ask for it — invitation links and emailed invitations already did
- Until now an account that had verified its email but never finished setting up could invite someone, have them accept, and end up holding a live connection — sharing still has to be turned on separately, but the connection itself should never have formed
- If you arrive mid-setup you are taken to finish it and returned to what you were doing, rather than hitting a dead end

## Polish & Fixes

- Every scheduled background job's production schedule is now pinned by the build, so a future edit cannot quietly move one; the check covers all ten jobs and also fails if a new job is added without being switched off during tests
- Curator guidance for authoring domains no longer hides where material belongs: the Engineering Sciences description now names building services — plumbing, HVAC, electrical distribution, lighting, acoustics, fire protection and vertical transportation — which is why around 41 building-services notes had been generating without computation guidance
- The Civil Engineering description no longer claims Surveying and Construction Management, which in practice are shared across programs
- Corrected `BP 334` to `BP 344`, and the Professional Practice & Regulation description now names the National Building Code and Construction Safety rather than reading as a two-programme list
- The curriculum-planning brief no longer pre-commits the answer it was meant to ask, which had produced 215 unclassified rows in a single plan
- A test that claimed to guard how authoring domains reach the AI was found to pass no matter what it was given; it is renamed to state exactly what it does and does not cover
- The new schedule guard was itself found to have three holes and was repaired before release: it checked the code's fallback rather than the configuration file that actually wins in production; it only looked inside one folder, so a job placed elsewhere escaped every check; and its "switched off during tests" check could be satisfied by a commented-out line, which had left the account-deletion job running during the whole test suite
- Rejecting an invitation from a half-finished account can no longer record a birth year on the way out — the value is permanent once written, and the ordering that prevents it is now enforced by a test rather than by convention
