# Release Notes: v0.76.1 — Adaptive Practice Entry Attribution

## Release Theme
An instrumentation-only patch: NoteLib now records where an Adaptive Practice session was started from, so an upcoming review of the feature can answer a question it previously could not.

## Key Features

**📍 Adaptive Practice now records where it was launched from**
- Every route that can start an Adaptive Practice session is now attributed — Dashboard Today's Focus, Dashboard Focus Areas, Dashboard Continue, the Challenge Quiz result screen, an Interview Practice readiness gap, Note Detail's mode launch, and Note Detail's due-concepts prompt
- Anything else records as a direct launch, so a typed URL or bookmark stays distinguishable from a real entry point
- Note Detail's two routes are recorded separately: choosing the mode is a different signal from following a "you have concepts due for review" prompt, and the distinction is deliberate
- **No change to what any learner sees or can do.** No new screens, no copy changes, no routing changes, no effect on quotas or on how sessions are generated

## Polish & Fixes
- Corrected the Adaptive Practice feature documentation, which stated that choosing the mode from Note Detail recorded as a direct launch — no longer true now that route is attributed
- Ships alongside two ratified product directions — *Support Another Learner* and *Adaptive Practice as the recommendation engine* — carried in this release rather than deployed separately, so learners are interrupted once rather than twice
