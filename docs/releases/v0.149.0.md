# Release Notes: v0.149.0 — Precision Before Coverage

## Release Theme

Program Family shortcuts get the one admin capability they were missing — reassigning an existing
catalog program's family — plus the lifecycle mechanism needed to retire outdated catalog entries
without deleting them, clearing the way for two new families: Health Sciences and Accounting.

## Key Features

**🗂️ Program Families Can Now Be Reassigned, Not Just Set at Creation**
- Admins can now move an existing Course/Program catalog entry into a different family, change it, or
  clear it — a capability the original Program Family mechanism never had. Before this, the only way
  to change a program's family was a database migration.
- A catalog program can now be marked inactive, retiring it from new authoring selections without
  deleting it or affecting any Note that already references it — an existing selection keeps
  resolving and rendering normally.
- This unlocks two new family shortcuts, Health Sciences and Accounting, built on the same generic
  mechanism Engineering and Education already use. Populating them is a post-deploy step; this
  release ships the capability, not the data.

**🎯 Family Shortcuts Show Their Real State**
- A Program Family shortcut used to disappear once every one of its programs was already selected,
  offering no feedback that it had been fully applied. It now stays visible as a clearly inert,
  checked state, and reverts to showing a remaining count the moment a member is removed.

## Polish & Fixes
- Aligned Bulk Generate's Domain Context helper text with the wording already used on the other two
  authoring surfaces.
- Two independent falsification passes (before and after implementation) found and corrected several
  issues before they shipped, including a deploy-ordering risk between the frontend and backend and a
  feature-doc claim that overstated where the new inactive-program filtering actually applies.

## Known Limitations
- Health Sciences and Accounting are not yet populated in production. Only Engineering and Education
  are currently assignable family shortcuts; the exact steps to populate the two new families are
  documented for the next post-deploy pass.
- A fully-selected family's displayed count can shrink without explanation if one of its members is
  later retired — a cosmetic edge case, unreachable with today's data, noted for the future.
