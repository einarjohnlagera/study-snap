# Release Notes: v0.33.4 — Builder Surface Clarity

## Release Theme
Separate the Goal Builder as a pure authoring surface by removing the readiness ring from the builder canvas; per-module stats in each Subject plan header already provide all the curation-relevant signal a curator needs there.

## Key Features

**Builder Surface Clarity**
- Removed the top-level `ReadinessSummary` ring from the Goal Builder page (`/collections/{id}/builder`) — the builder is a curation tool, not a study surface
- Readiness continues to appear on the Goal detail page via `GoalDetailView` (unchanged); no data or signal is lost
- Per-module stats in each Subject plan header row ("4 notes · 0% ready · 0/34 mastered") are retained as inline curation feedback
