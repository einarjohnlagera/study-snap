# Release Notes: v0.45.0 — Conversion Audit Tier 3 — Landing, Pricing & Discovery Polish

## Release Theme

Close out the 7-session conversion/retention UX audit with its Tier 3 findings — 18 medium-impact, lower-urgency items spanning landing, pricing, note detail, public plan discovery, onboarding, and the Public Library, all copy/composition/UI polish with no new backend entities, migrations, or pricing/quota changes.

## Key Features

**🏠 Landing Page Conversion Polish**
- Exam hubs now show a one-paragraph product-value strip on every hub, not just empty ones; the zero-note empty state adds a matching Learn category link alongside the existing signup and Public Library paths.
- The differentiation table was rewritten from four abstract contrasts to three concrete, felt ones (e.g. "gone when the chat resets" vs "saved in your library, reusable").
- Demo access (`/demo`) is now a required hero CTA and public nav item instead of unlinked fine print.
- A new landing FAQ section answers four pre-signup objections and emits `FAQPage` structured data; Learn articles now emit `Article` structured data as well.

**💳 Pricing Trust Polish**
- Plus and Pro plan bullets now lead with concrete learner outcomes, and the comparison table adds a `Best for` row.
- Pricing FAQ now answers pass-end, manual-renewal, and exceptional-refund questions.
- The generic Free upgrade fallback consistently reads `Upgrade to …`; near-limit banners now frame remaining credits as continued monthly progress rather than a hard warning.

**📄 Public Note Detail Polish**
- The non-owner copy flow now presents one quiz-first primary action plus `Add to Library` and share as secondaries, removing the competing editable-draft CTA.
- Related discovery now offers both `More from {Display Name}` and `More in {Subject}` — up to three cards from the matching subject, shown only when at least two related notes are available, with a link to the full subject listing.

**🗂️ Public Study Plan Card Polish**
- Public plan cards now show an `Official` identity badge, since the public list only contains admin-published plans.
- The Start/Continue CTA now explains that adoption opens a private, editable library copy.

**🧭 Onboarding & Dashboard Guidance**
- Teacher onboarding labels Learner Level as the default quiz difficulty.
- Dashboard guidance is unified through a single-slot picker: a post-completion topic reminder takes precedence, teacher introduction stays in the same slot, and returning learners get a spaced-review rhythm tip.
- Returning users (with a completed session) now see their Quick Review card lower in the Dashboard order, behind Usage and Progress; first-time users keep the existing order.

**🔎 Public Library Filter Polish**
- The no-results state now offers `Remove last filter` alongside a full clear.
- The More Filters sheet adds a reversible `Study Pack Ready` toggle, filtering the already-loaded result set client-side.

## Polish & Fixes

- Fixed a near-limit banner copy change from the pricing polish leaking stale assertions into two unrelated consumers (note editor, bulk generation), and a public note detail CTA removal that broke its own pre-existing test — both caught in a post-merge audit and fixed against the intended behavior rather than reverted.
- Fixed the Public Library tag-browser sub-modal not updating the "last changed filter" tracker, which could make `Remove last filter` target the wrong filter after a tag change made through that specific path.
- Corrected doc drift in `note-detail.md`, `public-notes.md`, and `landing.md` that had fallen out of sync with actually shipped behavior.

## Known Limitations

- None specific to this release. Three pre-existing issues surfaced during pre-signoff review (public collection note-count rollup for Goal-type collections, the Published Plans backlink not reflecting entry point, and no persistent catalog-browse link once a primary study plan is set) predate this release and are scoped into v0.45.1 rather than logged here.
