# Release Notes: v0.26.1 — Guidance System

## Release Theme
Features teach themselves — a reusable in-app guidance mechanism makes the Progress, Study Focus, Milestones, and Exam Hubs surfaces self-explanatory without cluttering the UI.

## Key Features

**🔗 Deep-Linkable Help Guides**
- The Help Center now opens a specific guide directly from a URL hash (e.g. `/help#progress-focus`), so in-app links land on the exact guide — not just the Help page index
- Hash-based (not a query param) to keep `/help` statically prerendered; no `useSearchParams` Suspense de-opt
- Opening and closing a guide syncs the browser hash via `history.replaceState` — shareable links, no scroll jump

**📌 HelpLink — Inline Reference Primitive**
- New `HelpLink` component (`components/ui/help-link.tsx`): a persistent "How this works →" link co-located with complex features, paired with a one-sentence inline gist
- Reference-grade (always visible, re-readable across terms) — distinct from the one-time dismissible `GuidanceTip`, which is reserved for "this feature exists" discovery nudges
- Placed on the Progress Goal Milestones card ("How milestones work →") and the Profile Study Focus / Exam Focus section ("How this works →")

**📊 Progress & Study Focus Guide**
- New Help guide covering the three concept-mastery states (mastered, due for review, not started), spaced-repetition decay (mastery isn't permanent — a concept slips back as time passes), the six goal milestones and what triggers each, profile-type-aware Study Focus framing (STUDENT = "Study Focus", BOARD_EXAM = "Exam Focus", TEACHER has none), and the honest new-term answer: no reset button needed — swap subjects and the new ones start fresh while kept subjects carry their mastery forward

**🧭 Exam Hubs Guide**
- New Help guide for the ALE, PNLE, and LET exam hubs — what they are (curated views over existing public notes, not separate content), and the three ways to reach them: the Exam Hubs nav link, public-note callout strips, and the Progress page next-step card when an exam goal is set

## Polish & Fixes

- `guidance.md` feature doc updated: four-layer guidance model documented, reference-vs-discovery distinction made explicit, deep-link mechanism and `HelpLink` placements table added, guide card list corrected to current 11 cards
