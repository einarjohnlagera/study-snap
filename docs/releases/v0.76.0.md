# Release Notes: v0.76.0 — Messaging Architecture: The Money Surfaces

## Release Theme
The places where NoteLib asks for money now sell the learning system rather than listing features — the pricing page finishes the voice it started, and the upgrade prompts adopt it.

## Key Features

**🏷️ A Free plan that says what it actually offers**
- Free is now *"Start with ready-made study material"* instead of *"For getting started"*
- Describes what Free is for — starting from material someone has already built — rather than naming the moment you sign up
- Deliberately avoids promising a *complete* review, because not every learner's program has an Official Review Set yet
- The plan description stays a plain list of what you get, so nothing implies Free is adopt-only when you can still create your own notes

**📊 A comparison table that describes learners, not contents**
- The "Best for" row now reads *getting started without building your own* · *building your own study plan from your notes* · *preparing with a real exam in sight*
- Answers "which one is me?" instead of "which one has more?"
- Free's row deliberately says something its tagline does not, so every row earns its place

**💬 Upgrade prompts that explain before they sell**
- Paywall headlines now carry the learning-system promise when a feature simply is not on your plan — *"Take your review all the way to exam day"*, *"Find out how ready you actually are"*
- When you have used something up, the headline still tells you that plainly, and the explanation moves into the body — you always know why the prompt appeared
- Buttons keep naming the feature you clicked, so what happens next is never ambiguous
- Free is now acknowledged in the upgrade prompt, where previously only paid plans were shown

## Polish & Fixes
- Fixed plan subtext in the upgrade prompt that described Adaptive Practice on every paywall — including when you were asking about Interview Practice or Board Exam Mode
- Plan subtext now describes what each tier is for, laddering from ready-made material, to building your own plan, to a plan that adapts as you go
- Corrected two documents still quoting the retired Free tagline and comparison-row copy
- Recorded the paywall copy rules — feature-named buttons, headline split by paywall type, tier-level plan subtext — so future copy work inherits them
