# Release Notes: v0.19.0 — Multi-Note Depth & Simulation Parity

## Release Theme
"Multi-Note Depth & Simulation Parity" — completes the multi-note exam story by bringing Board Exam Mode to feature parity with Long Exam, scaling question coverage and quota economics to match real multi-source cost, and fixing the simulation paywall so quota gates surface before users invest time in setup.

## Key Features

**🗂️ Multi-note Board Exam (Pro)**
- Board Exam Mode now spans up to 3 same-subject Study Packs in a single session
- Questions distributed proportionally across all selected source notes
- Subject validation enforces same-subject constraint before session starts
- In-session source attribution banner shows contributing note titles
- Session history displays "Multi-note Board Exam · spans N notes" sublabel on every participating note — not just the primary

**📐 Board Exam Coverage Scaling**
- Question count scales with source count: `min(12 × sourceCount, 30)`
- Single-note: 12 questions; two-note: 24 questions; three-note: capped at 30
- Ensures each source gets meaningful coverage regardless of session size

**💰 Per-note Quota Economics**
- Board Exam and Long Exam quota is now deducted per source note, not per session
- A 3-note Board Exam costs 3 Board Exam quota units; a 3-note Long Exam costs 3 Long Exam units
- Pro monthly caps raised: Board Exam 5 → **10 source-note units**, Long Exam 10 → **12 source-note units**
- Active sessions can always be resumed regardless of current quota state

## Simulation Paywall Timing
Board Exam quota exhaustion now surfaces the paywall at mode-card click during mode selection — before the Board Exam setup step — so users see the gate immediately instead of after configuring sources and clicking Begin. Long Exam direct visits now show the Pro paywall modal on page load instead of silently redirecting non-Pro users to the note.

## Admin Analytics Subject Drift Fix
"Top Subjects by Study Pack" now reads the subject from the source Note instead of the Study Pack's cached subject column. Study Packs created before a subject rename now report correctly under the note's current subject.

## Polish & Fixes
- Board Exam sessions surface on every participating note's Recent Sessions list (previously only the primary note)
- `lastSessionCompletedAt` updated for all source notes after a multi-note Board Exam completes
- Batch-fetch for additional Board Exam note subjects replaces N individual queries
- Subject normalization in Long Exam prestart updated to explicit English locale (`toLocaleLowerCase("en")`)
