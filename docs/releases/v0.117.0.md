# Release Notes: v0.117.0 — Authoring and Quiz Legibility

## Release Theme
Five things that were quietly wrong in daily use: a quiz question that ran together, a practice session that misnamed itself, two authoring controls that fought back, and an exam date that disappeared.

## Key Features

**📝 Assertion questions read properly again**
- A question built from several statements used to run its closing question onto the end of the last statement, so "Statement 2: Ice melts at 0C. Which statements are correct?" arrived as one line.
- The statements and the question now sit on separate lines. New questions are generated that way, and questions you already have are laid out correctly when displayed — nothing stored is rewritten.

**🎯 Practice across a plan says so**
- Starting Adaptive Practice across a Study Plan, then returning to it from one of its notes, used to show the session named after a single note — as if you were practising that note alone.
- It now shows the plan you are actually practising across.
- The weak concepts behind the session are grouped under the note each one came from, with a short summary and the full list one tap away, rather than a single long comma-separated line.

**🧲 Dragging a section behaves**
- Dragging a section in the Study Plan Builder showed a full-size preview of everything inside it, which made dropping it higher up the list nearly impossible.
- The preview is now just the section name and how many notes it holds, and the drop target follows your cursor rather than the middle of a very tall card.

**⚡ Choosing a section applies it straight away**
- Picking an existing section from the dropdown appeared to do nothing until you clicked elsewhere.
- It now applies the moment you choose it. Typing a brand-new name still waits until you finish, which is what stops a half-typed name becoming a section of its own.

**📅 Your exam date survives**
- If you had adopted a Subject Plan on its own, set your own target date on it, and later adopted the full Review Set it belongs to, that date was silently cleared.
- The date now carries across to the Review Set. Where several plans had dates, the earliest one is kept.

## Polish & Fixes
- Corrected two reference documents that described the section control and assertion-question format as they used to work.
