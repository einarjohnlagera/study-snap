# Release Notes: v0.120.0 — Canonical Note Title Integrity

## Release Theme
The title you type in Bulk Generate is the title your note keeps.

## Key Features

**✍️ Your typed topic is the note's title**
- Bulk Generate created each note with your topic and then overwrote it with the Study Pack's generated title, so `Site Grading Principles` was saved as `Site Grading Principles in Civil Engineering` — naming a discipline that was not among the selected Applicable Programs
- That overwrite is gone. The topic you type is the canonical title, which is how single-note generation has always behaved
- Your batch subject and the generated tags are still applied, exactly as before
- Legitimate disciplinary titles are untouched: `Nursing Management of Acute Asthma` stays as written. This keeps your words rather than stripping words it dislikes

**💡 The generated title is offered, not imposed**
- When a note's title differs from its Study Pack's, the note page offers the generated one as a dismissible suggestion
- Dismissing it sticks across reloads, so a note you have already decided about stays quiet
- It appears for curators only, and never costs an extra request

**🏷️ Plainer language for Interview Practice**
- The `AI Critique` chip is now **Per-Answer Critique**, and the surrounding marketing, in-app, Help Center and Learn-guide copy now say *critique* or *per-answer critique*
- Disclosures are deliberately unchanged — the Privacy Policy, Terms, the shared-quiz review notice, `AI-generated — verify calculations`, and the Learning Companion's human-review line all still say plainly that machine-generated output needs your judgement

## Polish & Fixes
- Existing notes are not renamed and no Study Pack is regenerated: this stops new contamination rather than sweeping old titles, because many similar-looking titles are correct and only a human can tell them apart
- The note detail response now carries the Study Pack's own title alongside the note's, so the suggestion needs no second request
- Viewing a note no longer risks changing which Study Pack your Dashboard treats as most recently opened
- Renaming a note inline clears a stale title suggestion immediately, instead of leaving one that would overwrite the name you just chose
- A test that asserted the old overwriting behaviour was rewritten rather than deleted — a passing suite had been protecting the defect
- The Bulk Generate helper no longer tells you titles are generated automatically, and the bulk generation, Study Pack generation, bulk regeneration, exam mode and professional profile docs were corrected to match
