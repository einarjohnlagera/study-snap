# Release Notes: v0.24.1 — Content Moderation Hotfix

## Release Theme
"Content Moderation Hotfix" — a targeted patch to the banned-word lists that were blocking legitimate academic notes containing common proper names, scientific terms, and engineering vocabulary.

## Polish & Fixes
- Fixed content moderation falsely blocking notes that contain "Dick" (e.g., the Dick and Carey Systems Model, or any other academic proper name using that surname)
- Removed `cock`, `bitch`, `tranny`, and `faggot` from the English list — all have standard academic uses (rooster in animal science, female dog in veterinary notes, transmission in automotive engineering, bundle of sticks in history and forestry)
- Removed `hayop` / `hayup` from the Filipino list — this is the ordinary Filipino word for "animal" and would have blocked biology, agriculture, and science notes written in Filipino
- Removed `puke` from the Filipino list — this is a common English word (to vomit) that was incorrectly placed in the Filipino dictionary, blocking health and medical notes
- Cleaned up a dead `putang ina` entry in the Filipino list that could never match anything (the tokenizer splits on spaces, so two-word entries are unreachable)
