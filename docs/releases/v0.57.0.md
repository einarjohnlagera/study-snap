# Release Notes: v0.57.0 — Practice-First Activation Onboarding

## Release Theme

For a board-exam learner whose target course/program already has a curated Official Review Set, onboarding now gets them to a real first practice question with zero note-authoring and zero AI generation, instead of forcing every learner through the same generate-or-write-a-note path.

## Key Features

**🎯 Practice-First Board Taker Onboarding**
- Immediately after Step 2 (Study Goal), a Board Taker whose collected course/program has a depth-qualifying published Official Review Set (has items, has ready notes) skips note authoring and Study Pack generation entirely.
- One new "Confirm & Practice" screen shows the matched Review Set and a one-tap "Start this plan" — the existing free, instant `adopt`/`adopt-goal` action, no LLM call.
- The learner lands on the adopted Review Set's detail page (Today's Focus, Continue Studying one tap away) rather than cold inside a quiz, matching every other adopt entry point already in the product.
- No qualifying Review Set, zero-ready coverage, or a lookup failure all fail open to the unchanged 5-step flow. Student, Teacher, and Professional onboarding are completely unaffected.

**📊 Interview-Free Activation Instrumentation**
- New analytics events mark when a learner becomes eligible for the practice-first branch and when they adopt the matched plan, so the activation funnel can be read from behavior instead of user interviews (which have gone unanswered for this product).
- Quick Review start/completion remains the existing generic signal for practice-started/completed once the learner taps Continue Studying.

## Polish & Fixes

- Fixed a pre-signoff finding from live testing: the original design landed the learner directly inside a Quick Review session on the first ready note, which felt jarring and disoriented for a brand-new learner. Changed to land on the adopted Review Set's detail page instead, and removed the now-unneeded first-ready-note resolution logic and its analytics event as a result.
- Fixed the Confirm & Practice screen's step header, which literally read "Step 3 of 5" with a partial progress bar even though it's the last screen this cohort sees. It now displays "Step 5 of 5" with a full bar; this is display-only and does not change the underlying step state or Back/transition behavior.

## Known Limitations

- **This release's own acceptance signal has not been read yet.** The pre/post W1→W2 retention comparison (pre-ship create-first cohort vs. post-ship practice-first cohort, on the same covered course/program tracks) requires a minimum ~14-day window after onboardings complete on both sides of the ship date, per `docs/claude-prompt/company-redefinition-out/02-activation-onboarding.md` Section 3.5. This release ships the instrumentation to make that read possible — it does not resolve it. The product owner has explicitly chosen to proceed to Phase 2 of the Company Redefinition roadmap (v0.58.0, Explore Convergence) without waiting for this read to come back.
