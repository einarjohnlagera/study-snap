# Release Notes: v0.124.0 — Collection Path Performance

## Release Theme
Opening a Study Plan — and opening its builder — stops making requests nobody needed: a 20-plan Review Set now renders in 3 requests instead of 22, and opening any collection no longer downloads your entire note library first.

## Key Features

**⚡ A Goal's builder loads in one batch read**
- Building a Review Set used to fetch each Subject plan separately — a plan with 20 subjects cost 22 requests to draw one page, all fired at once against a connection pool of 20.
- It is now three: the plan, its shape, and one read that returns every subject's notes together.
- The page looks and behaves exactly as before. Nothing about how subjects, sections or notes render has changed.

**📚 Opening a collection no longer downloads your whole library**
- Every time you opened a Study Plan, the app quietly fetched every note you own — with previews attached — to work out two things. For most people both were thrown away.
- One of them, the Study Pack behind the Board Exam button, now arrives with the plan itself at no extra cost. The other only matters to admins, so only admins fetch it.
- For a curator with hundreds of notes this is the largest single saving in the release.

**👩‍🏫 Curators stop loading the builder twice**
- Opening the builder ran the entire load a second time, but only for teacher accounts — the label for a plan resolves a moment after the page starts, and that alone re-triggered the load.
- A curator was paying double for the very pages this release exists to make cheaper.

## Polish & Fixes
- The Board Exam button now resolves its Study Pack from the plan itself rather than from a library-wide lookup.
- Publishing a plan is blocked while the check for private notes is still running, instead of appearing available and then being refused by the server.
- A new internal field added for the plan page is deliberately withheld from the public, sign-in-free collection view.
- Notes added to a plan without a page refresh now carry their Study Pack straight away.
- Corrected the previous release's notes: its lazy note list covered the builder only, not the collection page. That half shipped here.
