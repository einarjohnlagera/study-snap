# Release Notes: v0.140.0 — Pending Work in Reach

## Release Theme
Arranging a long review set meant working hundreds of pixels away from the only button that saved it — the control now follows you down the page, and leaving with unsaved changes finally offers more than "lose it or stay".

## Key Features

**📌 The Save control follows you down a long plan**
- Rearranging notes used to leave the Save and Discard buttons stranded in a header that scrolls out of view — on a 79-note review set, a curator was working far below the only control that commits their work
- A bar now sits at the bottom of the builder whenever there are unsaved changes, carrying the status plus Save and Discard, and disappears the moment there is nothing pending
- It reads **Drag changes not saved**, which is true of exactly what is waiting: choosing a section from the dropdown already saves immediately, so only what you dragged is pending
- On a phone the bar steps aside for your navigation rather than sitting on top of it

**🚪 Leaving with unsaved changes offers three choices, not two**
- The old prompt asked only whether to leave and lose your arrangement, or stay — so a curator who had genuinely finished had no way to leave *with* their work
- You can now **Save and leave**, **Discard and leave**, or **Keep editing**
- If saving fails you stay exactly where you are, with your arrangement intact and a retry — leaving is never the consolation prize for an error
- Opening a link in a new tab is left alone, since that never puts your arrangement at risk

## Polish & Fixes
- Corrected three backlog entries that described work as outstanding when it had already shipped — one of them by 39 releases — so future planning stops re-proposing finished features
- Repaired eight tracker rows whose contents had shifted into the wrong columns, recovering eight review dates that had been silently misfiled
- Measured two long-standing cleanup items that had been recorded as unmeasured: 89 notes carry a title the bulk generator overwrote, and that has not happened since early August
- Diagnosed a genuine display fault in generated quizzes, where a currency amount and a formula in the same sentence can collide and print the formula as raw markup — recorded with its real cause for a future release, not fixed here
- The release process now updates a backlog entry when the work it describes actually ships, rather than only when it is proposed
