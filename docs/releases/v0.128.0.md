# Release Notes: v0.128.0 — Onboarding Unfrozen

## Release Theme
New learners now pick their course or program from the live catalog during signup, so the answer that drives everything downstream matches what the product actually offers.

## Key Features

**🎓 Catalog-first Course / Program in onboarding**
- The signup screen now suggests programs from the live catalog first, with the built-in list kept underneath rather than replaced
- Onboarding was the last of five places still using only the built-in list — and the one that matters most, since almost every account sets its program here and nowhere else
- You can still type your own program. The field is not locked to the catalog, and there is no request-and-wait queue
- If the catalog is slow or unavailable, the screen falls back to the built-in list instantly and signup is never blocked

**📊 The measurement that was missing**
- Choosing a program during onboarding is now recorded the same way the other four surfaces already record it, so it is finally possible to see whether catalog-first ordering changes what learners actually pick
- Until now that signal was collected everywhere except the one screen where most learners answer the question
- Returning to change only your learner level does not re-record a program you never changed

## Polish & Fixes
- Removed a test that deliberately held onboarding on the old built-in list — it was protecting a signup measurement that has since been taken and closed out, and it was replaced with tests covering the new behaviour in both directions
- Corrected a planned item that had already shipped nine days earlier: Study Pack summaries have rendered maths since v0.96.0, and the release was opened describing code that no longer existed
- Closed two tracker entries that outlived the work they described — a learner-facing staleness signal fixed in v0.116.0 and an exam-date data-loss fix shipped in v0.127.0 were both still listed as open
- Corrected three documents that still described the onboarding freeze as active, including one that contradicted itself and one the release tracker depends on
- Trimmed the release history and roadmap baseline back to the current version plus the last five, moving the older entries into the archive verbatim
