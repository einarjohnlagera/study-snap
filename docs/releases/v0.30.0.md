# Release Notes: v0.30.0 — Readiness Signals

## Release Theme
Make Progress an honest, complete readiness picture for students and exam-takers: every practice mode now moves Progress, exam questions are tagged with the source pack's real key concepts, and Progress finally distinguishes a concept you keep getting wrong from one you have never practiced.

## Key Features

**📊 Exam Practice Now Feeds Progress**
- Long Exam, Board Exam, and Interview Practice completions now record fully-correct concepts into `ConceptHealth` — the only store the Progress page reads — so exam-takers no longer grind for hours against a flat Progress page.
- Recording mirrors the existing `recordCorrectAnswers` contract in `LongExamService` (Long + Board) and `InterviewPracticeService`: no new entity, no new quota, no parallel mastery store.
- Concepts are recorded per source Study Pack and intersected with that pack's `keyConcepts`, so non-matching free-form labels are dropped rather than written as invisible orphan rows; missing or unreadable source packs are skipped and completion still returns its report.

**🎯 Source-Constrained Key Concepts**
- Long Exam and Interview Practice generation now emit a separate per-question `keyConcept`, schema-enforced (OpenAI strict structured output) to an enum of the source pack's key concepts, so recording matches almost always — without fuzzy or semantic mapping.
- The report-facing `concept` label is left untouched: Long Exam keeps its free-form domain breakdown and Interview Practice keeps its senior-framed strengths/gaps.
- Completion recording prefers `keyConcept` and falls back to the free-form `concept` for legacy sessions and pre-warmed pool questions, so there is no pool migration; non-exam quiz schemas are unchanged.

**⚠️ Weakness Signal Across All Modes**
- `ConceptHealth` now records `lastIncorrectAt` alongside `lastCorrectAt` and derives a "struggling" state when the most recent signal is a miss, so Progress can tell a concept a learner keeps getting wrong apart from one they have never practiced.
- All six practice modes — Quick Review, Challenge Quiz, Adaptive Practice, Long Exam, Board Exam, Interview Practice — record missed concepts on normal completion (forfeits record nothing), applied uniformly so exams never drift from quizzes.
- The struggling state self-clears on a clean retake (a later fully-correct session updates `lastCorrectAt`), and Note Detail surfaces a "Needs work" indicator beside the existing "Due" chip.

## Polish & Fixes
- `recordCorrectAnswersForKnownConcepts` / `recordIncorrectAnswersForKnownConcepts` keep the "only record real key concepts" rule in one place, so the exam write paths cannot create orphan rows.
- `QuizItem` gained a nullable `keyConcept` added additively (no existing constructor signature changed; `@JsonIgnoreProperties(ignoreUnknown=true)` keeps old sessions and pool questions deserializing to `null`), preserved across every reconstruction and the session-state round-trip.
- `keyConcept` validation normalization was aligned (trim-only) with the schema enum so valid tags are never dropped.
- Adaptive Practice now treats an available concept breakdown as authoritative for both correct and missed concepts, preventing a missed concept from being double-recorded as correct (which would have canceled its struggling state for exactly the learners the signal targets).
- `V75` adds `last_incorrect_at` and drops the `NOT NULL` constraint on `last_correct_at`, since a `ConceptHealth` row can now originate from a miss; existing rows are unaffected and need no backfill.
