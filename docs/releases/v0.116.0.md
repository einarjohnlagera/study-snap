# Release Notes: v0.116.0 — Additive Review Set Updates

## Release Theme
A Review Set you adopted can now pick up the topics its author has added since — without touching any of the work you have done inside it.

## Key Features

**📥 Your adopted Review Set can catch up**
- When the author of an Official Review Set adds new topics, your copy can now take them. Until now it could not: your plan was a snapshot frozen at the moment you adopted it, and pressing Adopt again did nothing at all.
- You choose when to apply. Opening the plan shows you what is available; nothing changes until you say so.
- Only additions are applied. If the author renamed a section, reordered it, retired a topic or moved something, you are told — and your own plan is left exactly as you arranged it.

**🔒 Your work is never overwritten**
- Notes you have edited, your study history, your quiz results and anything you added yourself are untouched by an update.
- If you removed an upstream topic on purpose, a later update will not put it back.
- Applying twice does nothing the second time, and a note you already hold is never added again as a duplicate.

**🧭 Plans whose source is gone still work**
- If the original Review Set is taken down, your adopted copy carries on as normal. It simply stops offering updates, and says so plainly rather than failing.

**📖 You are told when a Learning Companion no longer matches your plan**
- A Companion is written for a plan as it stood at a particular moment. If your plan has changed since, you now see a short note saying so, instead of quietly following guidance that no longer fits.

## Polish & Fixes
- Adding upstream topics no longer risks duplicating notes you already hold when the author reorganises a Review Set into sections.
- Fixed a fault that could silently hide the update panel entirely for plans adopted before their source was reorganised.
- Applying additions no longer clears the notices about renames and reordering you have not acted on yet.
- Corrected several help and reference documents that still described adopted plans as permanently frozen.
