# Release Notes: v0.78.0 — Post-Mastery Next Step

## Release Theme

A learner who has just mastered a pack is told what to study next, instead of being left on a screen whose only remaining action was a quiz.

## Key Features

**🎯 Next in your plan**
- Mastering a Quick Review now offers the next note in your Study Plan alongside `Take a Challenge`, where the screen previously offered nothing at all
- "Next" is the first note in the plan you haven't practiced yet, in the plan's own order — so it never suggests something you've already finished
- When a note belongs to several plans, your Primary Review Set wins; otherwise the most recently updated plan containing it
- No plan, or a plan you've finished, stays silent — no placeholder, no filler card

**📚 A Study Plan recommendation, by name**
- The Dashboard now names one official Review Set matched to your course or program, with how much of it is ready to practice, instead of a generic "browse curated plans" pointer
- The same named plan fills the post-mastery slot when the note you just mastered isn't in any plan
- Nothing is recommended when no plan matches your program, or when you've already adopted it — the surface falls back to the Explore pointer rather than showing an empty invitation

**📊 Measurement for both**
- Impression and click events on the Dashboard recommendation, the pointer it replaces, and the post-mastery slot
- The `Next in your plan` action is instrumented too, so whether learners take the suggestion is answerable rather than assumed

## Polish & Fixes

- Practice state has exactly one definition across the whole feature — the same `lastSessionCompletedAt` the plan's progress counter uses, which also credits Board and Long Exam sessions that a per-note check would miss
- The post-mastery plan recommendation links to Explore's Review Sets tab, not the owner-scoped plan page, which returns "not found" for a plan you haven't adopted
- The Dashboard no longer fetches public plans for learners who already have a Primary Review Set, and fetches once rather than twice for everyone else — a doubling that had also reached onboarding
- Learners who have already adopted the matched plan keep the Explore pointer instead of an empty Dashboard slot
- The Primary Review Set card's detail line is unchanged for learners who have one
- Indexed `note_collection_items(note_id)`, which the new lookup filters on after every completed session

## Known Limitations

- The ~23 Study Packs still rendering raw LaTeX were scoped into this release but not regenerated; they are carried forward, and nothing is broken on screen because the display-time normaliser handles it
- A recommendation is only offered for the most recently updated published plan in your program; if you've already adopted that one, no alternative is suggested
- Click events fire before adoption is attempted, so they measure clicks rather than completed adoptions
- The Dashboard and post-mastery surfaces can name different plans in the same sitting for a learner who has a Primary Review Set but masters a note outside it
