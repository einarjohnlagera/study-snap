# Release Notes: v0.17.0 — Quiz Quality & Depth

## Release Theme
"Quiz Quality & Depth" — richer question format variety (True/False, multi-select, matching), generation quality fixes across all quiz modes, and computational questions with step-by-step working solutions for engineering and sciences notes.

## Key Features

**📋 Question Format Variety**
- **True/False** — 2-choice questions for factual recall, definitions, and binary classification; capped at 25% of any quiz set; choices never shuffled (always True first, False second)
- **Multi-select** — "Select all that apply" questions with 2–3 correct choices; all-or-nothing v1 scoring; available in all modes except Board Exam
- **Matching** — shared-option blocks of 2–4 consecutive questions mapping named items to a common set of labels; per-item scoring; available in all modes except Board Exam
- All three formats are plan-agnostic

**🔢 Computational Questions + Working Solutions (Pro)**
- Engineering, sciences, and finance notes now generate `COMPUTATIONAL`-type questions with numerical answer choices and formula-based distractors
- Step-by-step working solution displayed after answering for Pro users; teachers see it unconditionally in the quiz preview before export
- "AI-generated — verify calculations" disclaimer shown on all working solution panels
- Non-quantitative notes are unaffected — detection is heuristic-based on subject, tags, and note content

**🎯 Quiz Generation Quality**
- Explanations no longer echo answer choices by letter or text — each explanation explains WHY the answer is correct only
- Distractor independence enforced: no two questions in the same quiz share an identical choice set (excluding deliberate MATCHING blocks)
- Question framing variety: prompts now distribute across positive (~40%), NOT/EXCEPT negative (~25%), best-describes (~20%), and assertion-style (~15%) framings across Quick Review, Challenge Quiz, Board Exam, Long Exam, and Teacher Quiz

## Polish & Fixes
- Study Pack key concepts schema reliability — `keyConcepts` schema now accepts 5–10 items and coerces the `key_concepts` alternate field name; reduces intermittent "invalid key concepts" generation failures
- Library filters consolidated into a single "More Filters" modal (Filter/readiness, Subjects, Popular Tags, Course/Program); active filters shown as removable blue chips below the search bar
- AI subject suggestion no longer echoes the course/program name as the subject — derives the specific academic sub-field from note title and content instead
- Long Exam pre-start screen shows a contextual hint when the user has only one note for the subject, guiding them to create a second note to unlock multi-note exam mode
- Long Exam pool generation: when one parallel batch fails, the succeeded batch is salvaged and only the remaining questions are regenerated — cuts fallback latency roughly in half
