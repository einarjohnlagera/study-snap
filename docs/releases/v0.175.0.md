# Release Notes: v0.175.0 — Quiz Ready

## Release Theme

Challenge Quiz is now prepared in the background and waits until you're ready: your timer and monthly attempt
start only when you press Start quiz.

## Key Features

**⏳ Prepare now, start when you're ready**
- "Prepare quiz" gets your questions ready in the background, and you can keep reviewing in the meantime.
- When it's ready you land on a short briefing: the question count, the time limit and the notes it covers.
  Then press "Start quiz" whenever you like.
- Your timer and monthly attempt start only when you press Start quiz. Leaving, a failed preparation,
  discarding or an expired quiz never uses an attempt.
- An unstarted quiz stays ready for 7 days.

**🔔 A notification when your quiz is ready**
- If you leave while your quiz is being prepared, you get one in-app notification when it's ready.
- It opens that exact quiz safely, whether it's ready, still preparing, already started or expired.

**📚 Faster, steadier multi-note quizzes**
- Quizzes built from several notes are now prepared in the background, with each note's questions prepared
  in parallel.
- Questions you've already worked on are reused first, so preparing the same notes again is quicker.
- If a note can't be used, your quiz is still ready as long as it has at least two-thirds of the questions
  from at least two-thirds of the notes. It tells you clearly when it has fewer questions than requested.

**➕ Add more questions without waiting**
- "+5 questions" now adds questions in the background while you keep answering. Your answers and progress
  are never touched, and your timer is never paused.
- You can stop adding at any time, and an "Adding questions…" status shows on every question while it works.
- Complete Quiz waits for a moment while questions are being added, so you never submit before seeing them, and never for long.

**🧠 Smarter question choices on every plan**
- Challenge Quiz now uses the AI setup that matches your plan, following the same approach as Study Packs.
- The models switch on separately, after this release is live.

## Polish & Fixes
- Choosing Challenge Quiz now opens a quiz you already prepared, instead of asking you to prepare it again.
- A compact "Continue where you left off" card shows your prepared or in-progress quiz with one clear action.
- If you ask for a different set of notes than the quiz you already prepared, NoteLib now asks before
  replacing it, instead of quietly reopening the old one.
- Two-statement questions now have their answer key checked for consistency before they're used.
- An optional independent check of two-statement answer keys is built in, and stays switched off until it's
  validated further.
- Older two-statement questions are no longer reused from your question pool. New ones are generated with the
  newer checks in place.
- Questions from quizzes you discard or finish are released back to your pool correctly, including quizzes
  built from several notes.
- Stuck or expired preparations clean themselves up automatically, and never use an attempt.
- Friendlier, clearer wording throughout the Challenge Quiz flow, following NoteLib's new voice guidelines.
- Starting Redo Missed Questions while you have a Challenge Quiz in progress now asks first: resume your quiz, or end it and redo missed. Nothing is ended without your choice.
- A quiz you abandoned part-way is cleaned up automatically after its time runs out, and its questions return to your pool.
- A quiz that was ended in another tab now returns you to setup instead of leaving a stuck screen.
- +5 questions no longer repeats questions from your note's saved quiz, and keeps working if one of the notes in a multi-note quiz was deleted.
- If you finish while extra questions were still arriving, only the questions you actually saw are scored.
- Review Set and teacher entry points open the same first screen as before this release.
