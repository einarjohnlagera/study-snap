# Release Notes: v0.108.0 — Session Identity

## Release Theme
The product now knows which kind of practice session you have open — so it stops offering you one mode's session under another mode's name, and stops charging you to pick up where you left off.

## Key Features

**🧭 The Right Session, Under the Right Name**
- An in-progress Interview Practice session now appears as its own *Continue Studying* card and opens Interview Practice
- Previously it was offered as Adaptive Practice and led to a page that declined to open it
- Your session is routed to, not hidden — an active session you cannot reach is worse than one you can

**🔓 Resuming Never Costs You Anything**
- Picking up an in-progress plan session no longer checks your monthly limit or spends rate-limit budget
- A learner at their monthly limit can still finish a session they already paid for
- Only *starting* a session consumes anything

**⚡ Faster Plan Practice on Large Review Sets**
- Working out which notes a plan session should draw from now reads only the fields that decision needs
- A large Review Set no longer loads every note's full quiz and summary to choose a handful
- Full content is loaded only for the notes actually selected

## Polish & Fixes
- Interview Practice sessions no longer receive Adaptive Practice's "what's next" copy
- Removed a collection endpoint that duplicated what starting a session already does
- Coverage sampling keys on plan identity rather than plan title, so two same-titled plans stay distinct
- Pinned the emitted SQL for the read-path projection, so a future change cannot quietly make it load full rows again
