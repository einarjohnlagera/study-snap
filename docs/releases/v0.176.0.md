# Release Notes: v0.176.0 — Challenge Quiz Quality

## Release Theme
Test, before changing anything, whether better Challenge Quiz wording makes questions harder to guess and more meaningful, and ship nothing unless it provably does; the evidence said it does not yet, so the production prompt is unchanged.

## Key Features

**🧪 A Blind Evaluation Method for Quiz Quality**
- A test-scope harness generates Challenge Quiz questions under the current and a proposed prompt for the premium and the free-plan model, exports them blind, and calculates eight pre-registered gates offline.
- Scoring is separated from generation: Codex scores every question blind, cold Opus reviewers re-score a stratified sample and every flagged item, and disputes go to fresh adjudicators.
- Every fixed value, hash and deviation is recorded in a pre-registration that was committed before any paid run, with dated amendments for each change.

**📊 The Result: HOLD, Nothing Shipped**
- On the premium model the proposed wording cut serious giveaways (2.7% against 4.5%) but made questions easier: mode alignment fell from 4.23 to 3.81, cognitive demand from 3.47 to 2.90, and distractors did not improve, so three gates failed.
- Both models must pass, so the evaluation is HOLD: the Challenge prompt, the measurement log and every deploy are unchanged or unbuilt.
- The proposed wording is not shipped, and the evidence points away from shipping it as written.

**🔎 A Finding About Today's Prompt**
- On the current prompt the free-plan model scored weaker than the premium model: distractors 3.23 against 3.75, mode alignment 3.36 against 4.23, a 10.5% giveaway estimate against 4.5%, and 5 confirmed critical defects in 300 questions against none.
- This matches the learner feedback that started the release. It is an internal finding and never appears in customer copy.
- A Luna-first follow-up is recorded as a candidate, not approved.

## Polish & Fixes
- Review batches no longer abort on a malformed primary score row; the arm is marked incompletely scored and the item goes to independent review (PR #1537).
- The audit that voids a scoring pass on a forbidden-file mention now matches real file names, after the word "manifest" matched "clinical manifestations" in a nursing note.
- Reviewer passes are accepted only after the harness's own validator checks every row of every arm, because the gate report's loader silently accepts invalid rows in ungated arms.
- Spend stayed under the cap: about $3.03 by the meter against $4.00.
- No production code, prompt, schema, pricing, quota or entitlement changed, and the release is not merged to `main`; the harness reaches `main` inside the next release.
