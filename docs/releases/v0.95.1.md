# Release Notes: v0.95.1 — Rendering and Reorder Fixes

## Release Theme
A generated formula should look like a formula, dragging a section should not fight the save the last drag started, and a filter you set should still be there when you get back.

## Key Features

**🧮 Formulas render as formulas**
- Full Notes and the public note page now display maths properly instead of printing the LaTeX source
- Older notes written before formulas were marked up are repaired as they are shown
- The Summary tab is not covered yet — that needs a different fix and is coming next

**🖱️ Dragging sections is responsive and no longer fights itself**
- Reordering no longer reloads your whole note list, which is what made it feel slow on a large plan
- A drag that lands while a save is still running is refused instead of quietly corrupting the order
- The page now tells you when a save is in progress, so it is clear why dragging is paused
- A drag no longer starts on the first pixel of movement, so clicking a section name to rename it works reliably

**🔎 Your library filter survives**
- Deleting a note returns you to the filtered list you were in, not to the whole library
- A note opened from a Review Set now returns to that Review Set after deletion
- A filter that happens to match nothing shows an empty library, instead of silently clearing itself and showing everything

## Polish & Fixes
- Filter controls stay visible while their filter is active, so you can always clear a filter where you set it
- The section rename field no longer competes with the drag handle for the same click

## Known limitations
- The Summary tab still shows LaTeX source rather than rendered maths. Fixing it requires a markdown-aware change that also touches the onboarding screen, which is under measurement until 2026-09-11.
- Dragging still saves on every drop. The agreed direction is to let you drag freely and save once, explicitly; everything in this release is a step toward that rather than a substitute for it.
