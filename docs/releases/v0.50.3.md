# Release Notes: v0.50.3 — Public Note Copy Flow & Related-Notes Consistency

## Release Theme

Fix a real bug in the public note "Quiz yourself" flow — it could force a full Study Pack regeneration and cut off the AI-suggestion modal — plus two small consistency fixes on the same page's related-notes sections.

## Key Features

**🎯 Public Note "Quiz Yourself" Copy-As-Is Flow**
- Tapping "Quiz yourself on this note" on a public note now always copies the source Study Pack as-is and goes straight into Quick Review — it no longer sometimes forces a full regeneration that silently rewrote the summary and key concepts you never asked to change.
- The CTA now only shows when the source note actually has a ready Study Pack with a quiz; in the rare case a source pack becomes unavailable mid-copy, you land on your new note's normal detail page with the usual manual Generate action instead of a broken auto-redirect.
- Fixed the underlying race condition where an automatic Quick Review redirect could fire before a real generation's AI-suggested-metadata modal had a chance to open — the modal decision now always resolves first.

## Polish & Fixes

- Public note detail's two related-notes sections ("More {Course/Program} notes", "More in {Subject}") now share the same `See all →` link wording (with a full `aria-label` for accessibility) instead of wrapping onto two lines on mobile for longer subject/course names.
- The subject section's card grid now matches the course/program section's two-column layout instead of using three columns.
- Consolidated GPT context handoff docs (`GPT_CONTEXT.md` and the new Notes/Collections structural reference) into `docs/gpt-contexts/`, alongside the existing marketing context docs, with a README index.

## Known limitations

None specific to this release.
