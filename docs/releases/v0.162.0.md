# Release Notes: v0.162.0 — Say the Value

## Release Theme

A quiz explanation for a numeric answer now says what the answer actually is, and regenerating a Study Pack finally clears out the old Challenge Quiz questions it used to leave behind.

## Key Features

**🔢 Explanations now state the number**
- For a multiple-choice question where every option is a number or a measurement, the explanation must now state the correct value — the same one that appears in the answer choices — instead of talking around it.
- It still never spells out the answer as a letter ("option C"), and it still doesn't discuss why the other choices are wrong.
- Prose-answer questions (the large majority) are unaffected — this only changes numeric-answer questions, where withholding the value made it harder to catch a question whose stored answer key didn't actually match its own explanation.

**🧹 Regenerating a Study Pack now clears its Challenge Quiz bank**
- Challenge Quiz keeps a small bank of previously-generated questions per Study Pack so a returning learner doesn't always wait on new ones. Regenerating a Study Pack's content used to leave that bank untouched, so Challenge Quiz could keep serving questions built from material that no longer existed on the note.
- Regeneration now clears that bank, including your recorded right/wrong history on those questions. `Redo Missed Questions` will stop offering questions from content that's gone, for the same reason.
- If you're the author of an Official, publicly-reused Study Pack, its shared Challenge Quiz questions are automatically rebuilt after a summary-only repair, without you needing to do anything.

**🔍 A completed audit, no code change**
- We read a sample of real generated quiz questions by hand to check for a different kind of problem: not "does the explanation match the answer," but "does this question actually have one clearly correct answer at all." We found no confirmed cases.
- Because a hand-read sample can't rule out something rare, the recommended next step isn't an automatic checker — it's giving you a way to flag a question you think is wrong, which doesn't exist yet. That's a decision for a future release, not something this one builds.

## Polish & Fixes
- Fixed a real correctness gap found while reviewing this release before signoff: the automatic check that catches a quiz question whose stored answer disagrees with its own explanation could be fooled by a minus sign — a question keyed to `0.40` with an explanation that actually said `-0.40` was read as matching. Fixed and covered by a new test in both directions.
- The letter-based answer format (`A`/`B`/`C`/`D`) is unchanged this release — a separate, larger change to make the answer key store the actual text instead of a letter position was approved in principle but deliberately deferred to its own future release, so its effect can be measured on its own.
- A known, narrow limitation: if you tap "+5 more questions" in Challenge Quiz at the exact same moment you regenerate that Study Pack, a few of those new questions can be built from the content that's about to be replaced and survive the cleanup. This needs a larger change to close properly and is tracked for a future release.
- Multiple Opus-model cold reviews (independent agents given no context from this release's own work) checked this release before signoff — one on the Challenge Quiz bank change before it merged, one across the whole release at its final merged state; every finding was either fixed or is recorded as a known limitation in `RELEASES.md`.
