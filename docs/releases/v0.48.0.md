# Release Notes: v0.48.0 — Retention Experiment: Open Loop & Digest Trigger

## Release Theme

Test the two co-dominant causes identified in the retention root-cause diagnosis — a first quiz that ends in psychological completion instead of an open loop, and retention infrastructure that ships default-OFF and never gets exercised — with two independent, cheap experiments.

## Key Features

**🔁 Open-Loop First-Quiz Ending**
- A learner's first-ever completed quiz (Quick Review or Challenge Quiz, determined from activity history) now sees an `N of M concepts secured` header instead of a terminal "Your results" screen when concepts were missed, followed by a tomorrow-review prompt — leaving an explicit open loop rather than a closed, complete-feeling result.
- Perfect first scores, quizzes with no tagged concepts, and every later session keep the existing "Your results" framing — only a learner's genuinely first, genuinely incomplete session gets the open-loop copy.
- The secured count is derived from the same answer state that's already in memory on the result screen, so it stays identical for FREE and PRO users answering the same questions, independent of any plan-gated feature.
- Scores, next-step recommendations, and concept-health tracking are unchanged — this only changes how the existing result is framed.

**📧 Due-Concepts Digest Trigger Fix**
- New signups (both email/password and Google) now start with the weekly due-concepts digest enabled by default, replacing reliance on a feature that previously shipped opt-in-only and was rarely turned on.
- Existing users' preferences are completely untouched — no retroactive opt-in, no change to anyone who didn't already have this on.
- The digest email's call-to-action is now a styled button instead of a bare printed URL, with a plain-text fallback link retained for clients that strip styling.
- The existing Settings toggle and one-click email unsubscribe both continue to work exactly as before for anyone who'd rather not receive it.

## Known Limitations

- **Both experiments are unproven, not confirmed wins.** This release ships the mechanisms; it does not yet include a lift measurement. Whether either change actually moves week-1→week-2 retention is a follow-up analysis, not something this release claims.
- **The digest trigger has a delayed, narrower reach than it might sound.** A brand-new signup has zero due concepts until they've studied enough to accrue some — the digest only reaches learners who already returned at least once, not someone who never comes back after their first session. That gap is exactly what the open-loop experiment is aimed at instead.
