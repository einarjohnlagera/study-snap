# Release Notes: v0.23.0 — From Readers to Learners

## Release Theme
"From Readers to Learners" — NoteLib's public notes already pull in real discovery traffic; this release turns that traffic into active learners by making it one tap to start practicing and one share to spread a note.

## Key Features

**🎯 Quiz Yourself on Any Public Note**
- "Quiz yourself on this note" is now the primary action on every public note page
- New here? Tap it, create a free account, and land straight in a practice quiz on that note — no detour through setup
- Pages stay read-first and SEO-friendly; only the call-to-action changed

**🔗 Rich Share Cards for Public Notes**
- Sharing a public note link now shows a custom preview card with the note's title, subject, and number of practice questions
- Designed to be far more clickable in feeds and study-group chats than a generic logo

## Polish & Fixes
- Free plan now includes 10 AI note generations per month, up from 5
- Private Library subject chips now reflect your active filters — filter by a course or program and the subject breakdown updates to match what you're viewing
- Smoother, more reliable public-note sharing metadata across social platforms
