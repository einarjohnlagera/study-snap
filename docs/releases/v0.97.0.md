# Release Notes: v0.97.0 — Connection Lifecycle

## Release Theme

An unconfirmed connection request no longer sits forever holding someone's declared birth year — and the connection surface is honest about who it is waiting for, what it keeps, and what it requires.

## Key Features

**⏳ Unconfirmed requests now expire**
- A connection request that is never confirmed lapses after 30 days and reaches a new `EXPIRED` state
- The person's declared birth year is deleted with it, so an unconfirmed redemption leaves nothing behind
- Every pending request shows its deadline, so it can be acted on before it lapses
- Expiry reads as a timeout, distinctly from someone deliberately ending a connection
- An accepted connection never expires, and neither does one paused while guardian consent is re-confirmed

**🔐 Your provisional birth year appears in your data export**
- A year declared while redeeming an invitation link is now included in the account export, listed separately from your account birth year
- Each declaration shows which connection it belongs to and when it was made
- Only your own declarations are ever exported

**🤝 Supporter onboarding is defined**
- First-run orientation for the supporter role: what you will see, what you will never see, and who acts next
- States the privacy line plainly — a supporter never sees the learner's notes, under any permission
- Delivered on the connection surfaces, leaving the signup flow untouched

**🧹 Ending a connection now ends its sharing**
- Revoking or expiring a relationship withdraws every permission on it, in both directions
- Pausing for guardian consent deliberately does not, so sharing resumes when the connection does

**🔑 Invitation links require a finished account setup**
- All five invitation-link actions now require completed onboarding, not just a verified email
- Arriving at an invitation mid-setup takes you to finish setting up, then returns you to the invitation

**✍️ Curated note titles name the knowledge in both AI prompts**
- The title rule now governs the note draft as well as the Study Pack, as one shared rule rather than two wordings

## Polish & Fixes

- Expired connections no longer appear as live on the dashboard
- The help centre explains request expiry, including what it means for a request awaiting a guardian's permission
- The landing page no longer claims that accepting a connection lets you see someone's progress — sharing is always the learner's choice, and that claim had been inaccurate for several releases
- Study-plan and connection documentation corrected against the shipped behaviour
- Retired planning documents removed, and every remaining one indexed
- Scheduled background jobs no longer run during the test suite, removing an intermittent build failure
