# Release Notes: v0.92.0 — Activity Sharing

## Release Theme
Let a connection see that you are studying — only if you decide to show them — and tell people what a quiz costs before they spend it.

## Key Features

**🤝 Directional activity sharing**
- Share your study momentum with an accepted Learning Connection: streak, longest streak, and study days this week
- Sharing is off until you turn it on — accepting a connection grants nothing, it only creates the capacity to grant
- Each direction is independent: showing your activity to someone does not show you theirs, and either side can turn it off at any time
- Turning it off, revoking the connection, or a birth-year correction that pauses it all cut access on the very next request
- Momentum shows streaks and study days only — never scores, mastery, your notes, or what you studied

**📊 A momentum view built on what you already do**
- Reuses the study activity NoteLib already records, so nothing new is tracked and merely opening a Study Pack still does not count as studying
- Zero activity renders as an honest empty state rather than being hidden — nobody studying is a real answer
- Viewing someone's momentum writes nothing to either person's learning state

**🧾 "AI quizzes" — one meter, honestly named**
- The monthly generation allowance is spent by both Challenge Quiz and quizzes you make for someone else, so it is now labelled *AI quizzes* everywhere a usage meter appears
- The Challenge Quiz mode keeps its own name wherever it names the mode
- Fixes three different labels for one counter across the Dashboard, Settings, and the API

**🔗 Know your share-link budget before you spend**
- The *Quiz for someone* dialog now shows both AI quizzes remaining and share links remaining before you generate
- Running out of share links no longer surprises you after the quiz is already made — the quiz can still be created and exported
- Nothing about the limits changed; they are simply visible now

## Polish & Fixes
- Fixed a defect where *Shared with you* in the Library never loaded at all — the endpoint failed on every request, including the first page
- The Help Center now explains activity sharing, including that connecting alone shares nothing and that sharing works one direction at a time
- Help Center plan limits now come from a single source instead of being retyped, so they cannot drift
- The owner-facing share list no longer shows people whose connection has lapsed and who can therefore no longer open the note
- A learner's practice session is now denied rather than allowed when a permission check itself fails, while a Study Pack that simply cannot be read still never strands their own session
- Guardian consent is re-checked on every activity read and denies when a learner's age is unknown
- Fixed a screen-reader issue where the note access menu announced itself as a menu while containing a checkbox list
- Added a build-time guard that catches an entire class of database query defect the test suite structurally cannot see
