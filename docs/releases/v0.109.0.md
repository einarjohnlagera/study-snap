# Release Notes: v0.109.0 — Assessment Discoverability

## Release Theme
Four releases rebuilt what an exam and a practice session are. This one tells you.

## Key Features

**📖 The Guides Describe the Product You Actually Have**
- The Board Exam guide now says an exam is drawn from your whole Review Set, and that launching from a Subject Plan still covers the set it belongs to
- It no longer advises "one note per topic" — that had quietly become the *smallest* possible Board Exam
- Long Exam is described as spanning a Subject Plan, and Adaptive Practice as targeting what is due or what you keep missing, rather than only your last quiz

**📣 A Heads-Up Where Your Plan Lives**
- A one-time note on a plan page tells you practice and exams now cover the whole plan
- It appears once, and never competes with the target-date prompt a newly adopted plan shows first

**🎯 Plan Practice Reaches Every Plan**
- Practising across a plan is now offered on single-subject plans, not only on plans that contain other plans
- Previously that action was missing entirely from a plan with no children

## Polish & Fixes
- Added the two plan-scoped launch points to the entry tracking table, which claimed to list every one but omitted them
- Both assessment checkpoints are dated again, now that the capability has been announced
