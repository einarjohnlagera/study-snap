# Release Notes: v0.67.1 — Explore Convergence Follow-ups

## Release Theme

Close out the follow-up bugs `v0.67.0`'s own pre-signoff pressure test found in Explore, Exam Hub, and Dashboard — plus two further pre-existing bugs surfaced on review and one dark-mode contrast bug found from a live screenshot.

## Key Features

**🌓 Explore's Selected Tab Fixed in Dark Mode**
- The segmented control's selected tab (Review Sets / Notes) was visually indistinguishable from its own container in dark mode — both resolved to the same near-black — so the selection state was effectively invisible.
- Now a solid blue pill in both themes, matching the same pattern already used on the Settings page's billing-cycle toggle.

**🎓 Exam Hub Now Shows "Continue" for Already-Adopted Sets**
- The official-set preview card on Exam Hub pages always showed "Start," even for a signed-in visitor who had already adopted that set — a mislabeled CTA that also re-triggered the (harmless, idempotent) adopt call.
- Now resolves the visitor's real adoption status the same way `/collections/published` already does.

## Polish & Fixes

- Explore's Review Sets tab label no longer collides with `BOARD_EXAM`'s "Review Sets" Collections nav label — now reads "Official Review Sets" (or "Official Study Plans" / "Official Lesson Plans" per profile), disambiguating two different destinations that used to share one string.
- The zero-note Dashboard no longer shows two near-identical "browse a ready-made plan" links stacked on top of each other — the newer pointer card is suppressed there in favor of the original onboarding card's own link.
- `/collections/published`'s contextual back link works again from the standalone Public Library page; from inside Explore, the same "Browse official plans" link now switches Explore's own tab instead of leaving Explore entirely, per this project's "Explore owns discovery" doctrine.
- Two pre-existing bugs, unrelated to `v0.67.0`, were folded in on review: a malformed-but-200 backend response could crash the anonymous Exam Hub page's server render instead of degrading gracefully; and a Dashboard link's course/program filter reached Explore unslugified, so the arriving filter chip never displayed.
- A pre-signoff pressure test (four parallel review agents, plus one independently fact-checking this file's own claims against the real repo and git history) found and fixed two further gaps before shipping: the Exam Hub fix above was missing the same response-shape guard as the crash-risk fix; and the dark-mode contrast fix's new tab color happened to match the existing keyboard-focus ring color exactly, making focus nearly invisible on the already-selected tab.
