# Release Notes: v0.25.0 — Exam Capture & Goal Setting

## Release Theme
"Exam Capture & Goal Setting" — NoteLib now turns exam-community traffic into activated learners. Public exam hubs for ALE, PNLE, and LET funnel anonymous visitors through signup into a confirmed study goal; every returning learner with a goal now sees their mastery % front and center on the dashboard and progress report, and gets nudged toward their goal after every off-goal quiz session.

## Key Features

**🏥 Exam Hub Pages (ALE, PNLE, LET)**
- Public server-rendered landing pages at `/exam/ale`, `/exam/pnle`, and `/exam/let`
- Each hub curates existing public notes by `courseProgram` into featured, popular, and recent sections
- SEO metadata and CollectionPage structured data for exam-community search traffic
- Signup CTA persists the exam intent through the auth flow so new users land in the right context
- Static `/exam` index and a public footer entry point added

**🎯 Exam Goal Setting & Progress Framing**
- New `PUT /users/profile/goal` endpoint; dashboard suggests a goal from the exam-intent cookie first, note `courseProgram` fallback second
- `/progress` now shows an exam goal summary card, overall mastery %, and a next-best-study suggestion linked back to the relevant exam hub
- Dashboard "View full progress report" link is always visible — no longer hidden behind a weak-concepts gate

**📚 Universal Study Goal**
- Goal setting works for all profile types, not just board exam reviewers
- Students can pick any of their note subjects as a study focus
- Progress report shows mastery toward any `courseProgram` goal
- `/profile#study-focus` is the single place to set or change a goal

**💡 Post-Quiz Goal Nudge**
- After any off-goal quiz session (Quick Review, Challenge Quiz, Adaptive Practice, Board Exam Mode), a `GoalNudgeCard` appears below the primary next-step CTA
- Shows current goal mastery % and a direct link to `/progress`
- Long Exam excluded from v1

**📊 Dashboard Goal Card**
- Persistent card for users with an active goal: shows goal name, mastery %, weakest subject "Focus" hint, and a single "View goal progress" CTA to `/progress`
- `GoalPromptBanner` unchanged for the no-goal state

## Polish & Fixes
- Progress added to MAIN sidebar nav (`BarChart2` icon); `ProgressHeader` converted to `BackLink` + `PageHeader` pattern matching Library and Profile
- "View progress report" link moved from inside the Weak Concepts card to inline with the section header (right-aligned, blue)
- Corrected four `BackLink` labels from "Back to Note" → "Note" per back-link standard
- Subject mastery cards now have a mastery-keyed left border accent and matching % text color (gray = not started, rose < 40%, amber 40–60%, blue ≥ 60%)
- Exam hub build fix: `fetchPublicNotes` now catches ECONNREFUSED and returns an empty array; pages prerender to empty state at build time and populate via ISR on first live request
- Renamed `exam_goal` → `study_goal` across DB column, entity, DTOs, services, analytics events (`STUDY_GOAL_SET` / `STUDY_GOAL_DISMISSED`), and all frontend types
- Goal UX consolidated: goal setting lives exclusively in Profile settings; Progress page is read-only mastery view; removed `SetGoalCallout` from Progress to eliminate the circular set/go loop
- Fixed exam hub CTA incorrectly appearing for non-BOARD_EXAM profiles whose `courseProgram` happened to map to an exam slug
- Dashboard goal card now shows `weakestGoalSubject` as a "Focus: [subject]" hint; replaced two inline links with a single "View goal progress" outline button
- Progress page subject cards sorted weakest-first (ascending mastery %); "What to study next" moved above the subject list
- Library "Visibility" filter added to More Filters modal (All / Public / Private chips); fully client-side, URL-persisted, saved-filter-compatible
