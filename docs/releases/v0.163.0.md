# Release Notes: v0.163.0 — No Peeking

## Release Theme

A quiz no longer tells you the answer before you've committed to one, and Challenge Quiz's question bank stops racing itself when a Study Pack regenerates.

## Key Features

**🙈 Every quiz mode now hides the answer key until you've actually answered**
- Long Exam, Board Exam, Challenge Quiz, Interview Practice, Adaptive Practice, and Quick Review all used to send the correct answer and explanation for every question, unconditionally, whether you'd answered it or not — visible in your browser's network traffic from the moment a quiz loaded.
- Every mode now redacts the answer key for a question until you've answered it (or, for Interview Practice, until you've submitted a choice and received its critique). Reviewing your results after finishing still shows everything, exactly as before.
- Your own Note and Study Pack pages, and the DOCX export with answers included, are unaffected by design — those are your own material, and this release closes an accidental quiz-time leak, not access to content you already own.

**🔒 Interview Practice's resubmission exploit is closed**
- Interview Practice used to let you see a question's critique (which reveals the correct answer), then submit a different, now-informed choice for the same question and have it count — even for a different question answered at nearly the same time, where the exploit could hide the erased original answer entirely.
- Both paths are now closed: an answered question locks in its first choice, and answering two different questions at once no longer lets one silently erase the other's stored answer.

**⚖️ Adaptive Practice's score is now entirely server-decided**
- Adaptive Practice's completion used to let the app trust whatever score the client reported, which also fed your recorded concept mastery. Scoring — and everything derived from it — is now computed entirely from what the server has stored, not from anything the client claims.
- Answering a question now reveals that one question's correct answer immediately, instead of waiting until the whole session is done.

**🧵 Challenge Quiz's question bank no longer deadlocks or serves stale questions**
- A rare timing issue could make "+5 more questions" or regenerating a Study Pack hang indefinitely under specific conditions. That deadlock is closed, along with a related case where a regeneration racing question generation could let a handful of new questions slip in built from content that no longer exists.
- We also checked, and disproved, a third suspected race around completing a session at the exact moment a regeneration deletes its question bank — it's already safe, and we added a test that proves it.

**🛑 A completed quiz can no longer be silently un-completed by a stray background save**
- Across every quiz mode, an in-progress save that started before you finished — and was still running in the background — could, in a narrow timing window, overwrite your just-completed result back to "in progress." Since this release also stops sending the answer key until you've answered, that reopened a path to see it and resubmit. Closed for every affected mode, and Quick Review's own staleness check (which detects when the underlying material changed mid-session) was rebuilt on a more precise signal in the process.

## Polish & Fixes
- Fixed the same stale-read pattern behind the Challenge Quiz fix above in one more place it already existed, independent of this release: resuming an existing Challenge Quiz session could occasionally miss that it had just been completed elsewhere.
- Fixed a rare case where an admin content-repair tool racing your own regeneration of the same Study Pack could stamp two different quiz versions as identical, confusing the staleness check above.
- Fixed a case where Challenge Quiz's answer-saving could get stuck behind one slow or failed save and silently stop saving anything else for the rest of that browsing session.
- Known, narrow limitations not fixed in this release, each recorded in detail in `RELEASES.md`: two people trying to start the same shared Quick Review session at the exact same instant can occasionally get an error instead of one of them resuming cleanly; a lost network connection can occasionally cost Quick Review's retry-question list on the next reload (your score itself is never affected); and Adaptive Practice's oldest sessions (created before this release) still trust a legacy field this release didn't touch.
- This release went through three rounds of adversarial review by independent AI reviewers with no memory of how the code was written, specifically hunting for exactly the kind of subtle timing bug this release is about — the second and third rounds each found and fixed something the round before had missed.
