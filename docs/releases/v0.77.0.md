# Release Notes: v0.77.0 — Evidence-Gated Weak Concept Recommendation

## Release Theme
The Dashboard now suggests focused practice because you *keep* getting something wrong — not because one quiz went badly.

## Key Features

**🎯 Practice suggestions that wait for a pattern**
- Today's Focus recommends weak-concept practice based on concepts you have missed **repeatedly**, rather than on whatever your most recent Quick Review happened to show
- One bad session no longer triggers a suggestion — a single off day is not a weakness
- The wording now reflects that: it names the concepts that keep tripping you up, instead of reporting on your latest quiz
- Adaptive Practice sessions are limited each month, so this keeps them for the concepts that genuinely need them

## Polish & Fixes
- Suggestions stay within a single Study Pack, so counts always refer to one set of material rather than being mixed across unrelated packs
- Documented the new behaviour in the dashboard feature notes, including why suggestions are scoped to one Study Pack
