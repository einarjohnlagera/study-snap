# Release Notes: v0.23.1 — Quiz Format Fix

## Release Theme
"Quiz Format Fix" — a focused patch that fixes quiz questions which asked you to *choose* ("Which is correct?") but mistakenly showed **True / False** answers, and prevents that mismatch across every quiz mode.

## Polish & Fixes
- Fixed quiz questions that asked you to choose — "Which is correct?", "Which of the following…", or multi-statement "Statement 1 / Statement 2" prompts — but showed only True/False answers. These now correctly present four answer choices.
- Added a generation safeguard so the mismatch can't recur in any mode — Quick Review, Challenge Quiz, Adaptive Practice, Long Exam, Board Exam, and Teacher quizzes.
- Refreshed the affected questions in existing study packs. Your notes, summaries, key concepts, and progress are untouched — only the malformed quiz questions were regenerated.
