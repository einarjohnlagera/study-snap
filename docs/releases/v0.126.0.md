# Release Notes: v0.126.0 — Context Budget

## Release Theme
The project's governing documents stop charging every working session for history that is already written down somewhere else.

## Key Features

**🗜️ The instruction file shrinks by 90%**
- `CLAUDE.md` is read at the start of every session. One line in it had grown to 322,329 characters — a chain of 63 release summaries stretching back to `v0.37.0`, roughly 90% of the file.
- Every one of those summaries already exists in `RELEASES.md`. The chain now lives in the archive and the file is a tenth of its former size.

**📦 The release log returns to its documented shape**
- `RELEASES.md` was designed to hold "the current version plus the last few". It held 116. The older 111 moved to the archive, leaving a one-line index entry each.
- `ROADMAP.md`'s per-version retrospectives moved the same way.
- Both are moves, not deletions: every section is preserved word-for-word and still searchable.

**🔁 And it will not silently grow back**
- This exact archiving pass ran once before, in July, then never again — because nothing in the release process asked for it.
- The kickoff and signoff checklists now carry the step, in more than one place, so it survives the next release rather than being replaced by it.

## Polish & Fixes
- Restored two corrections that the first attempt at this trim removed — both had cleared a curator blocker that another document still described as open.
- The rule that says "don't delete old release entries" now explains that archiving is not deleting, which is what had quietly forbidden the pass for 85 releases.
- 31 cross-references inside the roadmap pointed at sections that had moved; they now point at where the sections actually are.
- 33 archived versions had no index entry at all and could not be found from the live file. They do now.
