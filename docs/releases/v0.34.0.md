# Release Notes: v0.34.0 — Journey: Goal-First Study Experience

## Release Theme
Transform the study plan detail from a static note list into a guided study surface — using only shipped infrastructure and zero new AI, mastery signals, or quiz models.

## Key Features

**🗺️ Plan Hero Card**
- Plan detail now opens with a full hero card: title, description, course/program badge, optional estimated study time, and overall Study Pack readiness count
- Replaces the bare header on leaf plan detail pages; Goal detail unchanged

**⏱️ Estimated Study Time**
- Curators can attach an optional `~N hrs` estimate to any plan via the edit modal
- Carries over on adopt; never blocks adopt, quiz generation, or publish

**📊 Section Readiness**
- Each section header on the plan detail shows a live `N% · M due` stat
- Lazy-loaded after initial render so it never blocks first paint; failures degrade silently
- Reuses existing `ProgressReportService` concept classification — no new signal or stored field

**▶️ Continue Where You Left Off**
- Dismissible banner identifies the last-studied note from `lastSessionCompletedAt` (already in the plan detail response) and surfaces its next action
- Zero new backend — pure frontend composition

**🏗️ Builder for Leaf Plans**
- `/collections/{id}/builder` now branches on leaf vs Goal: leaf plans get a note-section canvas with drag-and-drop reordering, section drag handles, and an Add notes flow
- Leaf plan detail no longer has an inline Organize mode — the Builder is the canonical authoring surface
- New plan creation redirects directly to the Builder

## Polish & Fixes
- Notes card on plan detail: removed duplicate "Add notes" button (moved to Builder), renamed "Build" CTA to "Edit", always visible
- Hero card action column right-aligned consistently across all breakpoints
- Add notes modal redesigned: results list sits directly under the search box; a pinned "Selected (n)" section appears below results with independent bounded scroll (~3 rows before scrolling); live count shown on the "Add selected (N)" button
- Builder canvas label changed from "Section canvas" to "Your notes"
- Six invocable slash commands added to `.claude/commands/`: `/kickoff`, `/signoff`, `/audit-diff`, `/codex-prompt`, `/feature-doc`, `/version-check`
