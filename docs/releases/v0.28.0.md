# Release Notes: v0.28.0 — Feature Discoverability & Activation

## Release Theme
Close the gap between strong signup conversion and weak feature activation by surfacing underused capabilities — quiz-session export, Challenge Quiz, and Study Plans — *in flow* through the systems we already have (one-time contextual tips, the Dashboard recommendation, the post-session next step), not new help pages. This is an activation problem, not a docs problem.

## Key Features

**🧭 Contextual Activation Nudges + Funnel Instrumentation**
- Two new one-time, dismissible tips at their moment of relevance — an **Export** tip on the quiz review screen and a profile-aware **Study Plans** grouping tip in the Library (non-teacher, ≥3 notes) — all routed through the existing `pickActiveGuidance` engine, no new tips framework
- The Library's tips were consolidated into a single `pickActiveGuidance` selection so nudges never stack, with Study Plan grouping prioritized for non-teachers
- `GuidanceTip` gained an opt-in `trackAnalytics` flag firing `GUIDANCE_TIP_SHOWN` (impression) and `GUIDANCE_TIP_CTA_CLICKED`, and the review screen fires `QUIZ_REVIEW_EXPORTED` — a complete impression → click → use funnel via the existing `AnalyticsEventType` enum (Java + frontend)

**🎯 Smarter Dashboard Recommendation**
- The existing `ContinueSpotlight` / `continueStudying` recommendation now includes a `SUGGESTED_CHALLENGE` step: eligible idle Student and Board Exam users with quiz-ready material, no prior Challenge Quiz session, and remaining monthly quota see a contextual `Try Challenge Quiz` action in the existing card — no permanent promo banner (explicitly rejected)
- Resume and low-score priorities are unchanged; Teacher/Professional and quota-blocked users fall through safely; impressions and clicks are tracked via `DASHBOARD_RECOMMENDATION_SHOWN` / `DASHBOARD_RECOMMENDATION_CTA_CLICKED`

**🗂️ Trackable, Actionable Study Plans**
- A Study Plan is now a *trackable unit*: collection detail aggregates per-note readiness and completed-practice signals into a compact "Study Packs ready · practiced" summary and progress bar — read-only, detail-only, profile-agnostic, with no new AI, persistence, entity, or quota
- It is also an *actionable* one: plan-gated (PLUS/PRO) per-note weak areas (concepts due for review, batch-loaded with no N+1) plus a frontend-only **Next in this plan** card that walks saved order through generate → study → due-review → caught-up
- Opening a note from a Study Plan now returns to that plan via a referrer-aware back link (profile-aware label through `getCollectionLabels`), instead of always falling back to Library

**🧠 Mode-Aware Post-Session Next Step**
- The post-session recommendation is now derived from the just-completed mode and based on *genuine* weakness — reviewed-and-decayed concepts plus actual misses, excluding never-reviewed concepts — so a strong Quick Review advances primarily to Challenge Quiz instead of looping forever on weak-concept practice
- Quick Review misses prioritize retry (Challenge still reachable); Challenge Quiz keeps diagnostic weak-area practice primary when genuine weakness exists; Adaptive Practice always steps up to Challenge rather than looping back into itself; Long Exam and Board Exam flows are unchanged

**📚 Study Plans & Collections Help Topic**
- Added a universal, profile-aware Help guide (deep-linkable at `/help#study-plans`) explaining what a Study Plan / Review Set / Lesson Plan / Collection is (a playlist over existing notes — no AI synthesis, no new quota), what you can do with it, and how to create one — closing the documented Help gap for v0.27.0's Collections feature

## Polish & Fixes
- The Library's previously separate one-time tips now flow through a single `pickActiveGuidance` selection, so a user never sees stacked nudges
- Weak-area and "Next in this plan" data degrade to empty for Free users, notes without a Study Pack, or concept-health lookup failures — never fabricated counts, never a broken page
- Free users see a single subtle upgrade affordance (via `getUpgradeCtas`) for plan-gated Study Plan weak areas, never a fabricated number
