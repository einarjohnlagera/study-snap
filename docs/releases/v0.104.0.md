# Release Notes: v0.104.0 — Assessment Source Provenance

## Release Theme
When you miss a concept in a multi-note quiz or exam, it now counts against the note it actually came from.

## Key Features

**🎯 Every question remembers which note it came from**
- Each generated item carries its source Study Pack through the whole session, from generation to scoring
- Stamped after per-source deduplication and before merging, so it survives the shuffle that follows
- Works across Challenge Quiz, Board Exam and Long Exam

**🧭 Weakness is recorded against the right note**
- Previously a multi-note Long Exam wrote the same concept list to *every* source note, so a concept missed on one note was recorded as missed on all of them — and notes drawn from one Subject Plan share vocabulary by design, which made this the normal case rather than an edge case
- A multi-note Challenge Quiz had the opposite problem: every concept from every note landed on whichever note you started from, and the rest recorded nothing
- Both now record per contributing note, so getting *Shear Force* right on one note and wrong on another is stored as exactly that
- This is what makes per-subject reporting — "Structural Engineering needs work, Transportation is stronger" — possible at all

**♻️ Sessions already in progress keep working**
- A session started before this release completes normally, falling back to the previous behaviour for each mode
- A note that has been deleted or is no longer yours is skipped rather than failing an exam you already sat

## Polish & Fixes
- Fixed quiz choice text being corrupted on every session load, in every mode — an answer beginning with an initial, such as "A. B. Smith", could lose part of its text
- Fixed an unlabelled concept being recorded under a different name than the one shown on the result screen, which would have split its history into two and reset the streak
- Fixed a multi-note Challenge Quiz failing to start when two notes happened to label their matching questions the same way, which the generator does by default
- Practice questions grouped as a matching set now always come from a single note
- "+5 Questions" records its new questions against the note the session started from, which is where they are generated from
- Verified that no plan limit, quota or entitlement changed, and that Quick Review and Adaptive Practice are unaffected
- Recorded a remaining gap honestly: Interview Practice still spreads concepts across all its source notes, so overall mastery reporting is not yet fully trustworthy even though Long Exam and Board Exam now are
