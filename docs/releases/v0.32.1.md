# Release Notes: v0.32.1 — Monetization Surfacing & Pricing Clarity

## Release Theme
Lift premium-exam exposure and desire at the top of the funnel, and make paid pricing read like the one-time, time-boxed passes it actually is — without changing any billing, quota, or checkout mechanics.

## Key Features

**🎯 Premium-exam paywall at the Start CTA**
- Free and Plus users can now open the full setup/prescreen for Long Exam, Board Exam Mode, and Professional Interview Practice and see the value before any upgrade ask.
- The Pro paywall fires from the Begin/Unlock **Start CTA** for those modes (via `PaywallModal`), not from the mode-selection card click; backend `FeatureGate` stays the enforcement boundary.
- Quota copy on those prescreens is hidden from non-Pro users so they no longer see misleading "0 remaining" / "not enough quota" messaging.

**📚 "Exam this plan" for non-teachers**
- Non-teacher Study Plan detail pages expose a profile-aware premium-exam CTA — Student → `Take the Long Exam`, Board Exam → `Take the Board Exam`, Professional → `Start Interview Practice` (Teacher keeps the DOCX Exam Builder; profiles with no premium mode hide the CTA). Mapping lives in `resolvePlanPremiumExamMode`, not scattered profile checks.
- The launch carries only `collectionId`; each prescreen scopes its additional-note picker to **that plan's notes** (up to the existing per-exam cap) and pre-selects them — selection can never include notes outside the plan. Eligibility is a ready Study Pack only (these modes generate their own questions).
- Plan-launched prescreens route their back link to the originating plan (profile-aware `Study Plan` / `Review Set` / `Collection` label), and the picker reads "Add up to N more notes from this plan."
- A soft **"Review first"** advisory appears when a plan still has unpracticed exam-eligible notes — a recommendation with `Start the exam anyway`, never a block.

**💳 One-time pass pricing clarity**
- Paid plans now read as one-time, time-boxed passes instead of recurring subscriptions: prices render as duration (`₱X / 1 month`, `₱X / 3 months`, `₱X / 1 year`), and intro pricing reads as a first-pass discount (`₱149 for your first 1-month pass · ₱179 after`) rather than `first month, then …/month`.
- Cards carry one-time-payment / never-auto-charged / monthly-usage-refresh / library-permanence / desktop-and-mobile-web reassurances (shared constants in `plans.ts`), plus FAQ entries on re-charging and what happens when a pass ends.
- The Pro card collapsed from three stacked CTAs to one hero (`Get Pro — ₱X / 3 months`) with a small `Also available: 1 month · 1 year` line. The Settings plans cards use a single 3-segment pass-length selector (`1 month · 3 months · 1 year`) driving one price and one CTA.
- No billing, quota, pass-duration, price, or checkout mechanics changed — copy and layout only; backend checkout still uses Xendit-returned URLs.

## Polish & Fixes
- **Premium-exam eligibility fix:** the Study Plan exam CTA required a *generated quiz* (the Teacher Exam Builder's condition); it now requires only a ready Study Pack, so plans with Study Packs but no pre-generated quiz can launch an exam.
- **Consistent pass-length units:** the 90-day exam pass displays as **"3 months"** everywhere (selector, prices via `formatPassDuration`, and an active pass's billing status as `3-Month Pass`).
- **Savings badge fix + 3-month savings:** the `Save N%` badge is now state-aware (no more green-on-blue clash when a segment is selected, in either theme), and the 3-month pass shows its own `Save N%` alongside the 1-year one, computed by a shared `passSavingsPct` helper (regular-monthly baseline, cycles from `durationDays`).
- **Paywall-modal & landing copy** were reframed to match the one-time-pass model through the shared price-label helpers, keeping active-pass billing-status copy accurate.
- **Mobile pricing-cards layout** was evaluated and intentionally kept as a vertical stack (Free-first) — a horizontal carousel was rejected for feature-heavy cards, and leading with Pro was rejected to avoid a "paid-only" first impression on a freemium product.
