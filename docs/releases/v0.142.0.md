# Release Notes: v0.142.0 — Awareness Before Action

## Release Theme
The notification inbox and the adopted Review Set update panel both went live for the first time
in the last two months and had never been polished against real production shape — this release
fixes a bug that sat on every live notification, then rebuilds both surfaces around what a learner
actually needs to see.

## Key Features

**🔔 Notifications close when you act on them**
- Tapping a notification's action used to mark it read but leave the panel open — every one of
  today's live notifications shared this exact path
- Activating a notification now marks it read, closes the panel, and takes you where it points, in
  one tap, on both desktop and mobile

**🗂️ Notification cards are single, coherent tap targets**
- Unread notifications now have a clear background tint and a dot, not just a slightly bolder title
- The card body is the one control: tap it to read and go, or tap a CTA-less notification just to
  mark it read — no more separate "Mark read" button living beside the action link
- Every notification shows how long ago it arrived

**📋 The Review Set update panel shows what changed, not a raw diff**
- Updates from the Official Review Set you adopted are now grouped into new topics, topics no
  longer available, and other curriculum changes — instead of two uncapped lists
- Repeated reorders, retirements, and moves collapse into a count, with the full list available on
  request in a new **Review update** view
- The action button now reads **Add N new topics**, and N is always the number of topics you're
  actually about to get — a Subject Plan bundled in as its own item no longer inflates the count

## Polish & Fixes
- Fixed a rare race where, after two update attempts overlapped (two tabs, or a retried request),
  the panel could overstate how many topics were still left to add
- Replaced remaining "upstream" wording in the update panel and its documentation with plain
  language naming the Official Review Set
