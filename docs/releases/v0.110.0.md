# Release Notes: v0.110.0 — Supporter Combined Quiz

## Release Theme

Someone helping a learner can build one quiz from several notes and hand it over, without either of them needing an account or a connection — and two defects that had been silently corrupting shared quizzes are fixed.

## Key Features

**🧩 Combined quizzes from several notes**
- Pick several notes in your Library and build one shareable quiz from all of them
- Available to everyone — no teacher profile, no connection, and the recipient still needs no account
- Each combined quiz is a snapshot, so deleting or regenerating a source note afterwards leaves the quiz you already shared working exactly as it was
- Assembling costs nothing: it reuses quizzes you have already generated rather than generating again

**🔗 A share surface that lives with your Library**
- Name the quiz yourself — a quiz spanning six notes is no longer stuck with one note's title
- Create, copy and turn off its share link from a page that survives a refresh
- Reopening the page reads your existing link instead of quietly minting a second one

**✅ Shared quizzes grade "select all that apply" correctly**
- A shared quiz with a multiple-answer question used to mark a fully correct answer wrong, and a partly correct one right
- Recipients can now actually select more than one choice, and the review screen highlights every correct answer

## Polish & Fixes

- A Plus or Pro supporter who picked 30 questions was silently given 10; the choice is now offered only where it is honoured
- Removed an upgrade prompt that offered Plus for a capability Plus does not include
- The Generate Quiz tip no longer points people at a multi-note flow they could not reach, and now names the one they can
- The Library's note picker says which purpose you are picking for, instead of always offering a Study Plan
- Notes without a generated quiz are named as excluded before you build, rather than quietly dropped
- Selection limits are shown and blocked before you submit, instead of failing after the fact
- The real cost of a multi-note quiz is stated up front: each source note still needs its own Study Pack and quiz
