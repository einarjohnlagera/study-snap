# Release Notes: v0.122.0 — Shared Quiz Discoverability

## Release Theme
You can send someone a quiz built from your notes — and now the product actually says so, in the app and on the marketing pages, after shipping the capability silently for twelve releases.

## Key Features

**📣 The app tells you the capability exists**
- A one-time tip on the note detail page: *"You can turn this note into a quiz for someone else — a link anyone can open and answer without an account."*
- It appears on a quiz-ready note where you have not yet made a quiz for anyone — the moment it is useful, and only then.
- It has **no action button** on purpose. The *Quiz for someone* menu item already exists; a second click target for the same thing would muddy the read this release exists to make possible.
- It waits its turn behind the copied-Study-Pack hint, so a learner who has just copied a public note is told how to fix its difficulty first.

**🌐 The marketing pages name it**
- The landing page gains a line beside the study modes — *Also: Quiz for someone* — deliberately **not** a sixth mode card, since that section counts its own modes.
- The How it Works page gains a matching entry: *Share a quiz with someone*.
- Both reuse the Help Center's exact wording, so the product makes one claim rather than three. Neither says the capability is new — it shipped in `v0.110.0` — and neither claims you can see the recipient's score, because shared quiz results are graded in memory and never recorded.

**📊 The promotion is measurable**
- The tip reports its own impressions, so a later read can tell *"nobody was told"* apart from *"nobody wanted it"* — the distinction that caused two earlier dated reads to be abandoned rather than answered.
- Nothing else about shared-quiz analytics changed.

## Polish & Fixes
- The Help Center no longer tells teachers to use a control they do not have — *"From a note's actions menu, choose Quiz for someone"* named a menu item that only non-teachers see, while teachers reach the same capability through a **Generate Quiz** button. Both are now named.
- The guidance tip reference table documented 11 of the 20 tips that ship; the 8 missing ones are added.
- Two rows in that table were wrong rather than merely absent, and both overstated a tip's reach: `note-detail-try-quiz` was documented as always showing, when it needs the Performance Overview expanded and zero attempts on both Quick Review and Challenge Quiz; `library-study-plan-grouping` omitted that it is hidden during multi-select.
- The table is now grouped by rule set with priorities shown, since only one tip in a set can appear at a time.
