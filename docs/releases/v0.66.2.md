# Release Notes: v0.66.2 — Card Surface Token Fix

## Release Theme

Fix `bg-card`, a Tailwind utility with 23 literal usages across 9 files (22 rendered elements) that had silently resolved to no output since it was first used, because no `--color-card` token was ever registered in `globals.css`.

## Key Features

**🎨 `--color-card` Token Registered**
- `bg-card` now compiles and applies across all 23 usages with no per-site changes, aliased to `--background`.
- `--background` was chosen over `--surface-alt` on `getComputedStyle`-verified evidence: standalone nested panels (`ScoreReveal`, `public-flashcards-preview`) sit inside a parent `Card` and gain real, visible separation from it (`rgb(255,255,255)` vs. the container's `rgb(249,250,251)`).
- One genuine, verified-good visual change: `quiz-generation-overlay.tsx`'s modal panel goes from a translucent blur-bleed-through card to a solid, legible dialog — checked in both themes, no regression.

## Polish & Fixes

- An owner-requested independent Codex audit caught a real reasoning error before signoff: the original scoping claimed two call sites (`challenge-quiz/page.tsx:2090`, `long-exam/page.tsx:1090`) deliberately override `Card`'s default `bg-surface-alt` with `bg-card`, and that this fix preserved that override. It doesn't — `cn()` has no `tailwind-merge`, and compiled-CSS cascade order (not JSX class order) decides equal-specificity ties, so `bg-surface-alt` wins regardless. Confirmed directly via `getComputedStyle`: both an "override" `Card` and a plain `Card` compute to the identical color. The earlier screenshot-based read that suggested otherwise was fooled by a border-color difference, not an actual fill difference. The token choice itself was unaffected — it rests on the separate, verified nested-panel evidence — but the false claim was corrected rather than left standing.
- Usage count corrected twice during scoping: 9 (original finding) → 21 (missed `long-exam.tsx` and `challenge-quiz.tsx`) → 23 literal occurrences / 9 files / 22 rendered elements (final, audit-confirmed count).
