# Release Notes: v0.133.0 — Education Family

## Release Theme
Teaching programs become a first-class family in the shared catalog, so a curator can add all eight Education programs to a note in one action — and a future family no longer needs a database migration to exist.

## Key Features

**🎓 The Education Program Family**
- Adds `Elementary Education`, `Secondary Education`, `Early Childhood Education`, `Technical-Vocational Teacher Education`, `Physical Education` and `Teacher Certification` to the shared Course / Program catalog.
- Groups them with the existing `Education` and `Special Needs Education` entries into one **Education** family, so the Course / Program(s) picker now offers *"Add all 8 Education programs"* — on the Note Editor, Note Detail, Bulk Generate and the Admin curation modal alike.
- All eight are tagged to the **Licensure Examination for Teachers**, so they appear under the LET exam goal on the public catalog. Within the family, LET-tagged programs go from one to eight.
- `Special Needs Education – Generalist` is renamed to `Special Needs Education` and keeps its identity, so every note already filed under it stays filed under it.

**🗂️ Create a Program Family Without a Migration**
- A Program Family can now be created directly from the Admin Course / Program surface, beside the existing family picker.
- Until now only a *program* could be added in-app — a *family* needed a database change, which is why Engineering and Education each arrived as their own migration. A third would have been a third migration.
- A family is created empty; membership is set on the program, using the family field that was already there. Duplicate names are rejected regardless of casing or spacing, so two identical-looking families cannot produce two identical-looking shortcuts.

## Polish & Fixes
- The Course / Program(s) helper text no longer explains backend resolution mechanics a curator cannot act on. It now states the actual distinction — these programs decide who finds the note, never how it is written — and points at program families as the fast way to add related programs.
- Added the first multi-family tests for the Course / Program(s) picker. Every previous fixture held exactly one family, because until this release production did too, so a picker that ignored which family was clicked and expanded all of them would have passed.
- The new families endpoints ship with a test that issues a real HTTP request rather than calling the handler directly, and a client-side test that pins the request shape — the shape of defect that shipped a broken feature in `v0.119.0` against a fully green suite.
- The families list is read from its own endpoint, so a family created moments ago survives a page refresh before any program has been assigned to it.
- Updated the LET exam hub's built-in fallback program list, which still named only `Education`. It is used when the live catalog read fails, so a stale list would have quietly under-represented the exam goal by seven programs instead of showing an error.
- Corrected `program-families.md`, which listed three authoring surfaces for the family shortcut when there are four — Bulk Generate had been missing since it gained the control.
