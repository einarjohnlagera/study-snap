# Release Notes: v0.66.0 — Challenge Quiz Result Clarity

## Release Theme

Give standard Challenge Quiz's result screen the same clean outcome hierarchy Board Exam Mode already had, closing the Known Limitation flagged while signing off v0.65.0.

## Key Features

**🎯 Challenge Quiz Outcome-Area Consolidation**
- Standard Challenge Quiz results now use the shared `ScoreReveal` component — the same one Board Exam Mode's result screen already used — instead of a duplicated raw-score block plus a separate "Score Summary" card repeating the same numbers.
- `ScoreReveal` gained a dedicated `challenge-quiz` tone and an optional subordinate `secondaryMetric` slot, so sessions with unanswered questions still show both "Answered Accuracy" (primary) and "Overall Completion Score" (secondary) in one outcome block, with the explanatory copy positioned directly beneath.
- Board Exam Mode and Long Exam Mode are unaffected — the new prop is additive and both call sites omit it.

## Polish & Fixes

- The performance pill ("Excellent"/"Good"/"Fair"/"Needs Improvement") now uses `ScoreReveal`'s existing outline-only style instead of Challenge Quiz's own filled/tinted badge — a deliberate choice, confirmed with the owner, since filled hue badges read poorly in dark mode.
- An owner-requested independent Opus review (fresh agent, no inherited context) plus a real-browser check found and fixed two gaps: the dual-metric explainer text was separated from the numbers it describes by an unrelated result message, and the secondary metric's `aria-label` sat on a `<p>`, a role ARIA doesn't guarantee gets announced.
- A third concern raised from the diff alone — `ScoreReveal` nesting inside the result screen's existing outer card, read as a possible "card-in-a-card" — was checked with an actual rendered screenshot in both themes and did not hold up; no structural change was needed.
