# Release Notes: v0.25.1 — Polish & Quick Review Fixes

## Release Theme
"Polish & Quick Review Fixes" — a targeted polish pass covering Quick Review multi-select UX, Public Library filter hierarchy and cascading, quiz question rendering, profile Study Focus usability, and minor label/layering issues.

## Polish & Fixes

- **Theme picker z-index** — raised the navbar header from `z-40` to `z-50` so the mobile theme-picker dropdown always layers above page body content
- **Library More Filters "Done" → "Apply"** — standardized the private-library More Filters close button to "Apply", matching the public library
- **Quick Review multi-select Submit flow** — multi-select questions now always show "Submit" as the CTA regardless of position; clicking Submit reveals the answer highlight and explanation; button then becomes "Next" / "Finish Quick Review" / "Finish Retry"
- **Multi-select answer-review label mismatch** — fixed the shuffle seed used in the post-session answer review so the "Correct answer: C and D" summary text names the same letter choices shown in the rendered choice list
- **Public Library filter reorder** — More Filters modal reordered to For → Course/Program → Subjects → Tags → Source; Course/Program is now the primary drill-down before subject and tag selection
- **Public Library cascading Course/Program filter** — selecting a Course/Program narrows available Subjects and Tags to only those associated with notes in that program; stale drafts auto-clear on program change
- **Study Focus chip cap** — profile Study Focus section caps at 8 program chips with a "Show N more" toggle; prevents overflow on mobile and power accounts
- **Quiz question newline rendering** — `QuizQuestionText` now renders `\n` characters as visible line breaks in both the Statement-label path and the plain-text fallback; fixes statement-list questions appearing as run-on text
