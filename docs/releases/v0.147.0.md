# Release Notes: v0.147.0 — The Escape Hatch

## Release Theme

A curator whose Bulk Regenerate batch expires can no longer see it start again — a permanent dead end
from a single 404 that this release turns into a real return-to-start path.

## Key Features

**🔓 Bulk Regenerate Can No Longer Get Permanently Stuck**
- The Bulk Regenerate modal seeded its batch id from `sessionStorage` with no awareness that receipts
  expire 24 hours after creation. An expired or unknown batch id 404s, but the poll's error handling
  swallowed every failure including that one, and its stop condition required a successful response —
  so the poll ran forever while the stuck batch id kept the "start a new batch" screen permanently
  hidden. The only workaround was clearing browser storage or closing the tab.
- The poll now discriminates a 404 as terminal: it stops polling, clears the stuck batch id, and returns
  to the start screen showing the server's own message ("That regeneration batch is no longer
  available."). Every other failure still swallows and retries, so a real network hiccup doesn't kill
  the batch view.
- A new "Start a new batch" action gives curators an explicit way out independent of the poll, covering
  any other reason a batch might become unreachable.

## Polish & Fixes
- No backend change, no migration — this release is a single frontend file fix.
