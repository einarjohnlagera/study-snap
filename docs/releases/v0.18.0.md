# Release Notes: v0.18.0 — Profile Completeness & Communication

## Release Theme
"Profile Completeness & Communication" — completes the Professional profile experience with multi-note Interview Practice, adds subscription expiry notification emails so paid users never lose access silently, renders KaTeX math in working solutions for quantitative subjects, and introduces concept-level spaced repetition signals in Adaptive Practice.

## Key Features

**🧑‍💼 Professional Profile Completion**
- Selecting Professional in onboarding now auto-selects the Professional learner level
- Note detail now recognises Professional users and surfaces an Interview Practice action button for Pro-plan users
- Up to 2 additional notes can be added on the Interview Practice prestart screen; questions are distributed proportionally with cross-source deduplication
- Additional note picker is filtered to the primary note's course/program
- Prestart screen redesigned to match Long Exam layout: attribution header, standalone Session Length card, What to Expect list, full-width note rows, consistent footer bar

**🔔 Subscription Expiry Email Notifications**
- 7-day warning email sent to paid users before plan expiry
- 1-day reminder email sent the day before expiry
- Post-expiry "your plan has ended" email with renewal link
- Deduplication via email_log prevents re-sends; emails are transactional regardless of retention preferences

**📐 KaTeX Math Rendering for Working Solutions (Pro)**
- COMPUTATIONAL quiz questions now include step-by-step working solutions
- Inline `$...$` and block `$$...$$` LaTeX expressions render via KaTeX
- Pro users see a dedicated working-solution panel after answering; plain-text solutions fall back gracefully
- LLM prompts updated to emit LaTeX-formatted derivations for all quantitative quiz modes

**🧠 Concept-Level Spaced Repetition Signals**
- Tracks last-correct-answer date per concept per user per study pack
- Adaptive Practice merges concepts due for review (not seen in 3+ days) with weak concepts at generation time
- Key Concepts tab shows amber "Due — Xd ago" badges for overdue concepts
- Badge prompts PLUS/PRO users to start Adaptive Practice directly from the Key Concepts tab

## Email Communication Overhaul
Audited and corrected all transactional email templates. Welcome email plan tier copy fixed: Plus now leads with Adaptive Practice as its primary differentiator; Pro now correctly lists Board Exam Mode, Interview Practice, Long Exam, and difficulty selection — removing the incorrect implication that Adaptive Practice is Pro-exclusive. Google signup now sends the welcome email (previously users were tagged as verified but the send was skipped). Spam folder guidance added to the Verify Email page and the Verify Email Required modal. Verification banner updated to feature-agnostic copy ("Verify your email to unlock all features") so it won't go stale as new gated features are added.

## Polish & Fixes
- Parent profile option hidden from Profile Type picker until the use case is defined
- Public Library "Clear all" no longer re-applies the profile audience pre-filter immediately after clearing
- Admin dashboard Engagement section now includes Long Exam and Interview Practice counts
- Private library filters persist in URL query params; state restores from URL on mount
- Opening a note from a filtered private library encodes the filter URL as `?ref=`; the "← Library" back link restores the exact filtered state
- Opening a note from a filtered public library saves the filter URL to sessionStorage; the "← Public Library" back link restores it
- Public Library Professional audience pre-filter no longer re-applies after the user explicitly clears it and navigates away
- Verify Email page description and resend toast updated to mention the spam folder
