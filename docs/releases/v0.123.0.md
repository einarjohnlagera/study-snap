# Release Notes: v0.123.0 — Collection Builder Integrity

## Release Theme
The Study Plan Builder stops wedging on a bad section name, and editing a section no longer re-downloads your whole note library.

## Key Features

**🔁 The builder no longer gets stuck reloading**
- A section name the server refused used to be retried forever, with each attempt re-fetching every note you own. The page looked like it would not stop refreshing, and deleting the note was the only way out.
- A refused write is now attempted once and the error is shown. Refocusing the section field retries it deliberately — so a name you legitimately want is never stuck.
- Section names that differ only by extra spacing are now treated as one section, and a name carrying accidental double spaces is tidied on its next save instead of quietly rewriting itself on every page load.

**⚡ Editing a section is a single request**
- Saving a section used to cost up to four round trips — two of them recomputing the same data, one downloading your entire note library. It is now one.
- The Add-notes list is fetched when you first open the picker rather than on every page load, so opening a plan and opening the builder are both lighter. Its Refresh button still pulls a newer list on demand.

**🧹 The cause is fixed at the source**
- Bulk Generate could create a section name carrying doubled spaces — its Section field is pre-filled from the Subject you type, so a pasted Subject was enough. Anyone adopting a published plan inherited it. That name is now tidied as it is created.

## Polish & Fixes
- The Add-notes picker no longer says "No notes available." while the list is still loading, or after a load fails — it now says which is happening.
- A failed note-list load is reported once instead of retrying in the background.
- Two notes in the same plan whose section names differ only by spacing no longer render as two identical-looking sections.
- The reshape read pack under `docs/curriculum/` is now a reusable template rather than being hardcoded to one program, and ships with a script that turns its CSV exports into a single reviewable workbook.
