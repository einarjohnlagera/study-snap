# Release Notes: v0.146.0 — Knowledge, Not Lost

## Release Theme

An intact Study Pack stays usable for every learning action even when its Note's most recent generation
attempt is still running or has failed — fixing the only generation-failure pattern that has ever
occurred in production.

## Key Features

**📚 Artifact-First Learning Availability**
- Quick Review, Challenge Quiz, Adaptive Practice, Flashcards, Memorization, Long/Board Exam eligibility,
  Review Set premium-exam launch, and public note rendering now all derive availability from the Study
  Pack's own artifacts (`quiz`, `keyConcepts`, `status`) instead of from the Note's generation lifecycle.
  A note whose regeneration is running or has failed keeps every learning action it had before — the
  lifecycle status is now shown alongside as a retry/progress message, never used to hide working
  material.
- This closes the only generation-failure pattern ever seen in production: all 7 historical generation
  failures were regenerations on notes that already had a complete, valid Study Pack, and every one of
  them was reported as having no learning material at all until now.
- A new `studyPackDone` fact (derived from the pack's own `StudyPackStatus`, never from the Note) is
  additive across four response types; nothing is removed, renamed, or made required. No database
  migration, no new persisted state — every fact is computed at response time from data already stored.

**🔁 A Real Escape Hatch for Stuck Generation**
- A new owner-callable recovery action lets a note stuck indefinitely in `GENERATING` — the rare case
  the automatic recovery sweeper cannot reach, because it never received a start timestamp — be manually
  marked failed and made retryable. It reuses the sweeper's own existing logic, so it can't double-charge
  quota, and only becomes available once the same generation-time bound the sweeper uses has elapsed.

**🃏 Flashcards and Memorization Can Recover Themselves**
- Both guards previously told a curator to "retry generation" with no way to actually do it. They now
  call the real generation API directly and refetch the note, matching what Note Detail's own retry flow
  already does.

## Polish & Fixes
- Quick Review can no longer be started against a Study Pack with an empty quiz — it now fails before
  creating a session, matching the guard Challenge Quiz already had.
- The Library's "Ready" filter and the Review Set premium-exam eligibility check now agree with each
  other and with the backend's own Long/Board Exam rule, all keyed on the Study Pack's own `DONE` status.
- Adaptive Practice's "no artifact" and "not entitled" cases are reported separately, so a learner on a
  plan without Adaptive Practice sees the real upgrade path instead of a message meant for a missing
  Study Pack.
- A pre-signoff falsification review (independent, cold-context) confirmed the release's core correctness
  claims and caught two smaller gaps before close: a stale feature-doc line describing a field that was
  added mid-implementation and correctly reverted for a performance reason, and a missing regression test
  for this release's own headline scenario. Both fixed.
