# Release Notes: v0.35.0 — Mobile-First Builder

## Release Theme

Make the leaf plan builder and exam builder functional and compact on all screen sizes — collapsible sections, a proper section drag overlay, and a two-row card layout that gives note titles full width on mobile.

## Key Features

**Section Drag Overlay**
- When dragging a leaf section, the drag overlay now renders a full section clone — header pill, note count, and a row of note title chips — instead of the previous title-pill-only ghost that gave no sense of what was being moved.

**Mobile Collapsible Sections**
- Leaf plan builder sections now collapse by default on mobile, eliminating the multi-thousand-pixel scroll on narrow viewports.
- A chevron toggle on each section header expands or collapses it individually.
- Desktop layout stays always-expanded; collapse state is page-local with no persistence.

**Mobile Two-Row Card Layout**
- Note cards in the plan builder and exam builder now use a stacked layout on mobile: note title and meta occupy the full card width on the top row, and action buttons (Up / Down / Move / Remove) sit right-aligned on the bottom row.
- Eliminates the title squeeze to 2–3 characters that occurred when four action controls shared horizontal space with the note title.
- Applied to the Goal builder (`SortableNoteCard`), leaf builder (`LeafSortableNoteCard`), and exam builder (`SortableExamBuilderItem`).
- Desktop side-by-side layout unchanged.

## Polish & Fixes

- Icon-only action buttons on mobile (Up / Down / Remove) with `aria-label` on all controls; text labels restored at `sm:` breakpoint and above.
- Drag handle retained on all card types alongside Up/Down buttons for reliable touch reorder.
- No backend changes, migrations, new API endpoints, or AI calls in this release.
