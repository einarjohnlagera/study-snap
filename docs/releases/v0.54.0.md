# Release Notes: v0.54.0 — CPALE Exam Hub (Wave 2)

## Release Theme

Extends the Exam Hub acquisition surface to a fourth board exam — CPALE (Certified Public Accountant Licensure Examination) — the first Wave 2 hub, reusing the same config-alias-map pattern that shipped ALE/PNLE/LET rather than building anything new.

## Key Features

**🧮 CPALE Exam Hub**
- `/exam/cpale` joins the existing three hubs, following the Wave 1 template exactly: discovery sections, "Browse by Subject," full-inventory "More Notes" section, `CollectionPage`/`ItemList` structured data, and the honest zero-note state — all inherited automatically since the dynamic `/exam/[slug]` route and sitemap already iterate the hub config, no route-level code change required.
- Added `cpale` (courseProgram `Accountancy`) to `frontend/lib/exam-hub-config.ts` and the synced backend `ExamGoalConfig`, so Study Goal resolution (`goalType = "EXAM"`) works for CPALE the same way it does for the other three.
- The `/exam` index page now shows four hubs with a CPALE card and icon; copy and the grid's `aria-label` dropped the "Wave 1" framing since Wave 2 hubs now render in the same list.

## Polish & Fixes

- Note filtering remains courseProgram-exact-match only (no subject-based fallback) — accountancy-adjacent notes tagged with a different courseProgram (e.g. "Business", "Commerce") won't surface in this hub; documented in `docs/features/exam-hub.md`'s new Wave 2 Set section as an accepted characteristic of the existing mechanism, not a bug.
