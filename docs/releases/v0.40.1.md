# Release Notes: v0.40.1 — Public Review Set Reachability

## Release Theme

Close a narrow, verified discoverability gap in Review Sets — PUBLIC Official Review Sets outside a learner's own course/program were technically public but unreachable through any UI path — while picking up the weekly-scheduling Phase 2 work deferred out of v0.40.0, and fixing three additional gaps surfaced from live usage of the shipped Primary Review Set feature.

## Key Features

**🌐 Browse All Official Review Sets**
- `/collections/published` now keeps the existing course/program-scoped Recommended section and adds a "Browse All Official Review Sets" section beneath it, calling the already-supported unfiltered public collections endpoint.
- Sorted alphabetically by title, with its own independent loading/error/empty states so it works even for a learner with no course/program set.
- Fixed the misleading "No curated Review Sets for X yet" empty-state copy, which read like "you have none" when it actually meant "no official set for your track yet" — now links straight to Browse All.

**📅 Weekly Scheduling Phase 2**
- `GET /collections/{id}/goal` now adds per-child `todaysConceptBudget` values using Hamilton largest-remainder allocation over each child Subject plan's not-started concepts, with due concepts as each subject's floor and exact sum parity with the Goal-level daily budget.
- Adds `weeklyFocusByDay`, a deterministic weekday-to-child-id focus template derived from study-days-per-week and child order — still pure derivation, no stored schedule, no AI call.

**⭐ Manual "Set as primary" action**
- A top-level collection's detail page now shows a `Primary` badge and a `Set as primary` / `Remove as primary` action in the existing overflow menu, closing a gap left open at v0.40.0 signoff.
- Available for any owned top-level collection (`parentCollectionId === null`), including childless leaf plans; excluded from child Subject plans.
- The `/collections` list page also shows the badge and sorts the primary collection to the front of the grid (everything else keeps the existing last-updated order).

## Polish & Fixes

- Fixed the "This Week" countdown card not appearing on a childless top-level Review Set (a flat, notes-holding plan with no Subject plans) even when a target date was set — the page only fetched the countdown data when the collection had children.
- Added an "Adopted" badge on both the `/collections` list page and a collection's own detail page whenever it was adopted from a public source, closing a long-standing gap where adopted-vs-owned had no visible indicator.
- Changed the `Primary` badge to a filled indigo pill with a star icon on both the list and detail pages — it previously shared the same neutral outline style as `Adopted`/`Private`, making it hard to tell apart from `Private` on the detail page.
