# Release Notes: v0.45.2 — Public Plan Preview Rollup Fix

## Release Theme

Close the one remaining gap in v0.45.1's Goal-collection rollup fix — the "Preview this plan" panel on public plan cards still showed "0 of 0 notes practice-ready" for a Goal even when its Subject Plans held real, ready notes — and keep that panel usable now that it correctly renders every note, including plans with 40+ notes.

## Key Features

**🔢 Public Plan Preview Rollup Fix**
- The plan-preview panel now correctly shows a Goal's real note count and practice-ready ratio, rolled up from its child Subject Plans instead of always reading "0 of 0."
- This was the third and final code path affected by the Goal-collection rollup issue: v0.45.1 fixed the card-level summary counts; this release fixes the preview-detail endpoint they didn't touch.

## Polish & Fixes

- The preview note list now caps at 5 (showing all notes when the total is 6 or fewer, so a single hidden item never shows up behind a "+1 more" line), with a muted "+ N more notes" line beyond that. The "Preview this plan" toggle now also shows the plan's total note count, so the cap reads as a sample rather than concealment.

## Known Limitations

None specific to this release.
