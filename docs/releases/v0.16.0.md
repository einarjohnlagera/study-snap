# Release Notes: v0.16.0 — Conversion & Growth

## Release Theme
"Conversion & Growth" — close the gap between social traffic and signed-up users, make teachers a distribution channel through shareable quiz links, and get the app installable on mobile.

## Key Features

**🔗 Shareable Student Quiz Links (Free · 3/mo, Plus · 10/mo, Pro · Unlimited)**
- Teachers generate a shareable `/quiz/[token]` link from the quiz preview page
- Students take the quiz anonymously in-browser — no account required
- Results screen prompts students to sign up and start their own notes
- Monthly quota tracked per teacher account (Free: 3, Plus: 10, Pro: unlimited)

**⚡ Post-Signup Copy-Note → Instant Quiz**
- New users who sign up via a public note's copy CTA land directly in a Quick Review session
- Note is auto-copied and Study Pack generation starts immediately on account creation
- Copy intent survives Google One Tap and email verification via a short-lived cookie
- Bypasses onboarding for users who already know what they want to study

**🌐 Profile-Aware Learning Loop on Landing**
- Replaced generic How It Works + Profile Showcase sections with an interactive ProfileLearningSection
- Four-tab layout: Students, Exam Reviewers, Teachers, Professionals — each shows a tailored learning loop, mode chips, and a screenshot
- Professionals tab reflects Interview Practice mode

**📱 PWA Installability + Mobile UX**
- Web app manifest updated with `start_url`, `scope`, and proper icon `purpose` fields
- Service worker caches static assets (stale-while-revalidate) and shows an offline page when navigating without a connection
- "Add to Home Screen" nudge shown to returning mobile visitors after 2+ sessions — Android gets the native install prompt; iOS gets a Share → Add to Home Screen instruction
- Fixed iOS Safari automatic input zoom (global font-size ≥ 16px)

**🔍 Library Filter Discoverability**
- Replaced chip-styled `+ More` overflow with `Browse all` text links in section headers (Subjects, Popular Tags)
- Added Course / Program filtering to both private and public libraries
- Public library Course / Program control moved into More Filters; More Filters badge activates when Course / Program is set
- Faded scroll-rail affordances signal scrollable filter rows
- Mobile library filter panel now anchors as a bottom sheet; soft-keyboard no longer pushes it off-screen

## Refund & Cancellation Policy
Added a public `/refund` policy page documenting the manual-renewal / no-proration refund model. Linked from the public footer, Settings billing note, and Terms of Service.

## Admin Refund Action
Admins can now trigger a Xendit invoice refund directly from the Recent Paid Upgrades panel. Eligible transactions are marked `REFUNDED` after Xendit accepts; users receive a refund confirmation email with the 5–10 business-day timeline.

## Polish & Fixes
- Cancellation modal now shows the specific access end date; post-cancellation plan card reads "Access ends [date]" instead of vague copy
- Teacher in-app guided tips: 5 one-time dismissible tips placed at first dashboard visit, note content area, Generate Quiz modal, library multi-select, and DOCX export button
- Send Feedback header icon now renders on all authenticated pages; removed the inconsistent floating button from Dashboard / Library / Settings
- Fixed modal positioning bug where `backdrop-filter` on the sticky header created a CSS containing block for `position: fixed` children — `AppModal` now renders via `ReactDOM.createPortal` into `document.body`
- Unified in-page at-limit banners (Study Pack, note generation) into a single `QuotaLimitBanner` component with icon, title, reset date, and plan-aware upgrade CTA
