# Release Notes: v0.66.1 — Goal Detail Due-Concept Signal

## Release Theme

Give a Goal's child Subject-plan cards a lightweight visual cue for concepts due for spaced-repetition review, and formalize an anti-drift exception that had shipped but never been documented.

## Key Features

**🟠 Overdue Color-Warning on Goal-Detail Child Cards**
- A Goal's child Subject-plan cards now render their "due" concept count in the existing amber-warning color when there's at least one concept due, matching the same warning convention already used elsewhere on this page.
- Presence-based only — no new magnitude threshold — and stays plain/muted when nothing is due.

## Polish & Fixes

- `AGENTS.md` and `docs/features/collections.md` now name the Goal-detail child card's `overallReadinessPercentage`/progress-bar display as a second deliberate exception to the collection-detail no-mastery rule. That display has been live since the original Goal → Subject hierarchy feature — this release only corrects the documentation to match already-shipped behavior; no behavior changed.
