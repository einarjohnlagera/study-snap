# Release Notes: v0.177.0 — Challenge Quiz Quality, Continued

## Release Theme
Test again, with a fairer gate and a narrower wording change, whether Challenge Quiz questions can be made harder to guess for the free-plan model without hurting the premium model, and ship nothing unless both pass; neither did, so the production prompt is unchanged.

## Key Features

**⚖️ A Fairer Gate**
- One pre-registered gate was unfairly harsh on certain question formats. It was reworded and signed as rubric v2, with formats that have too few items marked as not evaluated and disclosed rather than failed or hidden.
- The offline gate calculator now takes an explicit rubric version with no default, so a result can never silently mix the old and new rules.

**🧪 A Narrower Prompt Test**
- The proposed wording was cut to the five approved giveaway-reducing bullets only, without the change that lowered difficulty on the premium model.
- The variant lives only in test resources, with a guard test that pins both its hash and the unchanged production prompt.

**📊 The Result: HOLD, Nothing Shipped**
- The blind evaluation judged the free-plan and premium models separately: the free-plan model failed six of the gates and the premium model four, so the overall result is HOLD.
- A cold arithmetic audit reproduced every verdict from the frozen inputs, and found that part of the premium model's difficulty result depends on which reviewer scored it; that cannot change the HOLD, and the next evaluation should fix the reviewer source for both arms.
- This is an internal finding and never appears in customer copy.

## Polish & Fixes
- Every pinned hash, rule and threshold was frozen before scoring and checked again at signoff; nothing changed after the freeze.
- A voided and re-run set of generation starts (a local network outage) was recorded as a dated amendment, not edited away.
- Spend stayed under the cap: about $3.13 by the meter against $4.00.
- The full evidence set is preserved outside the repository and its hashes were verified.
- No production code, prompt, schema, pricing, quota or entitlement changed, and the release is not merged to `main` (deploy on hold); the test harness reaches `main` inside the release that merges this branch.
