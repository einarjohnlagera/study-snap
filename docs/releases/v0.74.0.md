# Release Notes: v0.74.0 — Quiz Progression

## Release Theme
The Quiz tab stops being an answer key to the test Quick Review administers — it becomes something you earn.

## Key Features

**🔒 The Quiz tab is now earned, not given**
- The saved Quiz questions stay visible but locked until you score a perfect Quick Review
- Locking it fixes a real hole: that tab revealed the answers to the exact questions Quick Review asks, so a score could be run up by reading them first — and Quick Review feeds ConceptHealth, the signal the whole app treats as mastery
- The lock names the real condition using your pack's own question count, and points you at the retry if you came close
- Challenge Quiz stays open from the start; it writes its own questions, so no answer key can spoil it

**🔓 A moment when it opens**
- A perfect Quick Review announces the unlock beside your score, the first time you earn it
- Mastery counts whether you got everything right first time or worked back through what you missed

**🏆 Challenge Quiz is promoted when you're ready for it**
- The post-session next step now waits for mastery before pushing you to Challenge, instead of nudging at 4 out of 5
- Miss something and you're sent back to the notes — the material, not another attempt at the same questions

**📐 Maths reads like maths**
- Formulas that used to print raw, backslashes and all, now render properly across quizzes, flashcards, interview practice and memorisation
- Fixed in two places: the generators are now told how to write maths, and existing content is repaired as it renders

**📊 Instrumentation that answers an old question**
- Nine analytics events, including the two that make the long-blocked Challenge-adoption read possible for the first time since June

## Polish & Fixes
- Teachers and admins bypass the Quiz lock so they can still inspect generated quizzes
- Board-exam learners land on their Study Pack after generating instead of on a lock screen
- Quick Review no longer routes into Adaptive Practice; a five-question refresher is too light a signal to spend quota-limited practice on, and it remains reachable from the dashboard and the mode picker
- The retry action was removed from the results screen — it restarted the whole quiz despite its label, and you had already been offered the real retry a screen earlier
- A weak repeat session on a pack you already mastered is no longer congratulated, and its missed concepts are shown again
- The unlock announcement no longer reappears on later perfect scores
- Fixed a rendering bug that could duplicate or garble text inside explanations
- Fixed a database connection-pool issue that could make mastery silently read as unearned under load
- Result screen back link now follows the project's own naming standard
- Reads (a) and (b) of the Challenge-adoption validation ran before deploy: conversion did not improve, so "motivation, not placement" is recorded as unconfirmed and reopened
