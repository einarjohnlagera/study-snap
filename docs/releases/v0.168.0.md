# Release Notes: v0.168.0 — Free Quota, Fairly Metered

## Release Theme

Fixed a confirmed production defect that silently blocked real users' free Study Pack generation
quota by counting note copies and shared-pack remixes as if they were paid generations.

## Key Features

**🛠️ Study Pack quota now counts only real generations**
- A Free (or any plan tier's) learner's monthly Study Pack usage is now based entirely on actual
  AI generations — never on copying a note or remixing a shared Study Pack, neither of which calls
  the AI at all.
- Fixes a real, confirmed defect: 76 real users were incorrectly reported as having used their full
  monthly quota, when in fact they had generated nothing — the system was counting their note copies
  against the same limit. 75 of those 76 users got there specifically by adopting a Study Plan, the
  single learner behavior most associated with returning to the app.
- No quota numbers changed for anyone. This restores the quota these users were always entitled to;
  it does not grant anyone more or less than their plan already allows.

## Polish & Fixes
- Found via a same-day product health audit; root-caused by tracing every code path that creates a
  Study Pack record and confirming the fix only affects the two paths that were never supposed to
  count (copying, remixing) while leaving every real generation path untouched.
- Verified via a cold falsification pass (run through Codex, against an isolated clone, independent
  of the implementing session) before signing off — all core claims confirmed; one test's name was
  found to overstate what it actually verified and was corrected to describe the real guarantee
  precisely.
- Clarified two feature docs (`docs/features/subscriptions-and-usage-limits.md`,
  `docs/features/study-pack-generation.md`) that previously described quota counting in a way that
  didn't explicitly rule out copies/remixes.
- Considered, and explicitly decided against for this release: rebuilding the Degree Journey catalog,
  multi-goal exam support, a Civil Engineering Exam Hub page, and Public Note → Study Journey
  discovery — each was checked directly against current production data and found not yet ready
  (either blocked on its own stated evidence gate, or requiring a decision not yet made).
