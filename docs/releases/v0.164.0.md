# Release Notes: v0.164.0 — Computing

## Release Theme

Ratifies `Computing` as a new authoring domain for the shared foundations of Computer Science, Information Technology, Information Systems, and Software Engineering — reversing an earlier rejection now that the real curriculum evidence exists to support it.

## Key Features

**💻 Computing Domain Context**
- A new authoring domain, `Computing`, joins the Domain Context taxonomy: variables and data types, conditional statements, functions and parameters, arrays and fundamental data structures, algorithmic problem solving, binary and data representation, computer systems fundamentals, and discrete logic treated for computation.
- The boundary, applied per note: is computation, information, algorithms, software, or computational systems themselves the object of study — and could this exact note, unchanged, legitimately serve a sibling computing program (Computer Science, Information Technology, Information Systems, Software Engineering)? Both yes, and it belongs here. CS-specific formalism (automata, theory of computation, computability), Precalculus and Algebra, and other program-specific specialization stay outside it.
- This reverses a 2026-09-04 rejection of the same name — that decision assumed `Computing` was an invented label; it's actually the confirmed ACM/IEEE *Computing Curricula 2020* umbrella term and a literal shared first-year course title under Philippine CHED regulation. Reconsidered on the strength of a 136-note curriculum corpus classification, not a change of mind.
- A checkpoint is on record to re-check the real authored population once BSCS Year 1 computing content exists in production, guarding against the value turning out to serve only one program in practice.

## Polish & Fixes
- `ADR-001`'s architecture record gained a new decision entry, with the original 2026-09-04 rejection preserved and dated rather than rewritten.
- Every doc that lists the closed Domain Context vocabulary was swept to the new count — the curriculum-shaping context, the product-facing context brief, and three feature docs — plus one independent, unrelated stale-claim fix found along the way.
- No database migration, no backfill, no resolver rewrite, and no bulk note generation — the new value is purely additive, and classifying real curriculum content is curator work outside this release.
