# Release Notes: v0.68.0 — Topic Note Rename

## Release Theme

Reserve the word "Generate" for what actually makes NoteLib different — turning a learner's own notes into Study Packs and quizzes — by renaming the bare-topic drafting action to "Create a Note," and align every surface that had drifted from that distinction.

## Key Features

**✍️ "Generate Note" → "Create a Note"**
- The bare-topic action that drafts freeform prose from a subject is now "Create a Note" across the note editor, onboarding Step 3, the demo flow, and the "Create from topic" entry tab.
- "Generate Study Pack," "Generate Quiz," and "Regenerate" are deliberately unchanged — those transform material the learner already wrote, which is the mechanism the rename protects the word for.
- Follow-through covered the whole flow, not just the button: status and confirmation copy, fallback error strings, the Library create menu, and the output field a learner reviews after drafting.

**🎯 Plan messaging built around the learning system**
- The pricing hero now leads with "Always know what to learn next," and the Plus and Pro taglines describe the learning outcome rather than an exam-prep feature list. Plan names are unchanged, so checkout, Settings, and receipts keep one vocabulary.
- Plan descriptions were rebalanced in length, which fixed a real card-alignment problem across all four surfaces that render them — the pricing page, the landing page, Settings billing, and the paywall modal.

**📊 One name for the topic-note allowance**
- The monthly allowance for topic notes is now called exactly that everywhere a learner sees it — quota counters, over-limit notices, paywall copy, the bulk-generate page, and the Library's bulk-failure banner.
- The backend's own quota message was brought in line with the frontend's, because both render into the same alert element and could previously show two different names for the same limit in one session.

## Polish & Fixes

- "Retry Generate" is now "Retry Generation" on Study Pack and quiz failure states, with the matching helper prose.
- Settings billing plan cards align correctly: the plan titles use one consistent size and the "Current plan" badge no longer pushes the active card out of line with its neighbours.
- The bulk-failure banner reads correctly when exactly one topic is affected.
- The Learning Profile hint in the note editor reads naturally again, and the exam builder no longer offers "create or generate" as if they were two different actions.
- The in-app Help guide for bulk generation now uses the same allowance name the page itself shows.
- A long-standing flaky Library test was diagnosed and fixed — it raced a mocked 10ms poll interval and failed on an assertion, not a timeout, so no amount of waiting had ever helped.
- Adopted a Companion Guidance Doctrine in `AGENTS.md` — one learning responsibility per feature, one question per surface, and a de-duplication rule for future guidance work.
- Documentation caught up with the code across plan copy, feature docs, and the terminology rename map, whose stale "keep" verdicts would otherwise have led a future change to undo this release.
