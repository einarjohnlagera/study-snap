# Release Notes: v0.103.0 — Mixed Retrieval for Free and Plus

## Release Theme

Practising across several of your own notes at once is now something Free and Plus learners can actually do — not just something the product had been built to allow.

## Key Features

**🎯 One quiz across several notes in a plan**
- Open a Study Plan, start a Challenge Quiz, and choose which of its notes the questions should come from
- Free covers up to 3 notes; Plus up to 6, including the one you started from
- Questions are spread evenly across the notes you pick, and every note contributes enough questions to be worth including

**🔓 It works now — before this release, nobody could reach it**
- The screen that lets you pick notes was reading its limit from something that does not exist until a quiz has already started, so every note was greyed out on every plan
- The limit now comes from the server, which had been sending it all along

**👪 The button and the screen it opens finally agree**
- Some learners saw "Start Challenge Quiz" on their plan and landed on Board Exam setup instead
- Both now decide the same way, so what you tap is what you get

## Polish & Fixes

- Corrected the note limit for Plus from 4 to 6: the old number was a leftover of dividing one setting by another rather than a decision about what Plus should offer
- Removed a "+5 more questions" button from multi-note quizzes that could never work — it always failed, and it spent a request finding that out
- Multi-note quizzes are counted separately so your ordinary quiz allowance is not quietly consumed by them
- Fixed a locking change that made every quiz start hold a database lock for the whole time questions were being generated, which could delay unrelated requests on the same account
- The pricing page no longer lists a Pro allowance for multi-note quizzes; Pro's plan action opens Board Exam, and that line was never an entitlement anyone chose
