# Release Notes: v0.26.0 — Exam Depth

## Release Theme
"Exam Depth" — NoteLib deepens the exam experience: public exam hubs surface contextually on note pages and in the nav, milestone markers show board exam takers exactly how far along their prep they are, a 90-day Exam-Cycle Pass matches how reviewers actually budget for a single exam window, and subject-level multi-select focus replaces the broad course-program picker with granular, AI-inferred study targets.

## Key Features

**🧭 Exam Hub Surface Improvements**
- `/exam` index restyled to icon badge + card pattern (PenTool/Heart/GraduationCap), matching the Help page visual language
- Public note detail pages now show a contextual exam hub callout strip when the note's `courseProgram` maps to ALE, PNLE, or LET — includes hub description, "Browse [Exam] notes" CTA, and an upgraded "More notes" link pointing to the exam hub instead of the filtered public library
- "Exam Hubs" added to the public navbar between "Public Library" and "Learn", replacing the footer-only entry point
- `NextStudyCard` on the Progress page now resolves exam hub slug via `getExamSlugForCourseProgram()` as a fallback, so Architecture/Nursing/Education goals set from the profile chip picker correctly link to `/exam/ale` etc.

**🏁 Mastery-Threshold Milestones**
- Six fixed ConceptHealth-derived milestone checkpoints appear on the `/progress` goal view, between the goal summary and the next-study card: first concept mastered, 25%, all reviewed, 50%, 70%, and all mastered
- `GoalSummaryResponse` now includes `notPracticedConcepts`; milestone logic is computed client-side with no new endpoint

**💳 Exam-Cycle Pass (90-Day Pro)**
- New `EXAM_CYCLE` billing cycle — a PH Pro-only 90-day pass at ₱599, a meaningful discount over three monthly renewals (₱747)
- Settings billing section and pricing cards show "Go Pro — 90-Day Exam Pass" only when the backend marks the cycle available (`examCycle.available === true`); non-PH and Plus exam-cycle pricing remain inactive by default
- Checkout uses the existing prepaid Xendit flow and monthly quota reset model — no changes to activation or webhook handling

**🎯 Subject-Level Focus Multi-Select**
- Profile Study Focus section replaced with a subject multi-select sourced from the user's own AI-inferred note subjects (`/subjects?scope=mine`), eliminating the confusing overlap with the Learning Profile course-program field
- Selections saved to a new `focusSubjects text[]` column (V71 migration) via a dedicated `PUT /profile/focus-subjects` endpoint; setting focus subjects clears `studyGoal` (mutual exclusion from the profile picker; exam hub intent flow is unchanged)
- Profile-type-adaptive framing: section hidden entirely for TEACHER, "Exam Focus" header for BOARD_EXAM, "Study Focus — subjects you're preparing for this term" for STUDENT
- New `SUBJECT_FOCUS` goal type in `ProgressReportService`: when `studyGoal` is null and `focusSubjects` is non-empty, aggregates mastery across selected subjects into one combined goal summary; `goalName` shows single subject or "N subjects in focus"; `NextStudyCard` routes to `/public/library?subject=weakestGoalSubject`
- Progress page empty state replaced with an actionable card showing the weakest 5 subject chips as one-click links to `/profile#study-focus` when mastery data exists but no goal is set
