# Release Notes: v0.79.0 — Catalog-First Vocabulary

## Release Theme

The course or program you pick should be one the product can actually act on.

## Key Features

**📚 Catalog-first Course / Program suggestions**
- `/profile`, the Note Editor, private Note Detail, and the Dashboard profile-completion prompt now suggest the official Course / Program catalog first
- Your own saved value stays selectable even when it isn't in the catalog, and nothing you previously chose disappears from the list
- A slow or failed catalog load falls straight back to the existing suggestions, so the field is never empty or blocked
- Free text is still accepted on the profile and note surfaces — this is convergence by default, not a lock

**🔎 Public Library program filters come from the catalog**
- The public Course / Program filter now lists catalog names only, so a personal free-text label no longer becomes a public shelf
- Personal values keep working on your own notes and in direct search

**📊 Measurement, with a baseline captured first**
- A new selection event records only which surface was used and whether the chosen value matched the catalog — never the text you typed
- It fires when a value actually changes, not on every save, so re-saving an unchanged profile doesn't inflate the numbers
- The pre-deploy off-catalog rate was captured before release, so the follow-up read has a genuine before-state

## Polish & Fixes

- Onboarding deliberately keeps its existing suggestions until after the 2026-09-11 completion checkpoint, with a test that stops a future refactor changing it early
- Selection events are omitted entirely when the catalog can't be loaded, rather than recording a match result that can't be interpreted
- Creating a note no longer records a selection for a program you never opened the panel to choose
- Editing your program from the Identity card is now recorded, where before it was committed silently

## Known Limitations

- This release changes what is *suggested*; it does not change the 32 existing profiles that already hold an off-catalog value, and no data was migrated
- Because a course or program is usually set during onboarding — which this release excludes — little movement is expected until the onboarding follow-up ships
- The Dashboard profile-completion prompt accepts only offered options, as it did before; the free-text allowance applies to the profile and note surfaces
- Public notes whose program exists only as free text are no longer reachable from the public filter dropdown
- A course or program added to the catalog by an admin is not normalized on save, so an unusual name could produce a filter chip that matches nothing
