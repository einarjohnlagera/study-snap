# Release Notes: v0.129.0 — Adoption Signal

## Release Theme
Official Review Sets now show how many learners have adopted them, so a learner browsing Explore can see which sets are actually being used.

## Key Features

**📊 Adoption counts on Official Review Sets**
- Explore cards show a compact count — `40 adopted`
- The set's preview shows the fuller wording — `Adopted by 40 study libraries`
- The number is the current count of learners who hold a copy, and it excludes the curator's own copy of the set
- Sets with only a handful of adopters show no number at all, rather than advertising a small figure

**🎯 Counts that stay honest as sets change**
- Adopting a set, deleting your copy, and adopting again returns the number to where it started
- Applying an update to a set you have already adopted never inflates it
- A Goal and the subject plans inside it are counted independently and are never added together

## Polish & Fixes
- Counts are read in a single grouped query for a whole page of Explore cards, so browsing does not get slower as the catalog grows
- Added a database index for the count, the only schema change in this release
- Learners who adopted a set before the product recorded where copies came from are not counted; that undercount is accepted rather than guessed at
- Corrected two claims made when the release was opened: the count appearing on both a Goal and its subject plans is not a display problem, because neither surface lists subject plans with counts; and the small-count rule currently hides nothing, since every published top-level set is already well above it
