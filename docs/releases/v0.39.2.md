# Release Notes: v0.39.2 — Public Library Learning Experience

## Release Theme

Connect the Public Library discovery layer to the signed-in workspace's richer review methods, so anonymous visitors experience enough of the study system to want to continue — without weakening the line between discovery and the personal study workspace.

## Key Features

**🧠 Flashcards Preview on Public Notes**
- Anonymous visitors can now try up to 3 real flashcards directly on a public note's page — tap to flip, see the concept and its definition, no account required.
- Built from the same data that already powers the authenticated Flashcards surface, so every previewed card has a genuine matched definition, never a "no definition yet" placeholder.
- Mirrors the existing Quick Check mini-quiz preview's sanctioned pattern: capped, fully client-side, no backend calls, no progress or session data ever stored for unauthenticated visitors.
- Finishing the preview surfaces one clear "Continue Learning" call to action into the full deck.

**🔁 Memorization, Introduced Honestly**
- Memorization now appears as a described option alongside Challenge Quiz, Adaptive Practice, and Board Exam Mode on public note pages — explaining the spaced-repetition review cadence (review again after 1, 3, 7, 14, and 30 days).
- Deliberately not offered as a live "try it" preview: Memorization's real value only shows up over days and return visits, which a single anonymous session can't demonstrate.

## Polish & Fixes

- The public note conversion CTA hierarchy (`Quiz yourself on this note`, `Create your own Study Pack`, `Copy to My Library`) is unchanged — the new Flashcards and Memorization entries are additive, not a restructure.
- Added a `PUBLIC_NOTE_FLASHCARDS_CLICKED` analytics event to track Flashcards Preview conversions distinctly from the existing quiz and copy CTAs.
- Zero backend changes required — the Flashcards Preview runs entirely on Study Pack data that was already present in the public note response.
