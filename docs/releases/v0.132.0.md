# Release Notes: v0.132.0 — Publication Boundary

## Release Theme
Curators can now finish a piece of curriculum before anyone sees it: edits to an Official Review Set stay private until they choose to publish them.

## Key Features

**📝 A working draft for curriculum**
- Adding a topic or a Subject Plan to a published Review Set no longer reaches learners the moment you save it
- Your edits stay yours until you press **Publish update** — the set keeps showing its last published state to everyone else
- The Review Set page tells you when you have unpublished changes, and the confirmation says exactly what is about to become available
- Publishing is one atomic action. Pressing it twice does nothing the second time, and a failure mid-way leaves nothing half-published

**👀 What learners and visitors see**
- Anonymous visitors browsing Explore, the Exam Hub and the dashboard see only published curriculum — in the plan itself and in every count on the card
- Someone adopting a Review Set today copies the published version, never a half-finished Subject Plan
- Publishing makes changes **available**; it never overwrites what an adopter has already made theirs. Their own notes, progress and edits are untouched
- Everything that was already public on the day this shipped stayed public — nothing disappeared from Explore

## Polish & Fixes
- Fixed a Goal whose Subject Plans were all still unfinished handing an adopter a completely empty collection — silently, as their primary collection, with no way to fix it by adopting again
- Fixed Explore cards advertising note and plan counts that the page behind them would not show
- Fixed a Review Set that existed before this release publishing none of its newer content the first time it went public
- Fixed a failed publish showing its error underneath the dialog that was still covering the screen, so the curator saw a click that did nothing
- Added the missing tests behind three files this release introduced, including the first one that checks the publication query actually works against a real database rather than a stand-in

## Known limitations
- Hiding applies to **additions**. A topic you remove, or a section you reorder or rename, still changes what people see straight away — there is no stored "before" for those to fall back to
- The **Publish update** action and the unpublished-changes indicator live on the Review Set's own page. The Builder — where topics are actually added — does not yet show either, so it is possible to author a whole Subject Plan without being told it is not yet visible
- There is no public "Updated on" date yet. The release records when a set was last published, but nothing displays it
