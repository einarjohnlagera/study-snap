# Release Notes: v0.113.1 — Anchoring Hardening

## Release Theme
A patch that closes the loose ends the previous release's pressure test found and deliberately left, so that finishing a plan-wide practice session can never cost you the session.

## Key Features

**🛟 Finishing a plan-wide session can no longer strand it**
- If a single question's source could not be traced back to one of your notes, completing the session used to fail outright and roll the whole thing back
- The session had already been marked complete at that point, so it came back as still-in-progress, failed the same way on every retry, and blocked you from starting another plan-wide session
- That one question's evidence is now skipped and recorded for us to investigate, and the rest of your results are saved normally

**🔓 An older plan-wide session survives its Study Plan being deleted**
- Opening one of these sessions directly used to show a "not found" page even though the same session opened fine from the note it came from
- It now falls back to the note it was originally anchored on, so both routes agree

## Polish & Fixes
- One rule now decides whether a practice session is properly anchored, instead of three near-copies that disagreed at the edges — the weakest of them accepted a half-filled shape the database itself rejects.
- Test fixtures now carry the same anchoring constraint the real database enforces, so a test can no longer save a shape production would refuse.
- The test harness now runs the same PostgreSQL version as production, so the checks proving these rules run where they actually apply.
