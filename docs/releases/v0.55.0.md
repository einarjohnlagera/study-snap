# Release Notes: v0.55.0 — Result-Screen Companion Bridge

## Release Theme

Curator-authored Companion guidance no longer stays stranded on the Review Set page — it now surfaces at the moment it's most relevant: the quiz result screen, right where the Weekly Pacing Echo already lives.

## Key Features

**🧭 Result-Screen Companion Bridge**
- The Quick Review, Challenge Quiz (including Board Exam Mode), and Adaptive Practice result screens now show a labeled excerpt from your primary Review Set's Companion — a Common Mistakes callout when one exists, falling back to Study Strategy otherwise.
- Reuses the exact `primaryCollectionId` pattern the v0.46.0 Weekly Pacing Echo already shipped in the same slot, off the same single fetch — no new schema, no new endpoint, no backend changes.
- Renders nothing when the primary collection has no Companion content or no primary collection is set. Curator-published content only — no generation, no mid-exam coaching.

## Polish & Fixes

- Removed a duplicate network call caught in pre-signoff review: the excerpt now reads `companion` off the same `getCollectionGoal` response the Echo card already fetches, instead of a second `getCollection` round-trip.
- Corrected a scope claim that said Board Exam Mode's result screen was out of bounds for this feature — it already carries the Weekly Pacing Echo (since v0.46.0) and now carries the Companion Bridge too, matching that precedent rather than diverging from it.
- Documented the new surface in `docs/features/companion.md` and `docs/features/collections.md`, alongside the existing Post-session echo entry.
