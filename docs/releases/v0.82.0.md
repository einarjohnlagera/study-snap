# Release Notes: v0.82.0 — Authored Depth Backfill

## Release Theme

Curator notes now carry the depth they were always meant to have, so the field that will replace "who this is for" actually holds information.

## Key Features

**📐 Four note metadata axes instead of five**
- Records that "Target Audience" is retiring — it never reached a single generation prompt, and the access control it was created for was never built
- Nothing is removed yet: the field, its filter and its shareable link all keep working while its information moves to Authored Depth
- States plainly what is lost along the way, rather than claiming the change is free

**🎓 Curator notes inherit their curriculum depth**
- Board-review notes written by the NoteLib team now carry a matching depth, so future regenerations aim at the right level
- Learner-owned notes are never touched — depth is an authoring decision, and nobody else gets to make it on your behalf
- Notes for general students keep an empty depth on purpose: "student" spans grade school through college, and a guess would be worse than a blank

**🔍 Two audits that changed the outcome**
- Every Information Technology note marked "board exam" turned out to be ordinary coursework — so those notes are excluded rather than mislabelled at licensure depth
- A second audit found the same mistake on a High School note, so the exclusion became a list of subjects that have no licensure exam instead of a single special case
- A planned fourth change was audited first and cancelled: curators had already set those depths by hand, so there was nothing left to do

## Polish & Fixes

- Recorded how to undo the depth change, and captured the exact notes it affects, before it reaches production
- Noted that only one of the two depth mappings has anything to act on today, so the release is not described as doing more than it does
- Consolidated the September review dates from nine separate reads down to two, dropping the ones too small to answer anything at current scale
- Documented that a "board exam" label cannot be trusted on its own, so nobody rediscovers this the hard way

## Known Limitations

- **The exclusion list matches subject names exactly.** A note filed under a shorthand spelling would slip past it. Every note found so far uses the full name, so the known set is covered, but the list only protects against subjects somebody has already checked.
- **The migration keeps no record of which notes it changed.** A capture taken before it runs stands in for that record, and reversing the change depends on it.
- **Only two subjects have been audited.** The "board exam" label was wrong in both. A dated follow-up checks whether it holds elsewhere, including a hand-check of the largest affected subject.
- **Notes for general students still have no depth**, so a depth-based filter would return nothing for them until a curator classifies those notes.
