Generate study pack materials from the provided notes.

Output JSON schema:

{
  "title": string,
  "summary": string,
  "subject": string,
  "tags": string[],
  "keyConcepts": string[],
  "quiz": [
    {
      "question": string,
      "choices": string[4],
      "answerIndex": integer (0..3),
      "concept": string,
      "explanation": string
    }
  ]
}

Rules:

Summary
- 3 to 6 sentences
- clear and concise

Subject
- exactly 1 value
- broad academic category only (for example: History, Biology, Chemistry, Physics, Mathematics, Literature, Computer Science, Geography, Economics)
- concise and human-readable
- do not return a sentence

Tags
- 3 to 6 tags
- each tag must be 1 to 3 words
- tags must be reusable broad topic keywords
- do not repeat the study pack title
- avoid punctuation-heavy labels and sentence-like tags

Key Concepts
- 5 to 10 items
- short phrases

Quiz
- exactly {QUIZ_COUNT} questions
- target mix:
  - recall: {RECALL_COUNT}
  - understanding: {UNDERSTANDING_COUNT}
  - application: {APPLICATION_COUNT}
- each question must test a different concept from the notes
- concept should be a short topic label for the key idea being tested (1 to 4 words, never null)
- prioritize conceptual understanding over rote memorization
- each question must have 4 choices
- answerIndex must be between 0 and 3
- exactly one choice must be correct
- explanation should briefly explain why the answer is correct (1-2 sentences)

Quiz quality
- use all major ideas in the notes across the full quiz; avoid repeating one concept in most questions
- avoid duplicate concepts across questions; if two questions are about the same concept, rewrite one
- recall questions should test facts, terms, and definitions
- understanding questions should test conceptual understanding, causes, differences, or relationships
- application questions should test practical use of the concept in a realistic scenario
- if the notes are too short or too simple, prioritize recall and understanding
- all questions must remain answerable from the notes
- avoid generic question stems that could fit any subject
- avoid repeating the same question pattern or wording
- incorrect choices must be plausible and same-topic, not obvious throwaway distractors
- incorrect choices should be credible alternatives a learner might confuse with the correct answer
- keep wording precise and exam-style; avoid trick questions and ambiguity
- do not use "all of the above" or "none of the above"
- include at least one question that connects two ideas when the notes include related concepts

Content guidelines

- Questions must be answerable from the notes
- If notes are incomplete, generate simpler conceptual questions
- Avoid hallucinating specific details not present in the notes
- If OCR noise exists, ignore gibberish lines
- If the notes were extracted via OCR and edited by the user, treat the edited text as the final authoritative notes.

Tone
- calm
- supportive
- easy to understand for students
