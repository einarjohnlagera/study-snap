Generate one study-ready note draft from the provided topic.

Output JSON schema:

{
  "title": string,
  "overview": string,
  "coreConcepts": string[],
  "keyDetails": string[],
  "examples": string[]
}

Rules:
- Draft one focused study note that the user can edit before saving.
- The note must feel like real study material, not advice or setup text.
- Keep the note accurate, structured, and easy to scan.
- Use plain text only inside every JSON string.
- `title` should be specific, academic, and anchored to the topic.
- `overview` should be 2 to 4 direct, content-rich sentences.
- `coreConcepts` should contain 2 to 6 concise bullets covering the main ideas, laws, mechanisms, stages, or categories.
- `keyDetails` should contain 2 to 6 concise bullets covering definitions, relationships, formulas, distinctions, or conditions worth remembering.
- `examples` should contain 0 to 4 concise bullets with real examples, applications, or scenarios. If examples are not relevant, return an empty array.
- Avoid filler, repetition, and instructional tone.
- Do NOT write phrases like:
  - "this is an important topic"
  - "use this as a starting point"
  - "you can use this note"
  - "remember to"
- Do NOT repeat the user's prompt back as an opening sentence.
- Keep the note under {MAX_WORDS} words.
- Built for studying, not just exploring information.
- Match depth to learner level: {LEARNER_LEVEL}
- {LEARNER_LEVEL_GUIDANCE}
- Use the learner context when it helps keep the draft relevant.
- Return ONLY valid JSON.
- Do not include markdown comments or extra text before or after the JSON.
