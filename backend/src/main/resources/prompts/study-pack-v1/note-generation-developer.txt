Generate one study-ready note draft from the provided topic.

Output JSON schema:

{
  "title": string,
  "overview": string,
  "keyIdea": string,
  "coreDetails": string[],
  "whyItMatters": string[],
  "quickRecall": string[]
}

Rules:
- Write for active review and recall, not passive reading.
- Use plain text only inside every JSON string. No markdown, no backticks, no asterisks.

`title`
- specific, academic, and anchored to the topic
- not generic

`overview`
- 2 to 3 sentences maximum
- Lead with the most important fact, not background or context-setting
- No filler openers ("This note covers...", "X is an important topic...")

`keyIdea`
- 1 to 2 sentences
- The single most important takeaway from this topic
- A student who reads only this should understand the core concept

`coreDetails`
- 3 to 6 bullets
- Key events, facts, mechanisms, stages, or categories
- One fact per bullet — no storytelling, no multi-clause sentences

`whyItMatters`
- 2 to 4 bullets
- Significance, real-world relevance, or lasting impact
- Not a repeat of coreDetails — answer "so what?"

`quickRecall`
- 3 to 5 bullets
- Must include: dates, names, key terms, formulas, or precise definitions
- Format each bullet as: Term — value or definition
- Keep each bullet at or under {MAX_ITEM_CHARS} characters, counting the formula and any variable definitions together
- If a formula plus all its variable definitions will not fit, split it across two bullets rather than truncating either
- These are the facts to drill before an exam

General
- Avoid filler, repetition, and instructional tone
- Do NOT write phrases like:
  - "this is an important topic"
  - "use this as a starting point"
  - "you can use this note"
  - "remember to"
- Do NOT repeat the user's prompt back as an opening sentence
- Keep the note under {MAX_WORDS} words
- Built for studying, not just exploring information.
- Use Domain to set the note's subject matter, terminology, examples, and framing (for example, Engineering Mathematics, Nursing, or Accountancy).
- Use the Note learner level to set depth and difficulty; it is the level at which the note was authored.
- The reader's learner level must not lower or redirect this static note content.
- Use the Domain context when it helps keep the draft relevant.
- Return ONLY valid JSON.
- Do not include markdown comments or extra text before or after the JSON.
